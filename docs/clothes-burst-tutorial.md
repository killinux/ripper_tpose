# 爆衣插件：一步步教你用（Fiona 示例）

> 2026-10-02。用户：「如何使用教我一下」。插件说明见 [插件 README](../scripts/blender_addons/clothes_burst/README.md)，
> 原理见 [clothes-burst-guide.md](clothes-burst-guide.md)。下面的菜单名都是 Blender 3.6 中文界面里的叫法。
> 例子用你的 `E:\Downloads\Fiona 18\Fiona 18 1002.blend`（没撕过的那份），数值和插件的默认值一样。

## 开始之前

1. **重开 Blender 3.6**：插件在 Blender 启动时加载，已经开着的 Blender 看不到它。
2. **确认插件在**：鼠标放在 3D 视图上按 N 打开侧栏，侧栏最右边那排竖着的页签里有「爆衣」。
   - 没有的话：编辑 → 偏好设置 → 插件，搜「爆衣」，勾上；
   - 「布料撕裂」也要在插件目录里，两个已经一起装好了。
3. **打开练习文件**：文件 → 打开近期文件（或打开）→ `Fiona 18 1002.blend`。
   - 练完用「另存为」换个名字保存，不要覆盖它，下次还能接着练。
4. **把场景改短**：时间线右边的「结束点」改成 120。
   - 碎片在爆开后大约 40 帧就落地了，帧数多只是烘得久；
   - 要在「一键爆衣」**之前**改，因为插件按场景的帧范围设缓存。

## 面板长什么样

```
爆衣
├ 1. 选衣服      显示现在选中了哪几件衣服（编辑模式下显示选中了几个面）
├ 2. 爆开        [ 一键爆衣 ]（大按钮）
│                [ 快速预览 ]
│                [ 烘焙 ] [ 清除烘焙 ]
├ 设置（都有默认值）                              [↶ 恢复默认]
│   爆开帧 30            松开用几帧 3
│   推力（× 重力）1.00   推几帧 10
│   推的方向  [水平往外][四面八方]
│   贯穿裂缝 10          不贯穿裂缝 10
│   锯齿程度 0.6         随机种子 1
│   ▸ 更多设置（切开套圈、重新生成裂缝、从下往上、过渡宽度、合并距离）
├ 当前：衣服名    爆过的衣服才有：范围（整件 / 一部分）、[显示范围] [改成整件] 两个小按钮、
│                 上次用的设置、布料 2 速度 / 质量步数、推力组
└ 清理           [ 撤掉选中衣服的爆衣 ] [ 全部清理 ]
```

## 例 1：整件爆开

| 步骤 | 操作 | 成功的样子 |
|---|---|---|
| 1. 选衣服 | 物体模式，在**大纲视图**里展开 `Fiona 18 None` → `Fiona 18 None_arm`，点 `00C_+Dress.1`，再 Ctrl+点 `00D_+Dress.2`。身体、项链不要选。<br>在 3D 视图里点容易点到身体，所以用大纲视图 | 面板「1. 选衣服」显示「选中：00C_+Dress.1、00D_+Dress.2」 |
| 2. 一键爆衣 | 点「一键爆衣」，设置不用动 | 等一两秒，有这些变化：<br>• 状态栏显示「爆衣设好了……点「烘焙」后从第 1 帧播放」；<br>• 大纲视图多出 `CT_地面碰撞`（脚底的线框平面）和集合 `CB_爆衣力场_1`，里面有个箭头 `CB_爆衣推力_1`，在腰的位置；<br>• 面板多了「当前：00C_+Dress.1」一栏，写着「范围：整件」 |
| 3. 烘焙 | 点「烘焙」 | 底部状态栏有进度条（Esc 能取消），120 帧大约一两分钟 |
| 4. 看效果 | Shift+← 回到第 1 帧，空格播放；或者在时间线上拖，← → 一帧一帧看 | 第 30 帧前裙子好好的；第 35 帧左右炸开，碎片飞出去大约一个身高的距离；第 60 帧前后都落到地上 |

## 例 2：只爆裙摆，上衣留着

先把例 1 撤掉：大纲视图里选中两件裙子 →「撤掉选中衣服的爆衣」。
不撤的话，例 1 里设好的 `00D_+Dress.2`（肩带）还会照样炸开。

| 步骤 | 操作 | 说明 |
|---|---|---|
| 1. 进编辑模式 | 大纲视图里只点 `00C_+Dress.1` → 鼠标放在 3D 视图上按 Tab | |
| 2. 切到面选择 | 按 3 | 顶点 / 边选不算，要选面 |
| 3. 打开透视 | Alt+Z（3D 视图右上角的「切换透视模式」按钮） | 不开的话，框选只选得到朝着你的那一面，背后的裙摆选不到 |
| 4. 选裙摆 | 小键盘 1 切到前视图。先按 Alt+A 全部取消选择，再从腰下面一点往下拖一个框，把整个裙摆框进去 | 选多了：按住 Ctrl 拖框减掉。<br>想精确一点：鼠标指着某一块按 L 选「相连元素」，Ctrl+小键盘加号「扩展选择」一圈 |
| 5. 一键爆衣 | **还在编辑模式里**，点「一键爆衣」 | 插件自己切回物体模式。面板「当前」一栏写着「范围：一部分（N 个面）」 |
| 6. 烘焙、看效果 | 「烘焙」→ 播放 | 裙摆炸开、落地，上衣一直留在身上 |

- 关掉透视：再按 Alt+Z。
- 两件衣服各爆一部分：物体模式下先选中两件，再按 Tab，两件一起进编辑模式，各选一部分，点「一键爆衣」。
- 看 / 改选过的范围：点「当前」一栏的「显示范围」小按钮（编辑模式图标），会进编辑模式并选中那部分面，改完再点「一键爆衣」。
- 不要范围了：点「改成整件」小按钮（四个角往外的箭头图标），再点「一键爆衣」。

## 调效果：改设置 → 再点「一键爆衣」→「烘焙」

改了设置一定要再点一次「一键爆衣」，设置才会写进去。原来烘焙的结果会自动清掉，接着点「烘焙」就行。

| 想要 | 改什么 |
|---|---|
| 飞得太远、飞出画面 | 推力（× 重力）改小，比如 0.5；或者推几帧改成 5 |
| 太近，像直接掉下去 | 推力改大，比如 2 |
| 碎片往上飞（更像爆炸） | 推的方向选「四面八方」 |
| 碎片更碎 / 更大块 | 贯穿裂缝、不贯穿裂缝加大 / 减小 |
| 换一种碎法 | 随机种子换个数 |
| 换个时间爆 | 爆开帧，比如 60（结束点也要相应加大） |
| 不是一下子炸开，而是很快地撕开 | 松开用几帧改大，比如 20 |
| 先快一点看个大概 | 按下「快速预览」再烘（快将近一倍）。满意了关掉，再点「一键爆衣」→「烘焙」定稿 |
| 全部回到默认 | 设置栏右上角的 ↶ |

## 例 3：多件衣服，或者已经撕过的场景

- **多件一起爆**：大纲视图里 Ctrl+点把要爆的都选上（Tifa 的战斗服是 12 件一起），再点「一键爆衣」。
  - 每件衣服的推力自动换算，细布条也飞得出去；
  - 件数多烘得久，Tifa 12 件 120 帧大约两分钟。
- **不同的衣服在不同的帧爆**：
  - 选 A、爆开帧 30 →「一键爆衣」；
  - 再选 B、爆开帧 60 →「一键爆衣」；
  - 最后「烘焙」。两次各用一组推力，互不影响。
- **用布料撕裂插件撕过的场景**（比如你存的 Tifa）：先点爆衣面板的「全部清理」，把旧的撕裂设置清掉，再按上面做。

## 撤销和保存

- **撤掉几件**：选中它们 →「撤掉选中衣服的爆衣」，这几件回到爆衣之前。
- **全部撤掉**：「全部清理」→ 确定，爆衣和布料撕裂加的东西全删，包括身体上的碰撞、地面、推力场。
- **退回**：Ctrl+Z 可以撤销；或者文件 → 重新加载，回到上次保存的样子。
- **保存**：文件 → 另存为，换个名字。烘焙结果存在 .blend 里，文件会大不少。
