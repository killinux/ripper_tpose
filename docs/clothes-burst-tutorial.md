# 爆衣插件：一步步教你用（Fiona 示例）

> 2026-10-02。用户：「如何使用教我一下」。插件说明见 [插件 README](../scripts/blender_addons/clothes_burst/README.md)，
> 原理见 [clothes-burst-guide.md](clothes-burst-guide.md)。下面的菜单名都是 Blender 3.6 中文界面里的叫法。
> 例子用你的 `E:\Downloads\Fiona 18\Fiona 18 1002.blend`（没撕过的那份），数值和插件的默认值一样。
> 2.0（2026-10-05）面板最上面多了一行「方式」：「布料撕裂」是例 1–4（Blender 里渲染用），「MMD 表情」是例 5
> （导出 PMX + VMD，MMD 里放）。

## 开始之前

1. **重开 Blender 3.6**：插件在 Blender 启动时加载，已经开着的 Blender 看不到它。
2. **确认插件在**：鼠标放在 3D 视图上按 N 打开侧栏，侧栏最右边那排竖着的页签里有「爆衣」。
   - 没有的话：编辑 → 偏好设置 → 插件，搜「爆衣」，勾上；
   - 「布料撕裂」也要在插件目录里，两个已经一起装好了。
3. **打开练习文件**：文件 → 打开近期文件（或打开）→ `Fiona 18 1002.blend`。
   - 练完用「另存为」换个名字保存，不要覆盖它，下次还能接着练。
4. **把场景改短**：时间线右边的「结束点」改成 120。
   - 碎片在爆开后大约 40 帧就落地了，帧数多只是烘得久；
   - 要在「一键爆衣」**之前**改，因为插件按场景的帧范围设缓存。

## 面板长什么样

```

[布料撕裂][MMD 表情]   ← 方式（2.0）：下面是「布料撕裂」的面板，「MMD 表情」的见例 5
├ 1. 选衣服      显示现在选中了哪几件衣服（编辑模式下显示选中了几个面）
├ 2. 爆开        [ 一键爆衣 ]（大按钮）
│                [ 快速预览 ]
│                [ 烘焙 ] [ 清除烘焙 ]
├ 设置（都有默认值）                              [↶ 恢复默认]
│   爆开帧 30            松开用几帧 3
│   推力（× 重力）1.00   推几帧 10
│   推的方向  [水平往外][四面八方]
│   贯穿裂缝 10          不贯穿裂缝 10
│   锯齿程度 0.6         随机种子 1
│   ▸ 更多设置（切开套圈、重新生成裂缝、从下往上、过渡宽度、合并距离）
├ 外观（1.1）     [ 撕口毛边 ]
│                 宽度 0.50   变暗 0.30
│                 碎片消失：[不消失][淡出][溶解]（选了淡出 / 溶解才有时间、光边设置）

│                 上次用的设置、布料 2 速度 / 质量步数、推力组
└ 清理           [ 撤掉选中衣服的爆衣 ] [ 全部清理 ]
```

## 例 1：整件爆开

| 步骤 | 操作 | 成功的样子 |
|---|---|---|
| 1. 选衣服 | 物体模式，在**大纲视图**里展开 `Fiona 18 None` → `Fiona 18 None_arm`，点 `00C_+Dress.1`，再 Ctrl+点 `00D_+Dress.2`。身体、项链不要选。<br>在 3D 视图里点容易点到身体，所以用大纲视图 | 面板「1. 选衣服」显示「选中：00C_+Dress.1、00D_+Dress.2」 |
| 2. 一键爆衣 | 点「一键爆衣」，设置不用动 | 等一两秒，有这些变化：<br>• 状态栏显示「爆衣设好了……点「烘焙」后从第 1 帧播放」；<br>• 大纲视图多出 `CT_地面碰撞`（脚底的线框平面）和集合 `CB_爆衣力场_1`，里面有个箭头 `CB_爆衣推力_1`，在腰的位置；<br>• 面板多了「当前：00C_+Dress.1」一栏，写着「范围：整件」 |
| 3. 烘焙 | 点「烘焙」 | 底部状态栏有进度条（Esc 能取消），120 帧大约一两分钟 |
| 4. 看效果 | Shift+← 回到第 1 帧，空格播放；或者在时间线上拖，← → 一帧一帧看 | 第 30 帧前裙子好好的；第 35 帧左右炸开，碎片飞出去大约一个身高的距离；第 60 帧前后都落到地上 |

## 例 2：只爆裙摆，上衣留着

先把例 1 撤掉：大纲视图里选中两件裙子 →「撤掉选中衣服的爆衣」。
不撤的话，例 1 里设好的 `00D_+Dress.2`（肩带）还会照样炸开。

| 步骤 | 操作 | 说明 |
|---|---|---|
| 1. 进编辑模式 | 大纲视图里只点 `00C_+Dress.1` → 鼠标放在 3D 视图上按 Tab | |
| 2. 切到面选择 | 按 3 | 顶点 / 边选不算，要选面 |
| 3. 打开透视 | Alt+Z（3D 视图右上角的「切换透视模式」按钮） | 不开的话，框选只选得到朝着你的那一面，背后的裙摆选不到 |
| 4. 选裙摆 | 小键盘 1 切到前视图。先按 Alt+A 全部取消选择，再从腰下面一点往下拖一个框，把整个裙摆框进去 | 选多了：按住 Ctrl 拖框减掉。<br>想精确一点：鼠标指着某一块按 L 选「相连元素」，Ctrl+小键盘加号「扩展选择」一圈 |
| 5. 一键爆衣 | **还在编辑模式里**，点「一键爆衣」 | 插件自己切回物体模式。面板「当前」一栏写着「范围：一部分（N 个面）」 |
| 6. 烘焙、看效果 | 「烘焙」→ 播放 | 裙摆炸开、落地，上衣一直留在身上 |

- 关掉透视：再按 Alt+Z。
- 两件衣服各爆一部分：物体模式下先选中两件，再按 Tab，两件一起进编辑模式，各选一部分，点「一键爆衣」。
- 看 / 改选过的范围：点「当前」一栏的「显示范围」小按钮（编辑模式图标），会进编辑模式并选中那部分面，改完再点「一键爆衣」。
- 不要范围了：点「改成整件」小按钮（四个角往外的箭头图标），再点「一键爆衣」。

## 调效果：改设置 → 再点「一键爆衣」→「烘焙」

改了设置一定要再点一次「一键爆衣」，设置才会写进去。原来烘焙的结果会自动清掉，接着点「烘焙」就行。

| 想要 | 改什么 |
|---|---|
| 飞得太远、飞出画面 | 推力（× 重力）改小，比如 0.5；或者推几帧改成 5 |
| 太近，像直接掉下去 | 推力改大，比如 2 |
| 碎片往上飞（更像爆炸） | 推的方向选「四面八方」 |
| 碎片更碎 / 更大块 | 贯穿裂缝、不贯穿裂缝加大 / 减小 |
| 换一种碎法 | 随机种子换个数 |
| 换个时间爆 | 爆开帧，比如 60（结束点也要相应加大） |
| 不是一下子炸开，而是很快地撕开 | 松开用几帧改大，比如 20 |
| 先快一点看个大概 | 按下「快速预览」再烘（快将近一倍）。满意了关掉，再点「一键爆衣」→「烘焙」定稿 |
| 全部回到默认 | 设置栏右上角的 ↶ |

## 例 3：多件衣服，或者已经撕过的场景

- **多件一起爆**：大纲视图里 Ctrl+点把要爆的都选上（Tifa 的战斗服是 12 件一起），再点「一键爆衣」。
  - 每件衣服的推力自动换算，细布条也飞得出去；
  - 件数多烘得久，Tifa 12 件 120 帧大约两分钟。
- **不同的衣服在不同的帧爆**：
  - 选 A、爆开帧 30 →「一键爆衣」；
  - 再选 B、爆开帧 60 →「一键爆衣」；
  - 最后「烘焙」。两次各用一组推力，互不影响。
- **用布料撕裂插件撕过的场景**（比如你存的 Tifa）：先点爆衣面板的「全部清理」，把旧的撕裂设置清掉，再按上面做。

## 例 4：外观，撕口毛边、碎片烧掉（1.1）

接着例 1（烘焙好了的两件裙子）做。外观只影响画出来的样子，改了马上生效，**不用重新烘焙**。

| 步骤 | 操作 | 成功的样子 |
|---|---|---|
| 1. 换到能看外观的视图 | 鼠标放在 3D 视图上按 Z，选「材质预览」（或点 3D 视图右上角四个圆球里的第三个） | 「实体」视图看不到外观 |
| 2. 看撕口 | 拖到第 36 帧左右，滚轮拉近一块碎片 | 撕口是参差不齐的毛边，不是一条直线。撕口毛边默认就开着 |
| 3. 让碎片烧掉 | 面板「外观」→「碎片消失」点「溶解」 | 不用再点别的。拖到第 34–48 帧：碎片在空中边飞边烧，烧的边缘是橙色的光边，第 49 帧前烧完 |
| 4. 调时间 | 「松开后几帧开始」「用几帧」 | 想等碎片落地再消失：开始 25、用 25；想让碎片在地上多躺一会儿：开始 60 |
| 5. 换颜色 | 「光边颜色」点开选蓝色，「光边亮度」调大 | 光边马上变蓝 |
| 6. 渲染 | Eevee：渲染属性里勾上「辉光」，光边会发光晕。Cycles 不用设 | 渲染 → 渲染动画 |

- 只想碎片慢慢变透明：「碎片消失」选「淡出」。
- 不要毛边：点掉「撕口毛边」。两项都关掉时，材质完全回到原来的样子。
- 外观会在衣服材质里加一个节点组「CB 爆衣外观」，着色器编辑器里能看到。撤掉爆衣、全部清理时自动拿掉。
- 导出 FBX / XPS 之前先关掉外观，有的导出器认不出中间多了节点组的材质。

## 例 5：给 MMD 用，碎片飞散 / 直接消失（2.0）

> 2026-10-05 在用户开着的 Blender 3.6 里一步步走过（a08 Inase 的 full 版，也试了跳着手势舞爆开）。
> 例 1–4 是真的布料物理，结果只在 Blender 里；这一种把爆衣做成模型的**表情**：碎片怎么飞、怎么落是顶点表情，
> 衣服消失、碎片出现是材质表情，VMD 里只有表情帧。导出 PMX + VMD，MMD 里直接放，不用物理。
>
> 10-05 晚起 E 盘归档的 ROE full 版本身就是两份身体（穿衣的 + 裸体的，见 `docs/roe-complete-nude.md` 第 18 节），
> 第 2 栏写「身体已经有两份」，没有「换成完整身体」和 nude 版那两项，下面第 5 步跳过。

方式选「MMD 表情」后的面板：

```

├ 1. 模型和衣服   模型：Pc A08 Hd Full
│                 点材质切换，按下 = 衣服：   （模型的每个材质一个按钮）
│                 [ 按「衣服非表示_材質」选 ]
│                 [ 按选中的面选 ]           （编辑模式里才能点）
├ 2. 做法         [碎片飞散][直接消失]
│                 ✓ 身体已经有两份（「裸体形状」换身体，不用再换）   （ROE 的 full 版，10-05 晚起）
│                 ——身体只有一份、带形状键「裸体形状」的模型这里是：
│                 ☑ 换成完整身体
│                 nude 版 PMX（可选）：[路径][📁]
│                 碎片大小 cm 10.0    随机种子 1
│                 飞出多远（厘米）：近 15.0  远 35.0
│                 上扬 0.25           偏转 0.35
│                 ▸ 更多设置（飞出时转几度、落下时转几度、落下时往外漂）
├ 3. 生成 [↶]     [ 生成爆衣表情 ]（大按钮）

└ 4. 时间、预览、导出
                  爆开帧 120      慢放 1.00
                  [ 碎片淡出 ]    爆开后第几帧淡出：从 26  到 40   （直接消失时是「淡出用几帧」）
                  [ ▶ 在时间轴上预览 ][🗑]
                  合进动作（可选）：[路径][📁]
                  [ 导出爆衣 VMD ]

```

| 步骤 | 操作 | 成功的样子 |
|---|---|---|
| 1. 导入模型 | 文件 → 导入 → MikuMikuDance Model (.pmd, .pmx)，选 `E:\game_export\RiseOfEros\Inase\pmx\pc_a08_hd_full\pc_a08_hd_full.pmx`。左边的设置不用动（你装的 mmd_tools 缩放默认 1.0） | 大纲视图多出 `Pc A08 Hd Full`，5 秒左右 |
| 2. 切到 MMD 表情 | 3D 视图按 N →「爆衣」页签 → 最上面点「MMD 表情」 | 面板变成上面 1–4 四栏 |
| 3. 选中模型 | 在 3D 视图里点一下模型（身体、衣服、骨架都行） | 第 1 栏显示「模型：Pc A08 Hd Full」和一列材质按钮 |
| 4. 选衣服 | 点「按「衣服非表示_材質」选」 | `pc_a08_hd_body1`、`pc_a08_hd_body2` 变成按下（蓝色）。ROE 的 full 版都带这个表情；别的模型点材质按钮自己选，或者编辑模式选几个衣服上的面 →「按选中的面选」 |
| 5. 选 nude 版（可选） | 第 2 栏写「身体已经有两份」时跳过（归档的 ROE full 版都是）。身体只有一份时：「nude 版 PMX（可选）」点文件夹图标，选 `…\Inase\pmx\pc_a08_hd_nude\pc_a08_hd_nude.pmx` | 不选也行：脱衣身体用 Blender 换算的法线，个别指甲处差几度 |
| 6. 生成 | 点「生成爆衣表情」 | 几秒，状态栏：「爆衣表情做好了：700 块碎片，身体本来就是两份……」（身体只有一份时：「……身体换成完整的（两份身体），法线从 nude 版 PMX 拿：对上 108426 / 108426 个角……」）；第 3 栏显示「已生成：碎片飞散」 |
| 7. 换到材质预览 | 鼠标放在 3D 视图上按 Z →「材质预览」 | 「实体」视图里材质表情不起作用（衣服不会消失） |
| 8. 预览 | 点「在时间轴上预览」 | 跳到第 109 帧，状态栏「第 119 到 160 帧打好了表情帧，按空格播放」。空格：第 120 帧和之前一模一样，接着衣服碎成几百块飞出去、身体换成完整的；第 150 帧碎片落地，第 160 帧淡出完 |
| 9. 导出 PMX | 选中模型 → 文件 → 导出 → MikuMikuDance Model (.pmx)，缩放和导入时一样（这里 1.0），换个文件名 | 新 PMX 里多了碎片、这几个表情（身体只有一份的模型还多了脱衣身体） |
| 10. 导出 VMD | 点「导出爆衣 VMD」，选位置 | 默认名「爆衣_第120帧开始.vmd」，20 个表情帧 |
| 11. MMD 里 | 读入新 PMX → 读入舞蹈 VMD → 再读入爆衣 VMD | 第 120 帧爆开 |

- **跳着舞预览**：选中模型，文件 → 导入 → MikuMikuDance Motion (.vmd) 读入舞蹈，再点「在时间轴上预览」。
- **只要一个 VMD**：「合进动作（可选）」选舞蹈的 VMD，再「导出爆衣 VMD」：导出的是舞蹈加上爆衣的表情帧（舞蹈原文件不动）。
- **调效果**：改设置 → 再点「生成爆衣表情」（自动撤掉上一次再做）→「在时间轴上预览」。

| 想要 | 改什么 |
|---|---|
| 碎片更碎 / 更大块 | 碎片大小改小 / 改大（按 1.6 米身高给，模型高矮自动缩放） |
| 换一种碎法和飞法 | 随机种子换个数 |
| 飞得更远 / 更近 | 飞出多远的近、远 |
| 更往上飞 / 方向更乱 | 上扬 / 偏转 |
| 换个时间爆 | 爆开帧（不用重新生成，再点「在时间轴上预览」） |
| 慢动作 | 慢放，比如 2（不用重新生成） |
| 碎片留在地上 | 点掉「碎片淡出」（不用重新生成） |
| 不要碎片，衣服直接没了 | 做法选「直接消失」→「生成爆衣表情」；「淡出用几帧」1 = 一下子没了，大一点 = 几帧内淡出 |
| 设置回到默认 | 第 3 栏右边的 ↶ |

- **撤掉**：「撤掉爆衣表情」：碎片、脱衣身体、加的表情都删掉，模型回到生成之前（裸体形状 还原成形状键；本来就是两份身体的不动它）。「清除预览」（预览按钮右边的垃圾桶）只删预览打的表情帧。
- **导入的已经是爆衣 PMX**（比如 `_hq_trial\爆衣插件\pc_a08_hd_burst\pc_a08_hd_burst.pmx`）：第 3 栏写「模型已经带着爆衣表情（导入的爆衣 PMX）」，生成按钮不显示，直接预览、导出 VMD。要换设置重做，导入没做过爆衣的 PMX（比如它的 full 版）。只有两份身体、没有碎片的 full 版不算，照常生成。
- **材质用 mmd_tools 的「Convert Materials For Cycles」转成过原理化BSDF**：mmd_tools 的材质表情连不到原理化BSDF 上，插件给衣服、身体、碎片的材质插一个「CB 爆衣透明」节点，状态栏会说「N 个不是 MMD 着色器的材质加了透明节点」。「撤掉爆衣表情」时拿掉；导入的爆衣 PMX 上是预览时插的，「清除预览」时拿掉。导出的 PMX 不受影响。
- **刚生成的头几秒衣服上闪过黑块 / 白块**：EEVEE 在编译新材质的着色器，等几秒就好。
- **导入设置**：缩放 0.08 还是 1.0、骨骼改不改名都行，结果一样。
- **已知限制**：碎片跟着它挂的骨头走。手臂抬着的时候爆开，手臂上的碎片「往下落」也跟着手臂转了，会停在半空，到淡出（爆开后 40 帧）才消失。

## 撤销和保存

- **撤掉几件**：选中它们 →「撤掉选中衣服的爆衣」，这几件回到爆衣之前。
- **全部撤掉**：「全部清理」→ 确定，爆衣和布料撕裂加的东西全删，包括身体上的碰撞、地面、推力场。
- **MMD 表情**（例 5）：「撤掉爆衣表情」，模型回到生成之前。
- **退回**：Ctrl+Z 可以撤销；或者文件 → 重新加载，回到上次保存的样子。
- **保存**：文件 → 另存为，换个名字。烘焙结果存在 .blend 里，文件会大不少。
