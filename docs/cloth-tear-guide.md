> 2026-10-01。用户给了 B 站视频 [blender-布料模拟撕裂效果](https://www.bilibili.com/video/BV1Zk4y1x7Eo/)
>（峰峰居士，2023-03-24，6 分钟，Blender 3.4），要求「读一下内容，做一个 blender 插件」，装到 Blender 3.6。

## 1. 视频讲的做法

视频没有字幕文件，也没有简介。页面接口拦了程序访问（412），只能下载 360p 原片逐帧看画面，好在画面上烧录了中文字幕。
步骤和参数如下：

| 时间 | 做了什么 |
|---|---|
| 0:15–0:30 | 加平面，编辑模式细分 **20 刀**，`Ctrl+F` **戳孔面**（每格 4 个三角，顶点 484 → 925）：「让之后布料撕裂有更好的细节」 |
| 0:35–0:55 | 选远端两个角，各 `Ctrl+H` 钩挂到新物体（两个空物体），两个角 `Ctrl+G` 建顶点组 `Group` |
| 1:00–1:25 | 加布料修改器，固定组 = `Group`，打开自碰撞；平滑着色 |
| 1:30–1:50 | 右边空物体第 90 帧打位置关键帧，第 190 帧拉到远处：一段拉扯动画 |
| 2:00–2:15 | 编辑模式边选择，选一些边当裂缝，边折痕（Shift+E）拉到 **1** |
| 2:20–3:00 | 几何节点：`拆分边`，选择 = 已命名属性 `crease`（就是边折痕） |
| 3:05–3:55 | 「需要一个有渐变动画的权重」：存储已命名属性（浮点、点，名字就是固定组 `Group`）=<br>原 `Group` + 颜色渐变（已命名属性 `UVMap` → 分离 XYZ 的 Y → 相加一个值） |
| 4:00–4:35 | 颜色渐变：白 ≈0.37 → 黑 0.405，过渡很窄；相加的值第 122 帧 −0.7、第 168 帧 +0.7（打关键帧），权重从上到下消减 |
| 4:40–5:20 | 布料修改器「一个物体只能加一个」，但 `Shift+D` 能复制：复制一个放到几何节点下面。「简单说就是俩布料修改器的混合」 |
| 5:30–5:50 | 再加一个几何节点：`按距离合并`（0.001 m），选择 = `crease`，「这样就不会穿帮了」 |

原理是两个布料修改器叠在一起：
- 布料 1 模拟一块完整的布被拉扯；
- 几何节点按裂缝把网格拆开，再把固定组改写成随时间从上往下扫的权重；
- 布料 2 用这个固定组：权重为 1 的地方完全跟着布料 1 走，看不出裂缝；权重降下来的地方各块就沿裂缝散开，这就是撕裂；
- 最后再按距离合并，没撕开的裂缝重新合上，不露缝。

## 2. 插件做了什么

侧栏（N）→「布料撕裂」页签，七块（1.2.0）：

| | 已生成后的参数 | 开始帧、结束帧、过渡宽度、合并距离直接在面板里调，不用重新生成（改了要清除烘焙重算） |

| 6. 清理 | 全部清理 | 1.2：删掉插件在这个场景里加的所有东西，回到用插件之前（先弹窗确认，可撤销）。见第 6 节 |

和视频的不同：
- **不用打关键帧**：几何节点里读「场景时间」，按开始帧、结束帧算出松开带的位置；
- **方向可选**：坐标先用整块布的最小 / 最大值归一化到 0..1，所以除了视频里 UV 的 V，也可以选 UV 的 U 或物体 X / Y / Z；可以反过来从下往上撕。
  布料是竖着建的（窗帘），选 Z 就是从上往下；
- **不会叠加超过 1**：固定组用 `max(原固定组, 松开带)`，不是视频里的相加；
- **没有固定组也能用**：原布料没设固定组时，松开带写进新建的顶点组 `CT_Pin`，布料 2 用它；
- 裂缝可以随机生成。

### 几何节点 `CT_TearSplit_<物体名>`

```
组输入 ─ 拆分边（选择 = 已命名属性 crease / crease_edge）─┬─ 存储已命名属性（浮点、点，名 = 固定组）─ 组输出
                                                         │        值 = max(原固定组, 松开带)
坐标 = UV 或位置的一个分量 → 属性统计 min/max → 映射范围到 0..1（可反向）= c
t    = 映射范围(场景帧, 开始帧, 结束帧 → 0..1, 钳制)
前沿 s = (1 + w) − t·(1 + 2w)；松开带 = 映射范围(c, s → s − w, 到 0 → 1, 钳制)
```

`t = 0` 时 `s = 1 + w`，整块布权重为 1；`t = 1` 时 `s = −w`，权重全为 0；中间是一条宽 `w` 的过渡带从 c = 1 扫到 c = 0。
「存储已命名属性」的名字和已有顶点组同名时，写进的就是顶点组，后面的布料修改器能直接当固定组用。
写进去的值只影响它后面的修改器，所以布料 1 看到的还是原来的固定组。

### 版本

插件按 3.6 写，也兼容 4.x：
- 边折痕属性 3.x 叫 `crease`，4.0 起叫 `crease_edge`；
- 节点组接口 4.0 起是 `interface.new_socket`；
- 修改器输入的键 3.x 是 `Input_N`，4.x 是 `Socket_N`；
- 都按版本处理了。只在 3.6.15 上测过。

## 3. 衣服模式（撕角色衣服）

> 2026-10-01 用户要「把我现在 blender 中的 Fiona 18 None 的衣服撕开」。在用户开着的 Blender 里做（blender-mcp），
> 过程中补了下面这些（插件 1.1.0）。

视频里是一块布被钩子拉着：布料 1 本身在模拟，撕开的碎片被钩子拉走。角色的衣服不一样，要改五处。

1. **布料 1 全部固定**（「衣服跟随身体」，`follow_body()`）：
   - 顶点组 `CT_Follow` 全为 1，布料 1 只是跟着骨架修改器走（布料排在骨架后面）；
   - 撕开前就是原来的蒙皮衣服，不会因为模拟而下垂或穿模；
   - 关掉自碰撞，缓存范围设成场景帧范围。
2. **松开带写进 `CT_Pin`**：
   - 布料 2 的固定组 = max(保留组, 松开带)；
   - 保留组默认是「无」，撕开的全部掉落；也可以选领口、腰带这样的顶点组；
   - 保留组和布料 1 的固定组不同，所以松开带写进单独的组 `CT_Pin`。
3. **碰撞和地面**：
   - `body_meshes()` 找同一骨架下、包围盒和衣服重叠的网格，加碰撞修改器；
   - 跳过头发、眼睛、睫毛、眉毛、嘴、脸、头，以及已经有布料的另一件衣服；
   - 模型按材质拆开后身体是好几块，例如 Body / Legs / Arms / Panties，都会加上；
   - 1.2 起项链、耳环、臂甲这类饰品不加碰撞，加的碰撞修改器叫 `CT 碰撞`（1.1 叫 `Collision`），见第 6 节；
   - 同骨架所有网格的最低点放一块不渲染的地面 `CT_地面碰撞`，碎片落在地上，不会一直往下掉。
4. **推力场**（`add_tear_force()`）：
   - 为什么要：角色不动时，松开的碎片只受重力，贴着身体慢慢往下滑，看不出是被撕开的；
     Fiona 第一次烘焙没有推力场，碎片到第 200 帧才滑到地上；
   - 做法：衣服包围盒中心放一个空物体力场：
     - 类型「力」，点形状；
     - 球形衰减、衰减幂 0（范围内恒定），最大距离 = 1.2 × 衣服最大尺寸；
     - 强度关键帧：开始帧前一帧 0 → 开始帧 + 5 帧到设定强度 → 保持到结束帧 + 10 → 再过 5 帧回到 0，之后碎片自然落下；
   - 只推衣服：布料的力场权重集合设成 `CT_撕裂力场`，里面只有这个力场；
   - 刚体世界原来没设力场集合时，设成空集合 `CT_无力场`，MMD 头发不被推；
   - 1.2 起不再是从中心往四面推的点力场，改成竖直轴的线力场：水平往外推，范围是衣服那一段高度的圆柱，见第 6 节。
5. **速度**（`tear_speed()`）：
   - 重力加速度固定 9.81。模型放大 10 倍后，下落同样比例的距离要 √10 倍的时间，看起来像慢动作；
   - 布料 2 的时间缩放取 `√(身高 / 1.7)`，不小于 1。身高 = 同骨架所有网格的包围盒高度；
     PMX 原尺寸的 Fiona 含头饰是 20.8，所以速度 3.49；
   - 质量步数提高到 `⌈5 × 速度⌉`，不然一快就炸；
   - 推力强度因此不用跟着尺寸改：
     - 碎片要推开的距离和尺寸 L 成正比；
     - 时间缩放 ts 时，同样帧数里模拟的时间是 ts 倍，位移 ∝ 力 × ts²；
     - ts² = L / 1.7，所以位移 ∝ 力 × L，和要推开的距离同比例；
     - 这是近似，布料自身的刚度不按这个比例。

另外修了两个只有衣服才会碰到的错：

- **裂缝按块分配**：衣服常常是好几块拼的，Fiona 的两件裙子共 59 块。
  - 旧版在整个网格的布边上随机取两个点连线，两点几乎总在不同的块上，连不通，生成 0 条裂缝；
  - 现在每条裂缝先按顶点数加权选一块，再在这块里连；不到最大一块 5% 的小块不撕。
- **合缝节点组共用**：旧版 `build_merge_tree()` 每次删掉 `CT_TearMerge` 重建。
  - 给第二件衣服生成时，第一件的合缝修改器就指向了被删的组，没撕开的缝再也合不上；
  - 现在已有就直接用。

## 4. 用法

**看效果**：点「一键创建撕裂示例」→ 从第 1 帧播放（或「烘焙」后拖时间轴）。也可以直接打开 `D:\cloth_tear_demo\cloth_tear_demo.blend`，
预渲染的视频在 `D:\cloth_tear_demo\cloth_tear_demo.mp4`。

**用在自己的布上**：
1. 布要有足够的面数，面越多撕口越碎；「细分网格」可以加面；
2. 编辑模式选要固定或拉扯的顶点 →「选中顶点钩挂 + 固定」，给空物体打关键帧做拉扯动画。
   用自己的钉固方式也行，只要布料修改器的固定组设好；
3. 加布料修改器（固定组 = `Group`），先确认不撕的时候拉扯效果对；
4. 编辑模式用边选择模式选裂缝的边 →「选中边设为裂缝」，或「随机生成裂缝」；
5. 选方向、开始帧和结束帧（在拉扯开始之后）→「生成 / 更新撕裂」；
6. 「烘焙」。改了任何设置要先「清除烘焙」再烘。

小贴士：
- 撕开的部分如果离钩挂点太远会整块掉下去，这是物理上对的。想两半各挂一边，就让一条贯穿的裂缝从两个钩挂点中间穿过；
- 过渡宽度越小，撕得越干脆；越大，越像慢慢扯开；
- 布料 2 是布料 1 的完整拷贝（质量、刚度、碰撞都一样），可以在修改器面板单独改，比如关掉自碰撞会快很多。

**撕角色衣服**（MMD 模型先在 MMD 侧栏点「按材质分开」）：
1. 选中衣服（可多选）→「衣服跟随身体」；
2. →「随机生成裂缝」；
3. 方向「物体 Z」、开始帧 / 结束帧 →「生成 / 更新撕裂」；
4. →「加推力场」；
5. →「烘焙」。

逐步说明见插件 README 的「用在角色衣服上」，照着做的完整例子见 [cloth-tear-fiona-demo.md](cloth-tear-fiona-demo.md)。Fiona 用的值：
- Dress.1 先 6 条贯穿（种子 5）再 6 条不贯穿（种子 6），共 325 条边；Dress.2 是 3 + 3 条（种子 7 / 8），44 条边；
- 第 30–100 帧，过渡宽度 0.08，合并距离 0.0005，撕开后仍固定 = 无；
- 推力强度 40、布料 2 速度 2.5、质量步数 12，这三个是手调的；现在的默认（强度 25 + 按尺寸调快）效果一样，见下面的验证。

## 5. 验证（Blender 3.6.15）

- **一键示例**，逐帧统计最终网格（合缝之后）的块数和固定组：
  - 1–120 帧：925 个顶点、1 块，固定组全部为 1；
  - 130–160 帧：固定组从上往下降（全 1 的点 712 → 518 → 325 → 131），撕开的缝顶点数增加（925 → 978）；
  - 170 帧起：2 块（519 + 465），只剩两个钩挂角是 1。
  - 渲染逐帧看过：拉扯 → 中间撕开 → 两半各挂在一个空物体上，边缘是毛的，和视频结尾一样。
  - 第一版示例全是贯穿裂缝，最后只剩两个小角挂着，所以改成一条主裂缝 + 不贯穿的短裂缝。
- **手动流程**：竖挂的窗帘（物体 Z 方向）按顺序跑了全部按钮：
  - 细分 16 刀 + 戳孔面 → 两个角钩挂 → 加布料 → 随机生成 3 条不贯穿裂缝 → 生成撕裂 → 再点一次更新 → 烘焙 → 清除烘焙 → 移除 → 清除裂缝，全部 FINISHED；
  - 第 110 帧撕成 2 块；
  - 没有裂缝时「生成撕裂」会报错提示；
  - 重复生成不会多出修改器；移除后只剩钩挂和原布料。
- 修过的错：第一版移动修改器时下标算错，布料 2 被排到拆缝节点前面，撕不开。现在一次性按最终顺序排。
- 安装：`%APPDATA%\Blender Foundation\Blender\3.6\scripts\addons\cloth_tear` 联接到仓库目录，偏好设置里已启用（1.1.0；10-02 起 1.2.0，用户重开 Blender 才会加载新版），面板注册正常。

衣服模式：

### 6.2 三处修改

1. **切开套圈**（`cut_loops()`，面板「切开套圈」开关和「只切开套圈」按钮）：
   - 道理：一块布有 k 圈边界，等于球面上开了 k 个洞；身体从洞里穿过去（腰带、袖子、筒裙）时，撕成碎片也掉不下来。
     加 k−1 条把各圈连起来的裂缝，整块就变成一片，没有圈了；
   - 做法：
     - 复制网格，按已有裂缝拆开（`bmesh.ops.split_edges`），已有裂缝算已经撕开；
     - 每块找边界圈（边界边按共用顶点连通）；周长不到这块最大一圈 25% 的小圈不算（镂空花纹、小孔）；
     - 从一圈出发做多源 Dijkstra，边长加随机扰动（和随机裂缝一样是锯齿状），走到最近的另一圈，路径上的边设为裂缝；
     - 再从连起来的部分出发连下一圈，直到都连上；
   - Fiona：Dress.1 只有腰带一块是环，补了 1 条（5 条边，所以是 305 = 用户的 300 + 5）；Dress.2 没有环，不加。
2. **饰品不加碰撞**（`ACCESSORIES`）：
   - 名字或材质名里有 necklace、earring、pendant、choker、bracelet、pad、armor、项链、耳环、吊坠、手镯、护甲、臂甲、
     ネックレス、アーマー之类的网格，「衣服跟随身体」不加碰撞，状态栏列出「饰品不加碰撞：……」；
   - 加的碰撞修改器改名 `CT 碰撞`（1.1 叫 `Collision`，和 Blender 默认名一样，分不出是谁加的）；
   - 已经有碰撞的饰品（1.1 加的）会提示「可以用全部清理或手动删掉」，不会自己删。
3. **推力场改成线形**（`add_tear_force(shape="LINE")`）：
   - Blender 力场「形状 = 线」时，力从物体的局部 Z 轴（竖直）指向点，是水平方向；
   - 衰减选「管状」，上下和径向各有最大距离：上下 = 衣服高度 × 1.05，径向 = 1.2 × 衣服最大尺寸，衰减幂 0（范围内恒定）；
   - 旧的点力场在衣服中心（Fiona z 14.3）往四面推：脖子、肩上（z ≈ 17.8）的碎片是往上推的，推完又搭回肩上；
     球形范围往下一直到小腿；
   - 新的：肩上的碎片水平推离身体；掉到衣服下沿以下就出了范围，自然落地，地上的碎片不会被推着滑。
   - 臂甲也归入饰品，是因为 T 字姿势时水平往外 = 顺着手臂：碎片被推到手臂上，挂在臂甲尖上（剩 3 小块）。
   - 试过只往前后推（平面力场，法线 = 身体前后方向）：臂甲有碰撞时更差，没碰撞时和线形一样，没采用。
