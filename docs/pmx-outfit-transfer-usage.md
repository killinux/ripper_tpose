# PMX 换装插件怎么用（pmx_outfit_transfer）

把一个 PMX 模型的衣服穿到另一个 PMX 模型身上：选好要搬的材质，插件把它们连同骨骼、刚体、关节、材质和贴图搬过去，
按目标的裸体形状贴身拟合，写出一个新的 PMX。两个原文件不动，两套衣服的刚体互不碰撞。给 PMX 之间换衣服、拼衣服用。

原理和踩过的坑见 [pmx-outfit-transfer.md](pmx-outfit-transfer.md)，插件目录：`scripts/blender_addons/pmx_outfit_transfer/`。

## 一、安装

本机已经装好（目录联接），别的机器这样装：

```powershell
New-Item -ItemType Junction -Path "$env:APPDATA\Blender Foundation\Blender\3.6\scripts\addons\pmx_outfit_transfer" `
         -Target "E:\code\othercode\ripper_tpose\scripts\blender_addons\pmx_outfit_transfer"
```

1. 打开 Blender 3.6（已经开着的要重启，或 F3 搜「Reload Scripts」）。
2. 编辑 → 偏好设置 → 插件，搜 `PMX Outfit Transfer`，勾上。
3. 同时要开着 **mmd_tools**（读写 PMX、把结果导入场景都靠它）。

## 二、面板在哪

## 三、一步一步（例子：g05 的衣服 → a08 full）

1. **衣服来自**：点文件夹图标选提供衣服的 PMX。
   例子：`E:\game_export\RiseOfEros\Luf\pmx\pc_g05_hd_full\pc_g05_hd_full_裙子碰撞修正_瞳孔修正.pmx`。
   有修正版（裙子碰撞修正、胸部修正）就用修正版，衣服的物理会一起搬过去。
2. **穿到**：目标 PMX。例子：`E:\game_export\RiseOfEros\Inase\pmx\pc_a08_hd_full\pc_a08_hd_full_裙子碰撞修正.pmx`。
   用 **full 版**（裸体 + 衣服在一个文件里）最好：有裸体材质才能贴身拟合，而且之后拉「衣服非表示」就能脱掉目标自己的衣服。
3. **输出 PMX**：留空就在目标旁边新建文件夹 `<目标文件名>_穿<前缀>衣服\`，PMX 和 `textures\` 都放里面。
   想放别处就填完整路径。已经存在的文件不会覆盖，会报错。
4. 点「**读取源模型的材质**」。列表里是源 PMX 的全部材质：
   - 身体、脸、头发、眼睛、睫毛、眉毛、武器默认**不勾**（按名字认：`_nk_body`、`_nk_face`、`_nude`、`eye_`、`lash`、`brow`、`_nk_hair`、`wp_`）；
   - 其余默认勾上。要搬头发就勾头发（它的物理链会一起来）；只要裙子就把上衣的材质去掉。
   - 同时会填好「源的身体材质」和「目标的裸体材质」：ROE 的 full 版源用 `*_nk_body`（衣服下面贴身那份），目标用 `*_nk_body_nude`。
     不是 ROE 的模型要自己填：源填「衣服是在哪个身体上做的」那个材质，目标填裸体材质。填错或留空，就只按骨骼重定向、不贴身。
5. 选项一般不用动（见第六节）。
6. 点「**换装**」。十几秒（g05 → a08：13 秒）。面板下面显示写出了什么；有警告（比如某根 IK 骨没带 IK）也在这里。
7. 默认「做完导入场景」：结果 PMX 用 mmd_tools 导入当前场景（缩放 0.08），可以直接转着看。
   不想要导入就取消勾选，去输出文件夹拿 PMX。

成品里有什么：
- 目标原来的全部东西（它自己的衣服也还在，两套重叠）；
- 源的衣服，材质名 `<前缀>_<源材质简称>_<挂的骨头>`，比如 `g05_body1_Riband_M`（前片）、`g05_body2_Leaf_L`（左半花环）、`g05_body2_Headgear`（光环）、
  `g05_body1_chest_L`（左胸带）、`g05_body2_Riband_BL`（左披帛）；
- 新骨骼在显示枠「`<前缀>衣服`」里；新刚体在目标没用的碰撞组里；
- `textures\` 里是两边贴图的实拷贝，整个文件夹能挪走。

## 四、之后挑零件、导出

两种做法任选：

**PMXEditor**：打开成品，材质页按名字找到不要的零件，删掉材质（顶点一起删）。目标自己的衣服不要了也在这里删。保存成新文件。

**Blender**（结果已经导入场景时）：
1. 选中模型的网格，进编辑模式，材质面板里选中某个 `g05_…` 材质 → 「选择」→ `X` 删除面；
   或者在物体模式 `L` 选连在一起的一块布。
2. 删完回物体模式，选中模型的根（空物体），文件 → 导出 → MikuMikuDance Model (.pmx)，勾「复制贴图」，存到新文件夹。

拉表情「**衣服非表示**」= 脱掉目标自己的衣服、显示裸体，新衣服留着（新衣服默认不加进这个表情）。
想让新衣服也跟着脱，换装时勾「加进『衣服非表示』」。

## 五、拼几套衣服

一次只搬一个源。要把 A 的上衣和 B 的裙子都穿到 C 身上：
1. 先 A → C，勾 A 的上衣材质，输出 C1；
2. 再 B → C1（「穿到」填 C1），勾 B 的裙子材质，输出 C2。前缀自动从源文件名取（`pc_b03_…` → `b03`），不会重名。
每套衣服的刚体占目标没用过的碰撞组，PMX 一共 16 组，一般够拼三四套。

## 六、选项

| 选项 | 默认 | 什么时候改 |
|---|---|---|
| 按身体形状贴身拟合 | 开 | 两边都没有裸体材质、或只想按骨骼摆一摆时关掉 |
| 贴身距离 cm | 2 | 离源身体不超过这个距离的衣服完全跟着身体形状走（贴身衣、腰带、胸带）。衣服本来就离身体远（宽松长袍）可以加大 |
| 远离距离 cm | 12 | 超过这个距离只按骨骼放（光环、法杖、披帛末端），中间渐变。觉得远处的东西被身材带歪了就调小 |
| 按骨骼方向旋转 | 开 | 两边休息姿势一样（ROE 都是 A 形）时没影响；一边 T 形一边 A 形时必须开 |
| 拆分材质 | 按挂的骨头 | 「按连通块」每块布一个材质（小碎块按骨头合并，阈值「最小零件顶点数」）；「不拆」源材质原样 |
| 两套衣服的刚体互不碰撞 | 开 | 基本不用关 |
| 新衣服碰目标的身体 | 开 | 新衣服的刚体和目标的身体碰撞体碰撞（和在源身上一样）。关掉就谁也不碰 |
| 加进「衣服非表示」 | 关 | 见第四节 |
| 做完导入场景 | 开 | 批量做时关掉 |

## 七、命令行（不开 Blender 界面）

```powershell
& "D:\Program Files\blender-3.6.15-windows-x64\blender.exe" -b --factory-startup `
    --python E:\code\othercode\ripper_tpose\scripts\blender_addons\pmx_outfit_transfer\cli.py -- `
    源.pmx 目标.pmx 输出.pmx `
    [--materials "pc_g05_hd_body 1,pc_g05_hd_body 2"] [--donor-body pc_g01_nk_body] [--target-body pc_a01_nk_body_nude] `
    [--no-fit] [--near 2] [--far 12] [--no-rotation] [--split bone|island|none] [--prefix g05] `
    [--no-isolate] [--no-body-collision] [--hide-morph 衣服非表示_材質]
```

不写 `--materials` 就是面板里默认勾的那些。最后一行 `REPORT {...}` 是 JSON 报告。
装了 numpy 的普通 Python 也能 `python cli.py …`，最近点搜索用 numpy 暴力算，慢一些。

## 八、常见问题

- **「没有勾选任何材质」/ 列表是空的**：先点「读取源模型的材质」。
- **「输出已存在，不覆盖」**：换个输出名，或把旧的挪走。
- **面板提示 skeleton fit only / 没找到身体材质**：两边的身体材质没认出来，手填「源的身体材质」「目标的裸体材质」。
- **衣服陷进身体**：源的身体材质填成了裸体那份（`_nude`）而不是贴身那份（`_nk_body`）时会这样——源的衣服本来就压进裸体几毫米，
  照搬到目标裸体上就陷进去。填 `_nk_body`。
- **光环、法杖、长披帛位置不对**：这些离身体远，只按骨骼放，在 Blender 里挪一下。调「远离距离」也行。
- **胸带下面的身体跳舞时顶出来**（full 版）：目标裸体乳头跟胸摆的比例（0.9）和胸带（0.44 左右）不一样，和 g05 full 当初一样。
  挑完零件后跑 `scripts\riseoferos\pmx_body_follows_cups.py` + `pmx_body_cover_cups.py --body <裸体材质>`，见 [roe-full-chest-fix.md](roe-full-chest-fix.md)。
- **源的表情没了**：源的材质表情、顶点表情不搬，目标自己的都在。
- **源的衣服骨和目标重名**（两条裙链都叫 `Skirt_L_01`）：自动改名 `<前缀>:Skirt_L_01`，不会挂错。
- **IK 骨**：衣服用到的 IK 骨会搬过来但不带 IK 设置，面板会警告。
- **mmd_tools 没启用**：换装照样写 PMX，只是不导入场景。

## 九、它怎么做的（一句话版）

衣服先按骨骼重定向到目标骨架 → 源的身体变成目标身材（最近点位移场） → 衣服按它在源身体上的位置贴回新身材，远处渐变回骨骼结果
→ 刚体、关节跟着走，碰撞组隔开。细节、数字、两个坑见 [pmx-outfit-transfer.md](pmx-outfit-transfer.md)。
