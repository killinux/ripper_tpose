## 2. 在 MMD 里用

### 2.1 读入模型

用支持 PMX 的 MMD（9.x 版）。有两种方法：

- 把 `.pmx` 拖进 MMD 窗口；
- 或者点"モデル操作"面板的"読込"，再选 PMX。

读进来以后，贴图从旁边的 `textures\` 文件夹找。

### 2.2 手动调表情、打关键帧

MMD 的"表情操作"面板分四栏，和 PMX 里的表情分类一一对应：

| MMD 面板 | PMX 分类 | 这个模型里的表情 |
|---|---|---|
| 目（左上） | 目 | まばたき、笑い、ウィンク、ウィンク右、ウィンク２、ｳｨﾝｸ２右、じと目、びっくり、はぅ、なごみ |
| リップ（右上） | 口 | あ、い、う、え、お、ん、ワ、にっこり、にやり、∧、口角上げ、口角下げ、口横広げ |
| まゆ（左下） | 眉 | 真面目、困る、にこり、怒り、上、下 |
| その他（右下） | 其他 | F_Smile01 等 14 个游戏整脸表情 |

打关键帧的步骤：

1. 在下拉框里选一个表情；
2. 拖滑块调数值（0–1）；
3. 点这一栏的"登録"，就在当前帧打上关键帧。

时间轴里"表情"那一组列出了全部 43 个表情，可以在那里复制、粘贴、删除关键帧。

### 2.3 套用舞蹈动作（VMD）

1. 选中这个模型，把帧位置放到 0。MMD 会从当前帧开始读入动作。
2. "ファイル → モーションデータ読込"，或者直接把 `.vmd` 拖进窗口。
3. 很多动作包把表情单独放在一个文件里（`表情.vmd`、`xxx_face.vmd`）。这个文件也要在第 0 帧读进同一个模型，
   MMD 会把它和身体动作合并在一起。

VMD 是**按表情名字**驱动的，所以 VMD 里写的名字模型里要有同名表情才会动。拿本机 `E:\Downloads` 下的 320 个 VMD
统计过：

- 带表情关键帧的有 246 个；
- **217 个（88%）用到的表情这个模型全都有**；
- 25 个缺 1–6 个名字。缺的是少见的表情（口横狭め、瞳小、下右 / 下左（单侧眉）、にやり２、ω、あ２、照れ、
  キリッ 等），或者别的模型专用的变形（巨乳、左手握り 这类）。缺的那几个不会动，其他表情照常；
- 4 个是给面部捕捉模型用的 ARKit 表情文件（`_face.vmd`，名字是 eyeLookUpLeft、mouthPressLeft 这类）。
  这种文件大部分不认，每个只有 4–8 个标准名（お、ウィンク、ウィンク右、ワ、困る 等）会动。

最常用的表情和它们在这 246 个文件里出现的次数，这个模型都有：

| 表情 | まばたき | あ | 口角上げ | ウィンク右 | 笑い | お | い | う | ウィンク | にやり | じと目 | 困る |
|---|---|---|---|---|---|---|---|---|---|---|---|---|
| 次数 | 204 | 154 | 70 | 67 | 44 | 38 | 37 | 33 | 27 | 16 | 13 | 12 |

视线不是表情，是骨骼：VMD 里 `両目`（或 `左目` / `右目`）的关键帧直接生效，`左目`、`右目` 跟着 `両目` 转。

### 2.5 使用提示

- **同一部位的表情会叠加。**
  - 笑い 本身已经闭眼，再和 まばたき 同时拉满，眼皮会闭过头、穿到下眼皮外面；
  - あ 和 お 同时拉满，嘴会张得过大。
  - 这和一般 MMD 模型一样，一个部位同一时间只拉一个表情，或者两个加起来不超过 1。
- **その他 的整脸表情已经包含眼、眉、嘴**，一般单独用。和 目 / 眉 / 口 的表情一起用也会叠加；通常只配 まばたき 眨眼。
- **眉毛动得轻**：MMD 的滑块最大到 1，想要更明显只能重新导出。插件里把"眉 强度"调到 1.3–1.5，
  或者命令行加 `--face-strength EYEBROW=1.5`，见第 3、4 节。
- **没有的表情**：瞳小、ハイライト消し、照れ 要改贴图或者加网格，骨骼数据给不出来；
  あ２、ω、□、▲、口横狭め、单侧眉（下右 / 下左）也还没做。VMD 里用到这些名字的地方不会动。

## 3. Blender 插件 FF7 Face Morphs

用来给 FF7 Remake 模型生成表情、调强度、导出带表情的 PMX。批量导出脚本用的就是插件里的同一份代码，
所以手动和批量结果一样。

### 3.1 启用

- 插件已经以目录联接装进 Blender 3.6，只差勾选：编辑 → 偏好设置 → 插件，搜 `FF7 Face Morphs`，勾上。
- 面板位置：3D 视图按 N 打开侧栏 → **MMD** 标签页 → FF7 Face Morphs。
- 需要 mmd_tools；"导出带表情的 PMX"还需要 Convert_to_MMD5 和 mmd_cloth_physics。这几个本机都已经装好。
- 换一台电脑装：见插件的 [README](../scripts/blender_addons/ff7_face_morphs/README.md)。

### 3.2 面板

### 3.3 常用流程

**A. 一键导出带表情的 PMX（最常用）**

1. 打开**源 .blend**：`E:\game_export\FF7Remake\Tifa\blend\<模型>\<模型>.blend`。
   必须是带脸部骨骼（`C_FaceBase_a`）的原始 blend；`_converted.blend` 和 PMX 里脸部骨骼已经合并掉了，不能用。
2. 选中模型的骨架或身体网格。
3. 点 🔍，再点"分析模型"，应该显示"可生成 43 个表情"。
4. 选类别和强度（默认全开、1.0）。
5. 填导出区。GANTZ 紧身衣勾"裙骨皮肤跟大腿"；要预览图就勾"渲染预览图"。
6. 点"导出带表情的 PMX"，等 1–2 分钟。
7. 面板显示"完成：N 个表情，撕裂 0，付与错误 0"和 PMX 路径后，点"打开文件夹"。

注意：

- 不用先点"生成表情"。导出时后台会按面板上的类别和强度重新生成；当前文件里之前生成过的表情会先清掉，
  所以 PMX 里只有面板上勾选的那些。
- 文件有没保存的修改时，会先存一个临时副本给后台用，导出完自动删掉。
- **`<输出文件夹>\<文件名>\` 会被整个替换。**不要把输出指向原版 PMX 的文件夹，除非就是要替换它。
- 一次只能跑一个导出。导出进行中按钮是灰的。

**B. 只在 Blender 里看效果、调强度**

1. "生成表情"，然后在"预览"里选表情、拖权重。
2. 不满意就调强度，再点"生成表情"，同名的会重新生成。满意后按流程 A 导出，强度会带过去。
3. "清除"只删插件生成的形态键。

注意：**不要把生成了表情的源 .blend 直接保存覆盖**。Convert_to_MMD5 摆 A 字姿势、对齐手臂和手指时，
会跳过带形态键的网格；FF7 模型全身是一个网格，以后不带表情数据批量导出时，手臂就不会被转成 A 字姿势。
要保留就"另存为"，或者保存前先点"清除"。带表情数据导出时没有这个问题（见流程 A 的注意第一条）。

**C. 自己用 Convert_to_MMD5 转换**

顺序是固定的：

1. 生成表情；
2. 展开"手动转换"，点"**转换前暂存**"。形态键会移到 .blend 里一个隐藏的网格副本 `FF7FaceMorphs_stash_<物体名>`，
   保存再打开也不会丢；
3. 用 Convert_to_MMD5 转换；
4. 点"**恢复并登记**"。形态键放回模型：模型在转换中被转了方向或缩放成米，会自动换算；脸如果被变形了，
   会放弃恢复并报错。同时把表情登记到 mmd_tools 模型的 目 / 眉 / 口 / その他，重建"表情"显示框；
5. 用 mmd_tools 导出 PMX（Scale 12.5）。

## 4. 命令行

```powershell
# 带表情转 PMX（和面板的导出按钮是同一个脚本）
blender -b <模型>.blend --python scripts/final/export_ff7_pmx_blender.py -- --out <输出文件夹> --name <文件名> `
    --model-name "<MMD 里的名字>" --skirt-to-legs `
    --face-data E:\game_export\FF7Remake\_meta\face\PC0002_Tifa.json `
    --face-categories EYE,EYEBROW,MOUTH,OTHER --face-strength EYEBROW=1.5

# 只看效果：在 .blend 上生成表情，逐个渲染脸部特写（不改原文件）
blender -b <模型>.blend --python scripts/final/ff7_face_morph_sheet.py -- --face-data <json> --out <文件夹>

# 从游戏重新提取 Tifa 的表情数据（约 20 秒，只读游戏；AES key 从 FF7REMAKE_AES_KEY 或 --key-file 读）
python scripts/final/ff7_face_data.py --out E:\game_export\FF7Remake\_meta\face\PC0002_Tifa.json
```

- `--face-categories` 和 `--face-strength` 可以不写，默认全部四类、强度 1.0。
- `--face-strength` 可以写多次，比如 `--face-strength EYEBROW=1.5 --face-strength MOUTH=0.8`。
- 批量脚本 `ff7_mod_pmx_batch.py` 目前还不能传表情参数。

## 5. 常见问题

| 现象 | 原因 / 办法 |
|---|---|
| 侧栏里找不到 FF7 Face Morphs | 插件没勾选；或者侧栏不在 **MMD** 标签页 |
| 面板提示"选中 FF7 模型的骨架或网格" | 当前没选中模型，点一下骨架或身体 |
| 报错 `no FF7 face rig here (C_FaceBase_a / L_Eye / R_Eye)` | 打开的是 `_converted.blend` 或导入的 PMX；要打开源 .blend |
| 报错 `no face data` | 找不到表情数据：先运行 `ff7_face_data.py`，或者手动选 json。目前只有 Tifa（PC0002）有数据 |
| "导出带表情的 PMX"是灰的 | 已经有一个导出在跑；或者插件不是从仓库联接安装的（面板会提示找不到 `export_ff7_pmx_blender.py`） |
| 面板显示"导出失败，见日志" | 日志在 `%TEMP%\ff7_face_pmx_<时间>.log`，看最后几十行 |
| MMD 里某个表情不动 | VMD 用的名字模型里没有（见 2.3），或者 VMD 读到了别的模型上（先选中这个模型再读） |
| 眉毛几乎看不出来 | 眉 强度 1.3–1.5 重新导出 |
| 眼皮闭过头、穿出下眼皮 | 笑い 和 まばたき 同时拉满了，见 2.5 |

## 6. 限制

- 只有 Tifa 的数据：`PC0002_Tifa` 的表情姿势 + `Tifa_Default` 口型。别的角色要先用各自的 `Facial00` 和 `LipMap`
  生成数据；Rebirth 还没看。
- 游戏里还有几个姿势没用上：单侧挑眉 `F_Brow_up_left01` / `F_Brow_up_right01`，眼皮 `F_Eyelid_up01` /
  `F_Eyelid_left01` / `F_Eyelid_right01`。
- 只在 Blender 里验证过（mmd_tools 读回、VMD 驱动渲染），还没在 MMD 本体里打开过。
