# 服装移植：把一套衣服的裙子装到另一套上（PMX）

工具：
- `scripts/mmd_physics/pmx_graft.py`：搬衣服，10-18 新增，10-24 加 `--hang-offset`。
- 之后照常修碰撞：
  - `pmx_skirt_fix.py`
  - `cloth_collision_pmx.py`：10-24 加 `--half-overlap`
- full 版的胸部：
  - `pmx_body_follows_cups.py`
  - `pmx_body_cover_cups.py`：10-24 补了「胸带折角下」的点，并加了 `--garment`，可以处理任意一件衣服下面的身体
- 量具：
  - `skin_clip_blender.py`：腿
  - `chest_clip_blender.py`：胸，10-24 会列出最常顶出的顶点

用户 10-18 的要求：「g05的裙子能加到a08上么，做个full 的版本，同样也做个 a08的裙子给到a05的，也是full，裙子碰撞，同口径修正的 pmx」。成品在 `E:\game_export\RiseOfEros\_混搭\`，见那里的 `说明.md`（这两个是误读了要求做的，2026-10-31 放进了回收站）。

## 搬什么、怎么搬

```powershell
python pmx_graft.py 源.pmx 目标.pmx 输出.pmx --bones "^Riband_M" --material-name g05_skirt [--hang-offset 0,0,-0.2]
```

- **骨骼**：源模型里名字匹配 `--bones` 的骨骼，加上它们往上直到目标也有的那根骨骼之间的骨骼（比如 `Riband_M_Dummy`）。接在目标的同名骨骼下，放在目标骨骼列表的最后。
- **网格**：每个源材质里，含有「这些骨骼上权重 ≥ 0.3 的顶点」的整个连通块。每个源材质变成一个新材质，贴图实拷贝进输出文件夹的 `textures\`，目标自己的贴图也一样。
- **位置**：按两边的 `下半身` 骨对齐，`--offset` 可以再整体挪一点。
- **物理**：这些骨骼上的刚体和关节一起搬。一头挂在别的骨骼上的关节，改挂到目标同名骨骼的刚体上。
- **表情**：新材质加进目标的 `衣服非表示_材質`，full 版脱衣服时裙子一起隐藏。

## 四个坑（10-24）

### 1. 两个模型的身材不一样：只按下半身对齐不够

a08 的大腿和小腹比 g05 往前约 2 cm（相对下半身骨）。g05 的前片按 g05 的位置搬过来：
- 顶端埋进 a08 的胯部，静止时就有点在身体里；
- 离大腿的余量比在 g05 身上小，腿一并拢、一抬，前片就被夹进大腿。

另外，前片和 g05 小腹上那块布是同一块网格，279 个顶点，一直到胸骨，权重在 上半身 / 下半身 上。按「整个连通块」的规则它也被一起搬了过来，正好藏在 a08 的小腹里面。

`--hang-offset dx,dy,dz` 只挪挂在衣服骨骼上的部分：
- 骨骼、刚体、关节整段挪；
- 每个顶点按它在这些骨骼上的权重挪。前片整段挪，上沿权重 0.7 的地方挪 70%，小腹那块布权重 0，不动，继续藏在身体里。

a08 用 `0,0,-0.2`（往前 1.6 cm）：前片离大腿最近处 1.4 cm，g05 自己是 1.3 cm；小腹那块布 279 个点里只有 4 个露出不到 0.5 mm。

### 2. 大腿分两半的碰撞体，中间有个缺口

`cloth_collision_pmx.py --thigh-halves` 把大腿分成两半各量一个胶囊：上半挂 足，下半挂 足D。原来每个胶囊的圆头正好伸到大腿中点，两个圆头只在中点相碰，中点附近的覆盖半径接近 0。a08 大腿中段的皮肤露在两个碰撞体外面 2–3.5 cm，正好是前片第 2、3 节靠着的地方。

`--half-overlap`（默认 1.0）：两半都以满半径一直伸到中点，圆头再往外伸 1.0 × 半径。

| 重叠量 | 大腿中段前内侧露在碰撞体外（a08，平均） | 碰撞体戳出裸体皮肤的点（> 6.4 mm） |
|---|---|---|
| 0（以前） | 2.0–2.3 cm | 0 |
| 1.0 | 0.3–0.6 cm | 0 |
| 1.5 | 0.2–0.6 cm | 10 |
| 2.0 | 0.05–0.3 cm | 23 |

`--half-overlap 0` 和以前的输出逐字节相同：a08 full 的拟合结果和 10-18 那份 md5 一致。默认 1.0 不戳出皮肤；a08 + g05 前片用的是 1.5，量出来更好。

### 3. 穿长裤的模型：腿的碰撞体按裤子量

a05 穿黑色长裤，a08 的裙子碰到的是裤子，不是腿：
- 碰撞体按裸腿量时，裙子能陷进裤子：每帧 0.8 → 4.3 个顶点（10-18 的试做）。
- 现在 足 / 足D / ひざ 按长裤量（`--skin "pc_a05_hd_body,..."`），其余按裸体量，用 `collider_mix` 合起来。结果是 1.3 / 0.9。
- a05 原来的碰撞体是导出时按穿衣网格量的，比长裤还胖：小腿那根的半径比贴着裤子量的大 2.4 cm，胯大 1 cm；有 331 个裤子顶点在小腿碰撞体里面超过 6.4 mm。所以直接搬过来时数字也很低（0.8），但那是靠把裙子撑开、远离裤子做到的。

### 4. full 版：长裤下面的身体从裤子里顶出来（a05 原档就有）

a05 + a08 裙子的对比视频里，两排都看得到黑色长裤上一块块的皮肤。a05 full 原档也一样，腿一弯就有，原因和 g05 full 胸部那次相同：
- 衣服下那份身体用的是裸体底模的权重（ThighTwist 骨）；
- 长裤用的是游戏的权重，主要挂在游戏的大腿辅助骨 `Bip001 Xtra02` / `Xtra04` 上。
- 两者转得不一样，身体就顶出来。手势舞里平均每帧 205 个顶点，最深 1.7 cm。外套袖子里也一样，每帧 209 个，最深 4.1 cm。

`pmx_body_cover_cups.py --garment pc_a05_hd_body --depth 2`：
- 整件衣服（长裤和外套）正下方 2 cm 以内的身体照抄衣服的权重，和胸带那步是同一个办法；
- 挂在物理骨上的部分（会摆的胸、衣摆）不抄，不然身体会跟着布料飘走；
- 一开始只按 MMD 的腿骨（`--bones "足|ひざ|..."`）挑长裤，漏了挂在 Xtra02/04 上的大腿那一块，所以改成按材质整件挑。

结果：
- 长裤 205 → 8.0（最深 6.8 mm）；
- 外套 209 → 48，剩下的在两个手肘里面，静止时就埋在袖子下 0.7–1.6 cm，手肘弯到底时线性蒙皮把这段偏移转了出来；
- 胸部仍是 0。

量具 `chest_clip_blender.py --bones REGEX --radius 3` 量任意一块衣服。

## 前片本身的两处调整（只用在 a08 + g05 上）

g05 前片的关节很硬，每节前后摆只有 ±5°–8°，最上面一节 ±5°。大腿一高抬，前片上部让不开，只能被穿过去：
- 上面三节放宽到 ±25° / ±20° / ±15°：手势舞每帧 46.3 → 41.5，八方来才 60.2 → 46.0；
- 碰撞盒厚度一半从 0.14 加到 0.20，全厚 2.2 → 3.2 cm：41.8 / 49.7；
- 两样都做：37.2 / 39.6。

脚本在 scratch（`panel_tune.py`），没进仓库。这是这条前片挂在别人身上时的特调，不是通用规则。

## 胸带折角下的点（`pmx_body_cover_cups.py`，10-24）

原来只处理「投影落在某个胸带三角形里」的身体顶点。a08 左胸有一个点在胸带折角下面，深 3.3 mm：
- 两边三角形往外折，投影哪个三角形都落不进去，权重没改；
- 手势舞里一半的帧顶出来，最深 2.7 mm。

现在投影落空时，改用胸带表面上最近的那个点。条件和量具配对一致：偏移主要沿法线（≥ 0.7），在胸带后面，不超过 `--depth`。a08 多处理了 88 个点，那个点最深降到 1.0 mm。
