# 模型细节：眼睛发亮有神（2026-11-15）

「模型细节」插件（`scripts/blender_addons/model_details`，侧栏「细节」）的第一项。核心在 `eyes.py`。

## 来由

- 2026-11-14 用户："换上原始材质这个按钮后，眼睛太暗淡了，做个专门的把眼仁变得发亮有神的按钮"。
  第一版做进了「ROE 游戏材质」插件。
- 2026-11-15 用户："单独做个插件处理这些细节么，先把眼睛这个加上，后续再加其他功能，让 ROE，剑星，Vindictus 的眼睛能变得发亮"。
  于是改成独立插件、三个游戏通用。第一版没提交，撤掉了，ROE 游戏材质回到 0.1.1。

## 三个游戏的眼睛

| | ROE | 剑星 | Vindictus |
|---|---|---|---|
| PMX 里的眼睛材质 | `eye_portable` | `MI_EyeRefractive1` | `4_Face-MI-Fiona-Face01-EyeBall_0.1_0_0` |
| 贴图 | 平涂浅色眼白，大红虹膜（烘焙） | 黑底，带血丝的眼白圆盘，小虹膜大瞳孔 | MetaHuman 式：外圈偏红，亮眼白环，黄绿虹膜，大瞳孔 |
| 测出的虹膜半径（UV） | 0.26，瞳孔 0.04 | 0.10，瞳孔 0.05 | 0.19，瞳孔 0.06 |
| 每只眼球的面数 | 432 | 1536 | 1536 |
| 游戏材质插件 | 「ROE 游戏材质」不动眼睛；ROE 插件 2.6 用 `hq_` 网络 | 「剑星游戏材质」用 `sbhq_` 网络 | 「Vindictus 游戏材质」用 `vhq_` 网络 |

- 三个游戏材质插件都是在材质里**另加一个输出节点**，靠切换"哪个输出激活"在 MMD 着色和游戏材质之间切。
  它们各自认"自己的输出"的方法是：第一个**不带**自己前缀的输出节点。
- 所以这里不能再加输出节点，节点名也不能用它们的前缀。本插件的节点名用 `mdx_eye_` 开头。
- 剑星的 PMX 另有一个 `EyeLight_Inst`（游戏自己的眼神光贴片，PMX 里透明度 0），和眼睛贴图上的 sphere 高光。

## 做法

**叠加，不替换**：对眼睛材质里每个连着东西的输出节点，把它原来的输入改走：

`原来的着色` → `混合（Fresnel IOR 1.376 × 2·湿润）光泽 BSDF 粗糙度 0.03` → `相加 发光` → 输出

- 不管当前哪个输出是激活的，效果都在；游戏插件切换 MMD / 游戏时也一样。
- 游戏插件重建了自己的网络（新的输出直接接它的着色器），`stale()` 能看出来，面板提示再点一次。
- 「去掉」时，每个输出都接回"现在喂给我们那层混合的东西"。所以游戏插件先删了自己的网络，也不会留下断开的输出。

**发光的颜色**：用眼睛自己的烘焙贴图（PMX 导出时就是从游戏眼睛烘出来的），饱和度 ×「虹膜鲜艳」。
- 整个虹膜（0.82r 到 0.97r 渐弱）×「虹膜发光」；
- 下半圈（比中心高 0.08r 开始，到低 0.7r 时满）×「下半透光」。光从上方穿过角膜、照亮虹膜下缘，是常用的"有神"画法；
- 瞳孔（瞳孔半径起，再往外 0.15r 渐入）不加。

**眼神光**：虹膜上的两个圆。
- 大的离中心 0.36r、半径 0.13r，在屏幕上「眼神光方向」那边（默认 145°）；小的在对面，0.34r，半径减半，亮度 0.45 倍。
- 屏幕方向换算成 UV 方向：用常量切线空间法线贴图取出 UV 的世界切线 / 副切线，转到相机空间，只留 x / y，归一化。
- 结果：
  - 两只眼睛在同一边；
  - 转镜头也保持在屏幕那一侧；
  - 眼睛转动时跟着虹膜走；
  - 眨眼时被眼皮盖住。
- 默认值是按三个游戏一起定的：在 125° / 0.45r / 0.15r 时，Vindictus 上眼皮比较低（盖住虹膜 0.36r 以上），主光点有一半被盖住。

**认虹膜**（`measure_iris`，贴图缩到 256 px）：
1. 中间 0.2 范围里，亮度小于 0.06 的像素的重心 = 瞳孔中心。
   阈值 0.12 时，ROE 偏暗的虹膜上半部也被算进来，中心往上偏了 0.06。
2. 从瞳孔中心算径向亮度剖面：
   - 0.04 到 0.45 里最亮的一圈是眼白；
   - 从中心开始亮度低于 0.12 的是瞳孔；
   - 往外第一圈亮度超过（虹膜中位亮度 + 眼白）/ 2 的地方是虹膜边。
3. 虹膜圆盘的重心（ROE 的瞳孔比虹膜中心高 0.011）。再按它算一次剖面，得到最终的虹膜半径。瞳孔半径加上两个中心的偏差。
4. 只用整张贴图里"暗于一半"的像素求重心不行：剑星眼白往边上越来越暗，重心被拖偏 0.1。
5. 检查：眼白比虹膜亮 0.15 以上，虹膜半径 0.04–0.45，瞳孔小于 0.8 倍虹膜半径；不满足就当它不是眼睛（剑星的 EyeLight、眉毛都被正确排除）。

## 试过又放弃的（第一版，在 ROE 上）

1. **按物理算一盏跟着相机的灯的反射**，用网格的着色法线：
   - ROE 的眼球很粗，虹膜里只有 73 个顶点，角膜凸起（法线倾角正弦 ≈ r(4.228 − 12.10r + 15.51r²)），圆是锯齿形，还贴着瞳孔。
   - 着色器里的相机空间 **+Z 朝场景里**（Cycles、EEVEE 一样），朝相机是 -Z，第一次方向就写反了。
2. **用 UV 重建平滑法线再找反射点**：常量法线贴图取出的 T、B 是当前像素表面的切线，跟着表面倾斜。
   所以 H·T 是 H 相对这一点法线的偏角，不是相对眼睛的轴。用 EXR 把 L / V / N / T / B / H 读出来才看清。
   骨骼动画下着色器里拿不到可靠的眼睛轴，就改成固定在虹膜上的眼神光。
3. **替换眼睛着色**（第一版的做法）：ROE 可以，但剑星、Vindictus 的游戏眼睛本身就是游戏插件的网络，替换掉会丢掉游戏效果。改成叠加。
4. **底层高光太强**（Specular 0.5，粗糙度 0.35）：正面的聚光灯把瞳孔照成一团灰白。现在原来的着色不动，角膜反光只按 Fresnel 混一点。

## 验证（后台 Blender 3.6，`--factory-startup`，scratch `eyes\test_details.py`）

- 三个游戏各走一遍：
  - MMD 着色加效果；
  - 滑块改到节点；
  - 「去掉」把输出接回原样；
  - 换游戏眼睛（ROE 用 2.6，剑星、Vindictus 用各自的游戏材质插件）后能看出需要再点一次；
  - 再点一次后两个输出都包上；
  - 游戏插件切到 MMD 时效果还在；
  - 游戏插件删掉自己的网络后输出仍然有效；
  - 最后「去掉」干净。
- 三个游戏全部通过。
- 渲染：
  - Cycles，用户 ROE 场景同样的灯（正面聚光、0.05 灰的世界、Filmic），剑星和 Vindictus 按模型大小换算；
  - EEVEE 抽查 ROE，和 Cycles 一致；
  - 对比图在三个模型的 PMX 文件夹里：`插件效果_眼睛发亮有神对比.jpg`。
- 面板按钮、属性名检查。

## 以后可以加的细节（待用户挑）
