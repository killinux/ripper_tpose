# ROE 材质手动修复指南

本页用于自动识别仍有偏差时，在 Blender 3.6 的 **ROE** 面板中修复单个材质槽或
头部局部面。适用于白色身体、身体图集错位、眼镜状透明片、脸/眼睛/睫毛/眉毛分错等
问题。操作会保留顶点、UV、骨架、权重和原始面分区。

## 1. 先判断是哪一类问题

| 现象 | 优先检查 | 修复入口 |
|---|---|---|
| 整个身体或一件衣服是白色 | 当前槽是否有 Image Texture、贴图目录是否完整 | 当前材质槽的用途/贴图覆盖 |
| 身体有图，但花纹或肤色落在错误区域 | 是否把 `body1/body2` 图集挂反，原 FBX 是否保留多槽 | 当前材质槽的贴图覆盖 |
| 眼睛附近出现眼镜片、灰片或泪膜 | 该槽是否为 `tear/tears/overlay` 透明罩 | 当前槽设为“透明罩/隐藏” |
| 脸、虹膜、睫毛或眉毛的局部颜色错误 | 错误是否只发生在头部的一小片连续面 | 编辑模式人工标记头部面 |
| 整个脸或头发为白色 | `_textures` 是否缺少体型公共贴图 | 补齐/重新提取贴图后重新准备材质 |

开始前先在 3D 视口按 `N`，打开 **ROE** 页签：

1. 工作流选择 **ROE 增强**；处理范围通常选择 **最新导入**。
2. “模型来源”选择保留完整材质槽的 HD FBX。
3. “ROE 贴图目录”选择 `D:\roe_exports\<角色>\_textures\`。
4. 点击 **检查模型**，再点击 **检查并准备材质**。
5. 如果“最近检查”仍显示“缺贴图”，先补齐贴图，不要用改 UV 或权重来掩盖问题。

## 2. 手动修复身体或衣服材质槽

适合白身、衣服白色、`body1/body2` 图集挂反等问题。

1. 回到 **Object Mode**，在视口或 Outliner 选中身体网格。
2. 打开右侧 **Material Properties**，在材质槽列表中逐个选择可疑槽。可进入
   Edit Mode 后点 **Select**，确认该槽实际控制身体的哪一片面，再回 Object Mode。
3. 在 `N > ROE` 勾开 **高级材质调整**。
4. “当前槽用途”选择：
   - **皮肤**：裸露皮肤，需要皮肤降饱和；
   - **身体/衣服**：服装或普通身体图集；
   - **脸**、**头发**：仅在当前整个槽确实属于这些用途时选择。
5. 在“当前槽贴图覆盖”中选择正确的 `*_Albedo.png`。如果自动贴图已经正确，可留空，
   只保存用途。
6. 点击 **保存当前槽覆盖**。
7. 对其他错误槽重复以上步骤，然后再点击 **检查并准备材质**。覆盖会优先于自动判断，
   但不会改变槽中面的归属。
8. 要恢复自动判断，选中该槽后点击 **清除当前槽覆盖**，再重新准备材质。

g07 的正确身体映射如下：

| 原始材质槽 | 正确颜色贴图 | 面数 |
|---|---|---:|
| `pc_g07_hd_skin` | `pc_g07_body1_rgbx_Albedo.png` | 14312 |
| `pc_g07_hd_body1` | `pc_g07_body1_rgbx_Albedo.png` | 7034 |
| `pc_g07_hd_body2` | `pc_g07_body2_rgbx_Albedo.png` | 24219 |

v1.1.7 已自动兼容这组命名：槽名中有 `_hd_`，贴图文件名却省略 `_hd_`。标准精确
命名仍优先，只有精确匹配失败时才尝试省略一次 `_hd_` 或 `_ld_`。

## 3. 手动隐藏眼镜状透明罩

b02 左眼附近的“眼镜片”并不是眼镜配件，而是游戏运行时使用的
`pc_b_nk_tears` 透明卡片。类似的 tear、泪膜或眼部罩层不应删除几何：

1. 在 **Object Mode** 选中包含异常片的网格。
2. 在 **Material Properties** 中逐槽选择；进入 Edit Mode 使用材质槽的
   **Select** 可确认该槽控制的是异常片。
3. 回到 Object Mode，展开 `N > ROE > 高级材质调整`。
4. 把“当前槽用途”设为 **透明罩/隐藏**。
5. 点击 **保存当前槽覆盖**，再点 **检查并准备材质**。

插件会为这个槽建立纯 `Transparent BSDF`，ROE XPS 导出时也会跳过该透明槽。
这样既不破坏模型拓扑和权重，也不会在导出后重新出现。要撤销时点击
**清除当前槽覆盖**。

## 4. 手动修复头部局部面

适合自动规则把一小片脸、虹膜、上/下睫毛、眉毛或眼部罩层分错的情况：

1. 选中 head 网格，按 `Tab` 进入 **Edit Mode**，切到面选择模式（键盘 `3`，不是
   小键盘 3）。
2. 取消全选，再选中错误区域。对于独立睫毛片、眉毛片或眼部罩，可把鼠标移到该片上
   按 `L` 选择相连面；提交前旋转视角确认没有连带选中脸。
3. 展开 `N > ROE > 高级材质调整`。
4. 在“所选头部面指定为”选择 **脸 / 眼球 / 睫毛 / 眉毛 / 透明罩**。
5. 点击 **标记所选头部面**。
6. 回到 Object Mode，再点击 **检查并准备材质**。

人工标记存储在网格的逐面整数属性中，后续重新准备材质时会覆盖自动分类。要清除某块
人工标记，重新选中这些面，选择 **自动**，再点击 **标记所选头部面**。

“修复眼睛”按钮只重新识别眼球及误入眼球槽的面，适合 a08 一类白眼问题；它不会
代替身体槽、透明罩或眉睫局部的手动覆盖。

## 5. 为什么优先使用 ROE 覆盖

直接在 Shader Editor 中改节点可以临时预览：

- 普通身体/脸：Image Texture 的 Color 接 Principled BSDF 的 Base Color；
- 需要贴图透明度的头发/眉睫：Alpha 同时接 Principled BSDF 的 Alpha；
- 完全隐藏的罩层：Transparent BSDF 直接接 Material Output。

但下一次点击“检查并准备材质”会按规则重建节点，临时节点修改可能被覆盖。ROE 的
“当前槽覆盖”和“头部面人工分类”会随 `.blend` 保存并在重建时再次应用，因此更适合
稳定修复和回归测试。

## 6. 保存与验证

1. 在 Material Preview 下从正面、侧面和近距离检查身体、眼睛和头部。
2. 再点一次 **检查模型**；“缺贴图”应为 `0`。
3. 保存 `.blend`，否则当前场景的材质节点、槽覆盖和逐面分类不会持久化。
4. 导出 XPS 后，把 `.mesh` 和插件复制的 PNG 保持在同一目录，再导回抽查一次。
