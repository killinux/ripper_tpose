附录 · 导出脚本用法

脚本在 scripts\final\，需在装有游戏的机器上运行，并且要有 pak 的 AES key （只放本机环境变量，仓库里没有）。完整说明见 docs\final-fantasy-vii-remake-extraction.md。

两段流程

步骤脚本做什么
① 提取ff7remake_export.ps1UE Viewer（umodel）按包路径解 pak：PSKX 网格 + PNG 贴图 + .mat；自动隔离 ~mods
② 材质化validate_ff7remake_model.py（Blender 3.6 无头）导入 PSKX，按 .mat 接 Diffuse/Normal/Alpha，渲预览，写报告 JSON
批量export_ff7remake_models.ps1按 docs\ff7remake-player-model-files.txt（36 个 Player 包）把①②串起来
cd E:\code\othercode\ripper_tpose\scripts\final
$env:FF7REMAKE_AES_KEY = '<key>'
.\export_ff7remake_models.ps1                 # 全部 36 个包
.\export_ff7remake_models.ps1 -Only PC0002     # 只要 Tifa 系
.\export_ff7remake_models.ps1 -SkipExtract -Force   # 只重做材质化
Remove-Item Env:FF7REMAKE_AES_KEY

产物 _blends\<包目录名>.blend（贴图外链到 GameContents\，不打包）、 _preview.png、.json 报告。

症状原因 / 处理
