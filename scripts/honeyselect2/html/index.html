脚本在 〈仓库〉\scripts\honeyselect2\，只需 Python 3（pip install UnityPy Pillow numpy）+ Blender 3.6 （默认 D:\Program Files\blender-3.6.15-windows-x64\blender.exe）。游戏默认 E:\SteamLibrary\steamapps\common\HoneySelect2Libido DX（--game / HS2_ROOT），产物默认 D:\hs2_exports。

cd 〈仓库〉\scripts\honeyselect2
python list_models.py                         # 底模、31 类 812 件物品、角色卡
python list_models.py --html                  # 带游戏缩略图的全部物品列表 D:\hs2_exports\_list\index.html
python export_model.py --card HS2_ill_F_000   # 角色卡穿好；--nude 去掉衣服和饰品
python export_model.py --all-cards [--nude]
python export_model.py --body female|male
python export_model.py --item fo_top:28 [--with-body]
python export_model.py --all-items --group hair   # 批量；--fbx 另出 FBX
python html\make_gallery.py                   # 重新生成本页

bodies\body_female|male\裸底模 + 默认脸
items\<list key>\<key>_<id>_<prefab>[_with_body]\单件：自带骨骼，或穿在默认底模上
每个目录<名>.blend（贴图已打包）、_preview / _side / _face.png、scene.json、parts\、textures\、build.log
