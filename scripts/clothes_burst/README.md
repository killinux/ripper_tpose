# 爆衣：先给衣服底下放进完整身体（别的游戏的模型）

爆衣插件（`scripts/blender_addons/clothes_burst`，「MMD 表情」那种）把衣服炸成碎片，露出来的是**衣服底下本来就有的身体**。
ROE 的 full 版衣服底下有完整身体，直接能炸。很多游戏的成套模型却只有露在外面的那几块皮肤：Vindictus 的 Fiona 盔甲底下
只有肩膀和大腿，躯干是空的；直接炸会露出一个空壳。

这里的两个工具先把一份完整的裸体放进 PMX，做成和 ROE full 版一样的结构：
- 裸体在文件里透明；
- 「衣服非表示」一拉，衣服藏起、裸体换上来；
- 然后照常用 `scripts/riseoferos/burst_pmx_blender.py`（或插件面板）生成爆衣。

| 工具 | 什么时候用 |
|---|---|
| `pmx_nude_switch.py` | 裸体已经在 PMX 里（导出前放进去的），只加开关 |
| `pmx_add_nude.py` | 裸体在另一个 PMX 里，骨架可以不一样：先摆到衣服模型的姿势，再放进来、加开关 |
| `pmx_twist_axes.py` | 把 腕捩 / 手捩 的固定轴摆回手臂方向（Convert_to_MMD5 导出时前后分量的正负号反了，见「再整理物理和捩骨」） |
| `pmx_place_prop.py` | 把武器这类道具（几个材质 + 挂它们的骨骼）整块挪到别处、转个角度，比如插在身边的地上（见「武器挪到旁边」） |

都只要 Python 和 mmd_tools 自带的 PMX 读写模块（不用 Blender）。

## 开关是什么（两个工具一样）

- 裸体的材质：文件里透明度 0（边线也是），穿着衣服时看不见。
- `衣服非表示_材質`（材质表情）：衣服的透明度 ×0。
- `裸体形状`（材质表情）：衣服模型自己的那几块皮肤（`--skin`）×0，裸体的透明度加回来。换整个身体，原来的皮肤和裸体不会
  叠在一起闪。
- `衣服非表示`（组表情）：上面两个一起，一个滑块脱掉。三个都放进「表情」显示框。

MMD 里拉「衣服非表示」就能脱；爆衣插件看到这个结构（`裸体形状` 是有加算条目的材质表情）就只加碎片，身体不再换。

## `pmx_nude_switch.py`：裸体已经在里面

```
python pmx_nude_switch.py <in.pmx> --outfit <材质> --nude <材质> [--skin <材质>] [--out <pmx>]
```

材质名用逗号分开，可以用通配符（`MI_P_EVE_09_Metal*`），每一项都要对上至少一个材质。默认写在输入旁边
（`<名字>_switch.pmx`）；`--out` 写到别的文件夹时，用到的贴图一起拷过去（不同盘的路径会被写成绝对路径）。

**例子：剑星 Eve（09 号潜水服）**。剑星的裸模来自 EveOriginalProportions Mod，它本来就是替换衣服底下那层身体的，
骨架和服装一样（两边共有的骨头最多差 1.3 mm，只是头发骨），服装自带的那块皮肤离裸体表面中位数 1.65 mm。
1. 在 Blender 里把裸体网格放进服装的 .blend，挂到同一副骨架上，命名为 `Eve_Body_Mesh_02`。mmd_tools 按物体名字排网格，
   这样它的材质就排在服装后面、头发前面：MMD 按材质顺序画，半透明的头发要在不透明的身体之后画。
2. `scripts/stellarblade/export_pmx_blender.py` 照常导出。两个身体走同一套转换，胸部物理也一起算。
3. 加开关：
   ```
   python pmx_nude_switch.py Eve_CH_P_EVE_09_full.pmx --outfit "MI_CH_P_EVE_09_Suit,MI_P_EVE_09_Metal*,MA_Plastic_2_Inst,MI_P_EVE_09_lace" --skin MI_P_EVE_09_Skin --nude SkinEve --out <文件夹>\Eve_CH_P_EVE_09_full.pmx
   ```

## `pmx_add_nude.py`：裸体在另一个 PMX 里

```
python pmx_add_nude.py <穿衣.pmx> <裸体.pmx> --take <裸体的材质> --outfit <材质> [--skin <材质>]
                       [--snap <裸体材质>[=<穿衣材质>]] [--map <裸体骨>=<穿衣骨>,...] [--after <穿衣材质>] [--out <pmx>]
                       [--weights-from <同骨架的服装.pmx> --weights-mats <它的皮肤材质> ...（可以重复，几套一起用）
                        [--weights-cm 1.5,3.0[,1.5]] [--weights-bones <正则>] [--weights-keep breast|胸|bust]]
                       [--sdef-joints 左ひじ,右ひじ] [--finger-cm 2.5] [--normals surface|bones]
```

默认写成 `<穿衣>_full.pmx`。做的事：

1. **骨头按名字对**（两边都是 MMD 标准名）。裸体独有的骨头（Fiona_BaseBody 的 `Bip001_*` 肌肉、扭转辅助骨）算作它在
   穿衣骨架里最近的上级。`--map` 把指定骨头的权重挪到别处，比如裸体的胸骨挪到穿衣模型带物理的胸骨上，脱了胸部照样晃。
2. **把裸体摆到穿衣骨架的姿势**（正向运动学）：
   - 从根往下，每根骨头只转不扭，让它从自己的关节指向下一个关节的方向和穿衣骨架一样；关节跟着上一级走。
   - 「下一个关节」按 MMD 标准骨的固定对应表定（上半身→首、腕→ひじ、足D→ひざD、指１→指２……）。
   - 根部骨头不转：センター、グルーブ、腰、下半身、腰キャンセル。
   - 裸体保留自己的骨长，所以身材不变。
   - 转超过 60° 的不转：这说明两副骨架对这根骨头的理解不同，不是姿势不同。
   - 骨长不同，摆完脖子会对不上（Fiona 差 5 cm）。这个差距平均分摊到两边都有的几节脊柱上，脖子正好落到穿衣骨架的关节上。
   - 四肢的根部再挪到穿衣骨架的关节上（手臂一半在锁骨、一半在上臂根，腿在足D）。两边四肢骨长一样，肘、腕、膝也就
     对上了。Fiona 的手臂原来差 2.7 cm，肘部绕着错的支点弯（见下面「手臂用游戏的权重」）。
   - 法线跟着摆好的表面转（`--normals surface`，默认），不只跟着骨头转。关节一挪，权重混合的地方（肩膀）网格会被
     拉斜，只跟骨头转的法线和表面差到 70°，举手时锁骨一带出现暗痕（见下面「举手时锁骨的折痕」）。
3. **`--snap` 贴合**：两边顶点一一对应的材质（同一个脸网格），头部那段直接贴到穿衣模型的脸上：
   - 每个顶点看它在头部以外的骨头（脖子、脊柱、锁骨）上的权重占比，在 0.05–0.95 之间平滑过渡，占比越高越保留摆好的位置；
   - 穿衣模型的眼睛、牙齿、睫毛、头发照样贴在脸上；
   - 穿衣模型的表情复制到这张脸上，所以穿衣模型的脸要放进 `--skin`，脱衣时换成这张。
4. **重新绑定**：
   - 权重换到穿衣骨架上，SDEF 改成 BDEF2；
   - 指节骨（`小指１` 这类 １–３ 号）上离骨头超过 `--finger-cm`（默认 2.5 cm）的权重去掉，剩下的重新归一
     （见下面「手腕翻边」）。掌骨（０ 号）本来就带一大片手掌，不动；
   - `--weights-from`：手臂换成游戏的权重，出了游戏皮肤的边缘（手腕）在 1.5 cm 内退回自己的；挂在胸部物理骨上的
     顶点保留自己的（`--weights-keep`）；肘部一圈做成 SDEF（`--sdef-joints`，默认左右 ひじ）。见下面；
   - 材质和贴图拷进来，放在 `--after` 后面（默认最后一个 `--skin` 后面）：不透明的身体排在睫毛、头发前面；
   - 和穿衣模型重名的材质加 `_nude`。
5. **加开关**（同上）。

**例子：Vindictus Fiona（默认盔甲 + Fiona_BaseBody）**。Fiona_BaseBody 是旧版 Bip001 骨架。和盔甲模型比：
- 大腿只差 0.7 cm；
- 脊柱、脖子位置差 6–9 cm，脸整体往前 6.1 cm（形状一样）；
- 手臂抬高约 10°，手指姿势不同。

```
python pmx_add_nude.py Fiona.pmx Fiona_BaseBody.pmx ^
  --take "4_BaseBody-MI-pc-female-body05_0.1_0_0,4_BaseBody-MI-pc-female-handfoot05_0.1_0_0,4_Face-MI-Fiona-Face01_0.1_0_0" ^
  --snap "4_Face-MI-Fiona-Face01_0.1_0_0" ^
  --outfit "4_Foot_0.1_0_0,4_Hand_0.1_0_0,4_Lower-PCF-005-Onepiece_0.1_0_0,4_Lower-T-pc-female-shiningwill*,4_Upper-T-pc-female-shiningwill*" ^
  --skin "4_Lower-MI-PCF-Lower01_0.1_0_0,4_Upper-MI-PCF-Upper01_0.1_0_0,4_Face-MI-Fiona-Face01_0.1_0_0" ^
  --map "左胸=breast_physics_02_l,右胸=breast_physics_02_r,Bip001_L_bust_1=breast_physics_02_l,Bip001_L_bust_2=breast_physics_02_l,Bip001_R_bust_1=breast_physics_02_r,Bip001_R_bust_2=breast_physics_02_r" ^
  --weights-from E:\game_export\Vindictus\Fiona\pmx\PCF_007\PCF_007.pmx --weights-mats "4_Onepiece-MI-PCF-Body01_0.1_0_0" --weights-cm 3.0,4.5 ^
  --out <文件夹>\Fiona_full.pmx
```

Fiona_BaseBody 自带的白色内衣壳（`5_BaseBody-inner`）不拿。

结果：
- 264 根骨头转过；
- 脖子差 4.96 cm，分摊后为 0；
- 脸摆好后离盔甲模型的脸中位数 1 cm，头部 5,824 个顶点贴上，脖子 1,330 个顶点过渡；
- 表情复制 123,664 条位移。

走过的弯路（`docs/clothes-burst-guide.md` 8.8）：
- 第一版按「离骨头尾端方向最近的子骨」选下一个关节。这些 PMX 的骨头尾端几乎都是偏移量，`下半身` 选到了髋关节；
  两副骨架的 `下半身` 高度差 6 cm，整个骨盆歪了 30°，两条腿往外撇。
- 第二版没分摊脖子的差距，5 cm 全压在脖子上。

### 手臂用游戏的权重（`--weights-from`，10-05 晚）

用户看了视频：「fiona的肘部还是有问题，看看游戏里有权重什么的么」。

- **原因**：Fiona_BaseBody 在游戏里是个静态网格（`SM_pc_fiona_basebody.pskx`），蒙皮权重是我们当初自己做的，PMX 里
  也没有 SDEF。肘部弯到 90° 以上时，外侧成了尖角、小臂根部塌陷。
- **游戏有的**：几套光胳膊的衣服（PCF_006、PCF_007）带一块身体皮肤 `MI_PCF_Body01`，在新骨架上，是游戏自己的权重。
  它们和盔甲模型的骨架从肩到手腕完全一样（差 0）；腿差 1–2 cm（鞋跟），手指姿势也不一样，所以只转手臂。
- **做法**：裸体手臂区域的顶点（默认肩、腕、ひじ、手捩这些骨头上的权重），在 PCF_007 的皮肤上找最近的表面点，
  用三角形的重心坐标插值那三个顶点的权重。3 cm 以内整份用，4.5 cm 以外不动，中间过渡。
  ```
  ... --weights-from E:\game_export\Vindictus\Fiona\pmx\PCF_007\PCF_007.pmx --weights-mats "4_Onepiece-MI-PCF-Body01_0.1_0_0" --weights-cm 3.0,4.5
  ```
  Fiona：手臂 3,688 个顶点，2,309 个整份换成游戏权重，649 个过渡；旧裸体手臂离游戏皮肤中位数 1.5 cm。
- **试过的**（同一段舞里肘部弯得最厉害的两帧，开着 SDEF 渲肘部特写，和 PCF_007 原版比）：

  | 做法 | 结果 |
  |---|---|
  | 抄最近顶点的权重和 SDEF 参数 | 肘部一道横向台阶：SDEF 的中心按游戏顶点算，抄到形状不同的网格上，相邻顶点不一致 |
  | 抄最近顶点的权重，SDEF 按 `pmx_sdef.py` 的规则重算（一个关节一个中心） | 还是台阶：最近顶点的权重一格一格跳 |
  | 表面插值的权重，加 SDEF | 权重平滑了，但「只挂两根骨头」的顶点零散分布，SDEF 和普通顶点交错，又出台阶 |
  | 表面插值的权重，不加 SDEF | 平滑一些，但内侧还有折线、外侧有尖 |

  **真正的原因**（用户：「你看看inase的模型效果，肘部还是不对」，拿 Inase 做标准）：摆完姿势后，裸体的整条手臂比盔甲
  骨架的关节靠前 2.7 cm（腿 0.7 cm）。权重绑的是盔甲的骨头，肘部绕着手臂后面 2.7 cm 的支点弯，怎么调权重都会折。
  `pose_transforms()` 加了四肢对准（`LIMB_ANCHORS`：手臂一半在锁骨、一半在上臂根，腿在足D），两边手臂骨长一样，
  肘、腕也跟着对上；裸体手臂离游戏皮肤从 1.5 cm 降到 0.17 cm。之后：
  - 游戏权重、不加 SDEF：平滑，和 Inase 一样；
  - **再加肘部 SDEF（`--sdef-joints` 默认 左ひじ,右ひじ）：平滑而且外侧圆，最接近 PCF_007 原版（采用）**。
    上面表里的台阶都是支点错位造成的。

- **渲染**：盔甲本身的肘部是 SDEF（导出时就有）。Blender 里 mmd_tools 要把 SDEF 驱动绑上、打开「自动运行 Python 脚本」
  才生效，`render_pmx_dance.py` 没绑，盔甲的肘部也会折。视频改用会话草稿 `dance_render_sdef.py` / `cloth_tear_dance.py`
  绑上 SDEF 渲染。MMD 本身总是会应用 SDEF。
- **胸部特写的镜头**：`render_pmx_dance.py` 按 `左胸` / `右胸` 找高度，Fiona 的胸骨叫 `breast_l` / `breast_r`，找不到就
  退到 `上半身3`，拍到了肚子。新脚本按这两种名字依次找。

### 手腕翻边：小指的错权重（`--finger-cm`，10-05 晚）

肘部修好后重渲的胸部特写里，手腕一弯（6.0 秒、8.6 秒，握拳）手背外侧就翻出一片皮肤，顺着前臂方向直直伸出去。

- **不是游戏权重造成的**：只对准四肢、用裸体自己权重的那版也有。
- **不是网格重叠**：身体网格在手腕关节前 1.6 cm 就结束了，和手的网格只重叠 0.6 cm。两张贴图都没有透明通道。
- **原因**：Fiona_BaseBody 的蒙皮（游戏里是静态网格，权重是当初我们自己做的）每只手有 40 个左右的手腕顶点挂在
  `小指１`（小指第一节）上，权重最高 0.71，离这根骨头 7 cm。握拳时小指一弯，这些顶点就跟着甩出去。
  游戏自己的皮肤（PCF_007）没有这种情况。两副骨架的手指链几乎一样（都有掌骨 ０），所以也不是骨头对错了名字。
- **修法**：`finger_strays()`：指节骨（１–３ 号）上，离骨头那一段（关节到下一个关节）超过 2.5 cm 的权重去掉，剩下的
  重新归一；一点不剩的给最近的非指节上级（这次没有）。Fiona 左 40、右 43 个顶点，都在 `小指１` 上。
  掌骨（０ 号）不算：手掌本来就离它那条线远，游戏的皮肤也一样（拇指掌骨：裸体中位数 1.5 cm，游戏 1.4 cm）。
- **对比**（手腕特写，舞蹈第 180、228、258 帧，左右手）：修之前手背翻出一片，修之后和 PCF_007 一样干净。
- 还剩手腕一圈颜色偏浅：手脚是另一张贴图（`T_pc_fiona_hand_foot02_D`），比身体偏黄，加上两块网格重叠 0.6 cm。只是颜色，动作没问题。

### 举手时锁骨的折痕：法线（`--normals surface`，10-06）

用户：「还有哪些可优化的，再检查一下」。这段舞用不到的极限姿势单独摆一遍（关掉 IK，绑上 SDEF，每个关节拍特写；
肘弯 135°、腕弯 ±70°、前臂扭 90°、举手、膝弯 120°、深蹲、侧抬腿、转头），和 PCF_007、Inase、Eve、白虎比。
别的都和参照差不多，只有**举手过头**时 Fiona 的锁骨到肩膀一线有几处皱痕，腋下顺着胸侧一道暗带（跳舞的胸部特写里
锁骨附近也隐约能看到）。

- **皱的是脸网格的围兜**：Fiona 的脸网格一直盖到肩膀（9 月 26 日修脖子时贴到了旧身体上），把它涂红就看出来，
  皱痕都在红色里。只对准四肢、用裸体自己权重的那版也有，所以不是游戏权重。
- **权重不是原因**：贴在身体上的围兜顶点（0.5 cm 以内）权重和身体只差 0.01–0.03；把围兜贴回身体表面、权重也换成
  身体的（试验），只好了一点；在新法线上再贴一次，围兜下边缘反而出了一道台阶，没采用。
- **原因是法线**：原版 Fiona_BaseBody 里，存的法线和网格几何差中位数 0.3°（身体）/ 2.7°（围兜），没有超过 20° 的；
  摆到盔甲骨架的姿势后，肩部一带差到中位数 7.9° / 15.6°，113 + 102 个顶点超过 20°，最多 70°。摆姿势时脖子的差距
  分摊、四肢对准都会挪关节，权重混合的地方网格被拉斜；法线只跟着骨头转，没跟着表面。mmd_tools 和 MMD 都用 PMX 里
  存的法线打光，所以静止时锁骨的起伏被压平，举手时显出暗痕。
- **修法**：`transport_normals()`：每个顶点的法线，按它周围的面在摆姿势前后的朝向变化来转（只转不改形），原版对接缝
  做的法线修饰也就保住了。修后肩部偏差回到原版的水平（0.3° / 2.7°，超过 20° 的 0 个），整块身体超过 20° 的从 179 个
  降到 6 个；静止时锁骨、胸骨上窝的起伏回来了，举手时腋下的暗带没了，锁骨的折痕也软了。`--normals bones` 是旧做法。
- **游戏皮肤的边缘**：顺带给 `--weights-from` 加了一条：最近点落在游戏皮肤的开口边上（顶点已经出了那块皮肤，比如手腕），
  在 1.5 cm 内退回自己的权重（`--weights-cm` 的第三个数）。边上的权重属于游戏里和另一块网格的接缝。Fiona 有 1,004 个
  这样的顶点。
- **试过、没采用：游戏权重扩到上半身**。PCF_007 那块皮肤其实也盖着肩膀和后背（露背裙），扩过去以后腋下、肩胛的变形
  和游戏一模一样，可腰侧多了一道竖线：那块皮肤在腰侧到头，后面是游戏权重、前面是裸体自己的，差得多，跳舞一扭就看得见。
  扩上半身时乳房外缘也会换成游戏的分布（257–685 个顶点的胸部权重少了 0.1 以上），所以加了 `--weights-keep`：挂在
  胸部物理骨上的顶点保留自己的。最后还是只用手臂。
- **验证**：所有极限姿势、跳舞里肘部和手腕弯得最厉害的几帧（第 180、228、258 帧）都和修之前一样好或更好。
  举手到 150° 时锁骨上还有一个变浅的小折痕（这种角度下网格本身会折，游戏原版的腋下也折）。

### 腿和胯也用游戏权重？（几套服装一起当来源，10-06，没采用）

用户问「fiona游戏里的权重是否都存在，是否匹配mmd」。查下来是这样：

- **盔甲本身**：游戏的权重全在。导出时 UE 的辅助骨（扭转骨、肌肉骨）先并进它所在的那段肢体，再由 Convert_to_MMD5
  按 MMD 的规矩重新分给 腕捩 / 手捩 和 捩1–3。
- **裸体**：手臂是游戏的（上一节），腿、胯、躯干是 Fiona_BaseBody 自己的，游戏里没有带蒙皮的裸体。
- **游戏里其实还有**：8 套服装（PCF_002 / 003 / 004 / 006 / 007 / 009 / 010 / 012）的身体皮肤都是同一个身体网格，只是按不同
  领口、裙长剪开的，腿和胯上都有游戏权重。合起来能盖住裸体手臂的 98%、胯 93%、膝盖小腿 84%、大腿 79%，躯干只有 32%：
  没有一套衣服露腰背。
- **差多少**（同一位置的权重差，一起动的骨头先合并）：手臂 0.02（已经换过）、膝盖小腿 0.04、大腿 0.10、胯 0.3（将近一半
  顶点差超过 0.3）、躯干 0.38。

`--weights-from` 现在可以重复，几套皮肤一起当来源。每个顶点取最近的表面点，落在某套皮肤内部的优先于落在另一套剪口边上的。
用旧参数（只给 PCF_007）重建，结果和原来逐字节一样。

试了「手臂 + 腿 + 胯」全用这 8 套皮肤（会话草稿 build_v11.sh）：

- 侧抬腿 60° 时，两侧胯部出现台阶和凹痕，正面、背面都看得见，v10 是平滑的；
- 深蹲、屈膝两版差不多。

原因和上一节扩躯干时一样：游戏皮肤盖到和盖不到的地方权重差得多，交界处就出接缝。腿本身只差 0.04–0.10，换了也没好处，
所以腿、胯、躯干保留原来的，只有手臂用游戏的。

## 再整理物理和捩骨（10-06）

用户：「综合看一下，彻底解决这个权重和物理的问题吧……衣服的物理效果是否正常，是否有穿模」。full 版做好以后、爆衣之前，

```
python scripts\mmd_physics\cloth_collision_pmx.py Fiona_full.pmx Fiona_full_coll.pmx ^
  --skin "4_BaseBody-MI-pc-female-body05_0.1_0_0,4_BaseBody-MI-pc-female-handfoot05_0.1_0_0,4_Face-MI-Fiona-Face01_0.1_0_0_nude"

```

- **衣服、头发碰身体**（`cloth_collision_pmx.py`，原理和数字见 `scripts/mmd_physics/README.md` 第 5 节）：Fiona 的头发、
  裙子、肩布、长围巾原来一个都不碰身体，是因为身体碰撞体按盔甲量的，太胖，布一开始就在里面，导出时就被放进了「什么都不碰」
  的组。现在碰撞体按裸体皮肤重新量，171 个刚体里 167 个和所有部位都碰。跳一遍手势舞，陷进身体的顶点每帧平均从 37.7 降到
  5.4，最深从 7.5 cm 降到 4.4 cm。
- **捩骨**（`pmx_twist_axes.py`）：Convert_to_MMD5 的 `convert/semistandard.py` 写固定轴时用了 Blender `(x, z, -y)`，而
  mmd_tools 存的是 `(x, z, y)`，所以每个导出的捩骨轴前后分量都反了。Fiona 的 腕捩 / 手捩 偏了 3.2°，手臂越往前伸的模型偏得
  越多。MMD 播 VMD 是照原样转，跳舞几乎看不出来；在 MMD 里手动转捩骨时，手臂绕的线是歪的。现在把轴设成关节连线：
  腕 → ひじ，ひじ → 手首。插件本身 10-06 晚也改好了（Convert_to_MMD5 窗口，用户同意）：之后新转换的模型不用再过这一步。
- **骨骼**：MMD 标准骨齐全。捩骨（腕捩 / 手捩 和 捩1–3，付与 0.25 / 0.5 / 0.75）是导出时 Convert_to_MMD5 一键转换加的，规格
  和社区标准模型（Tifa Gantz）一样；D 骨、IK、付与的变形顺序都对。

## 武器挪到旁边（`pmx_place_prop.py`，10-06）

武器不在 `衣服非表示_材質` 里，爆衣不碰它，爆开以后还在原处。ROE Inase a08 的巨剑导出时剑尖朝下立在原点，正好挡在她身后。
用户：「巨剑插在右边的某个地方吧，不参与爆衣」。在 full 版上、爆衣之前挪：

```
python scripts\clothes_burst\pmx_place_prop.py pc_a08_hd_full_fixed.pmx out.pmx --materials "wp_a08_l,wp_a08_r" ^
  --at=-6.5,-2,2.5 --turn=-20,3,3 --floor 0
```

- **挪哪些**：`--materials` 选中的材质的顶点，加上只带这些顶点的骨骼和它们下面的骨骼（a08：Point007_L / Point007_R、
  chain_ALL、chain01–04，剑上挂的链子跟着走）。骨骼还带着别的顶点、或者顶点和别的材质共用时，工具会停下：那样挪会把模型
  撕开。
- **挪到哪**：转轴是道具底面的中点（立着的剑就是剑尖）。`--at` 是转轴挪到的位置，PMX 单位（x 朝模型左边，y 朝上，z 朝后，
  1 单位 = 8 cm）：上面就是她右边 52 cm、身后 20 cm、往地下插 16 cm。`--turn` 依次是绕竖直轴转、往后仰、往右歪（度）。
  负数要写成 `--at=` 这样带等号，不然会被当成选项。
- **`--floor`**：MMD 没有实心的地面，视频里的地面也只显示影子，插进地下的部分会照样露出来。所以落到这个高度以下的顶点压平在
  地面上，剑身看起来像从地里长出来的。
- **跟着改的**：法线、SDEF 参数、道具的顶点表情（a08 的「武器非表示」把剑缩进骨骼里，缩到的位置跟着挪）、挂在这些骨骼上的
  刚体和关节、移动这些骨骼的骨骼表情。
- 舞蹈 VMD 不动「全ての親」，剑的骨骼挂在它下面，所以整段舞剑都插在原地。跟拍镜头会把这些骨骼算进画面宽度，剑放得越远
  镜头退得越远：放在 52 cm 处只退了 2.5%（6.05 → 6.2 m），剑整个在画面里；剑在身后 20 cm，手臂侧平举也碰不到它。
