怎么导出模型（操作说明）

这个游戏本体是 2D 卡牌（843 张卡是加密的图片，没有模型）。3D 的东西都在 E:\SteamLibrary\steamapps\common\Taimanin Collection\TaimaninCollection_Data\data.unity3d 这一个文件里：阿莎姬一个角色、摩托小游戏用的摩托车、运输机、桥面赛道和道具， 以及一批 Action Taimanin 留下来、这个游戏并不显示的残留（材质被剥掉的两套城市布景、221 个几乎都只有默认材质的原始模型）。 导出 = 把一个 prefab 读出来做成能直接打开的 .blend（游戏的材质 + 骨架 + 表情），需要的话再转 XPS 和 MMD 的 PMX。 不用启动游戏、不用联网、不需要密钥。

最短的路：三条命令 （第一次用，先看下面的「第 0 步」）
  1. 打开 PowerShell，进到脚本目录：
    cd E:\code\othercode\ripper_tpose\scripts\taimanincollection
  2. 导出一个模型。这里是阿莎姬；换别的就把 prf_asagi_costume_1 换成下面清单里的 id：
    python export_model.py prf_asagi_costume_1 --xps --pmx --turntable
    约 3 分钟（只要 .blend 就去掉后面三个开关，约 30 秒）。最后一行是 done: 1 built, 0 skipped, 0 failed 就成了。
  3. 刷新本页，「已导出」里会多出这个模型的卡片：
    python list_models.py --html
第 0 步　准备（只做一次）
  1. 装 Python 包：
    pip install UnityPy lz4 numpy pillow
  2. Blender 3.6：D:\Program Files\blender-3.6.15-windows-x64\blender.exe 本机已有（别处就设环境变量 TSQUAD_BLENDER）。
  3. 游戏在 E:\SteamLibrary\steamapps\common\Taimanin Collection 本机已有（别处就设 TCOLLECTION_GAME_DIR）；导出到 E:\game_export\TaimaninCollection（TCOLLECTION_EXPORT_ROOT）。
  4. 按想要的格式再准备：
    想要什么命令里加另外需要
    .blend + 预览图（角色另有脸部特写和表情总览）什么都不加不需要别的
    转台视频（只有角色）--turntable同上
    XPS--xpsBlender2XPS，放在仓库旁边：E:\code\othercode\blender2xps 本机已有（别处就设 BLENDER2XPS）
    PMX--pmxBlender 3.6 的插件 mmd_tools、Convert_to_MMD5、mmd_cloth_physics （和 Taimanin Squad 的导出相同，装上就行，脚本自己启用）
  5. 脚本复用了旁边两个目录的代码：scripts\taimaninsquad（Blender 端和格式转换）和 scripts\actiontaimanin （读角色、材质）。三个目录要在一起。
第 1 步　找到要导的模型

本页下面的「全部清单」按类别列出了 276 个带网格的对象，绿色的是已导出的。命令行里：

python list_models.py全部 276 个，按类别；最后一列是已导出的格式
python list_models.py --category prop level只看某几类
python list_models.py --find asagi "*truck*"按 id / 角色名找，支持通配符
python list_models.py --details多列出顶点 / 三角面 / 骨骼 / 材质（其中几个是默认 / 被剥掉的）/ 着色器
python list_models.py --html重新生成本页

id 就是 prefab 自己的名字（prf_asagi_costume_1、fbx_motorcycle_rig），场景是 scene_<场景名>，场景里单独一个根物体是 scene_<场景名>_<根物体名> （装好轮子的整辆摩托是 scene_race_bridge_bikeobj）。

第 2 步　导出
python export_model.py prf_asagi_costume_1只出 .blend 和预览图，约 30 秒
python export_model.py prf_asagi_costume_1 --xps --pmx --turntable角色全套：.blend + XPS + PMX + 转台视频，约 3 分钟
python export_model.py fbx_motorcycle_rig fbx_dropship_rig --xps --pmx一次几个
python export_model.py --category vehicle prop scene --xps --pmx按类别
python export_model.py --game游戏实际显示的全部（角色、载具、道具、赛道段、场景）；残留的不算
python export_model.py prf_asagi_costume_1 --xps --pmx --force已经有的也重做
python export_model.py prf_asagi_costume_1 --pmx --reconvert --bust amount=1.3只从现有的 .blend 重做 PMX，胸部幅度 1.3 倍
python export_model.py scene_race_bridge --preview-view 1,0,0.3道具 / 场景的预览换个方向看

这条命令做了什么

  1. 读游戏数据（Python + UnityPy，整个文件读进来约 15 秒）：按 id 找到 prefab，读出骨架、网格、材质的全部参数和贴图、 Dynamic Bone 的物理链；角色另外把脸部的表情动画片段做成形状键。临时放在 E:\game_export\TaimaninCollection\_work\scenes\<id>（建好后删掉，--keep-work 保留）。
  2. 建 .blend（Blender 3.6 后台）：角色和载具用游戏的卡通着色（Toony Colors Pro 2）加描边；场景件是不受光的贴图 × 烘焙光照图 + 发光图。渲预览图，贴图打包进文件 → <组>\blend\<id>\。
  3. --turntable（角色）：转一圈 + 脸部特写的视频。
  4. --xps：Blender2XPS 导出，再读回 Blender 渲一张检查图 → <组>\xps\<id>\。
  5. --pmx：角色转成 MMD 标准骨架，加物理（胸、头发）、切出 MMD 标准表情，再读回套舞蹈、渲表情表； 载具 / 道具 / 场景不是人形，保持游戏原来的骨头，没有 IK 和物理 → <组>\pmx\<id>\。
  6. 数字记进 E:\game_export\TaimaninCollection\_meta\exports.json。

导出时可能出现的三句提示（都不是错）：
… material(s) lost their properties in the build - pictures taken by name：这个材质在游戏的构建里被剥掉了着色器和全部参数 （残留布景），贴图是按名字猜的（mat_x → tex_x、tex_x_lm、tex_x_e）。
… left plain：同上，但连同名的贴图也没有，这个材质是纯色的。
… carry Unity's default material - dressed as the game dresses the same mesh：这个原始模型只挂着默认材质， 用的是游戏在别处（过场演出里）给同一个网格挂的材质 —— 运输机就是这样。

出问题时　终端里的这些话是什么意思
看到意思和办法
data file not found: …游戏不在默认位置：设 TCOLLECTION_GAME_DIR 为游戏文件夹
Blender not found: …设 TSQUAD_BLENDER 为 blender.exe 的完整路径（要 3.6）
no model matches: xxxid 写错了：python list_models.py --find xxx
<id>: already exported (…) - --force to redo不是错：.blend 已经有了。重做加 --force
FAILED <id>: the prefab has no enabled renderer这个对象里的网格都是关着的，没有东西可导
FAILED <id>: Blender failed for <id> (exit N), log: …建 .blend 失败：看它给的日志最后几十行
! XPS failed: … / ! PMX failed, log: …看 <id>.xps.log / <id>.pmx.log；先确认第 0 步里的 Blender2XPS / 三个插件
PMX: not a human figure - …不是错：载具、道具、场景都走这条路，骨头保持游戏原名，没有 IK 和物理
手工路线（不用脚本）

没有实测过。原理上：data.unity3d 是没加密的 UnityFS，AssetStudio 能打开，在 Asset List 里按 Mesh / Texture2D 筛选可以把网格和贴图导出来。但这是一份不带类型树的玩家构建，脚本组件（Dynamic Bone）它读不出来；材质要自己接 （mat_asagi_* → tex_asagi_*）；脸没有形态键，表情是动画片段。同一个阿莎姬在 Action Taimanin 里更完整， 手工步骤见那边的画廊页。
