附录 · 导出脚本用法

脚本在 scripts\doa5lr\，需在装有游戏的机器上运行。 完整说明见同目录 EXPORT_GUIDE.md（操作）与 README.md（格式与原理）。

角色由三个 TMC 组成

部件条目名不加会怎样
服装 + 身体<角色>_COS_NNN—
脸<角色>_FACE（无编号）不加 -Face → 无头
头发<角色>_HAIR_NNN不加 -Hair → 光头

一键出带材质 blend（export_full.ps1）

cd E:\code\othercode\ripper_tpose\scripts\doa5lr

.\export_full.ps1 KASUMI_COS_001 -Archive chara_initial -Face auto -Hair 001 -Label KASUMI_Kasumi
.\export_full.ps1 MARIE_COS_001 -Face auto -Hair 001 -Label MARIE_MarieRose

产物是 _blends\<Label>.blend（贴图已打包进文件）和同名 _preview.png。卡片上的绿色徽标就是该角色所在封包，对应 -Archive 参数。

查条目名 / 换服装

python extract_lnk.py "<游戏>\chara_initial.bin" --list --filter "KASUMI*"

服装编号是纯数字（COS_001、DLC_011），名字看不出款式， 导出后看预览挑。模型分散在 36 个封包：常规服装在 chara_initial 或 chara_common，过场版在 rtm_common，DLC 在 patch_XX_catalog，场景在 stage_*。

社区 mod（含 nude）

.\export_full.ps1 -TmcFile D:\mods\nude.TMC -Label KAS_Nude
.\export_full.ps1 KASUMI_COS_001 -TmcFile D:\mods\nude.TMC -Archive chara_initial -Hair 001 -Label KAS_Nude
官方内容没有 nude。全部 36 个封包、12,625 个条目名搜 nude/naked/bare/skin/under/lingerie 零命中，衣服底下的皮肤网格被裁掉了。 mod 是替换用的 .TMC + 同名 .TMCL，格式与官方一致， -TmcFile 直接吃；-TmcFile 也接受目录。 DOA5LR 的 mod 在 GameBanana 上是 0 个，主要在 LoversLab（需登录手动下载）。

已知坑

症状原因 / 处理
光头 / 无头漏了 -Hair / -Face
皮肤半透明起噪点已修复。DOA5LR 把高光遮罩塞在 diffuse 的 alpha 里， 现在按数据判定（需 >2% 全透明 且 >4% 全不透明像素）才接透明通道
头发压在脸上 / 没有脸已修复。多数角色三部件本就同处一个坐标系， 早期版本强行按包围盒对齐反而挪歪（马尾的包围盒顶端是发梢；女天狗的翅膀撑大身体包围盒）
Alpha-152 通体白素材如此：三部件加起来只有 8 张贴图， 游戏里靠特殊半透明 shader 表现，原始数据没有颜色贴图可还原
.ps1 报 missing terminator脚本被存成无 BOM 的 UTF-8， PowerShell 5.1 按 GBK 解析吞掉引号；用 UTF-8 with BOM 重存

重新生成本页

blender --background --factory-startup --python scripts\doa5lr\html\collect_manifest.py
python scripts\doa5lr\html\make_gallery.py

第一步用 Blender 打开每个 blend 收集网格/材质/贴图统计写成 manifest， 第二步把预览图缩成 JPEG 放进 _gallery\thumbs\ 并重写本页。 缩略图刻意不进仓库 —— 和其它脚本一样，仓库不收任何游戏素材。
