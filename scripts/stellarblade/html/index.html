附录 · 导出脚本用法

脚本在 scripts\stellarblade\。完整说明见 docs\stellar-blade-extraction.md， 服装编号→名称对照见 docs\stellar-blade-eve-outfits.md。

一套服装一条命令

cd E:\code\othercode\ripper_tpose\scripts\stellarblade
.\export_eve.ps1                       # 先跑一次：标准 Eve + 共享的脸 / 发型 / 马尾 / UEFormat 快照
.\export_outfit.ps1 CH_P_EVE_45_TypeB  # 任意服装：UE Viewer 按包名导 PSK+PNG -> Blender 组装 -> 渲染 + 报告
python list_models.py --glob 'CH_P_EVE_*'   # 从 .utoc 索引枚举包名（DLC 加 --path-filter SB/Content/DLC）

产物 blender\Eve_<包名>.blend（单一主骨骼 Eve_Armature， Face_003 带 53 个表情 Morph，贴图外链）、validation\Eve_<包名>.png / _face.png / .json。 画廊用的亮预览由 scripts\final\html\render_blend_preview.py -- blender --suffix _gallery 补渲。

包名规律

形式含义
CH_P_EVE_NN / NN_Body本体服装（02–63，12/13/38/44 不存在）
_TypeB / _TypeC / _Body_02换色变体（名称见对照表）
NH无高跟版本
Nier_01~04 / Nikke_01~06NieR / NIKKE 联动 DLC，挂在 SB/Content/DLC_1|2/
InnerSuitSkin Suit；EveOriginalProportions 裸模 mod 覆盖的就是它
原版没有 nude。裸模来自本机安装的 EveOriginalProportions mod（Eve_Nude_*.blend）。

已知坑

症状原因 / 处理
UE Viewer 报 Found N game files 数量不对用错构建；必须用专用的 umodel_stellar_blade_v6.exe
Face_003 导不进 Blender 3.6UEFormat 导入器要用钉住的快照 + 仓库补丁（export_eve.ps1 自动处理）
裸模发型悬空mod 骨架缺 SC_Hair，用 --alignment-reference 复用标准报告的变换
