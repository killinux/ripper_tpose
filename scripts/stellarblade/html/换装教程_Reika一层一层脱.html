2两个滑块怎么用

表情里只有两个换装滑块，按顺序拉到 1，拉上去的不用放回：

1_A脱ぎ2_B脱ぎ穿着
00Reika A（打开时就是这样）
10Reika B
11裸体
顺序不要反过来：只拉 2_B脱ぎ 会在 A 底下看到裸体。脱下的那层会收进身体里面（往骨头中心收），所以拉反了也不会从皮肤里穿出来，只是样子不对。

每个滑块里面是几个零件表情（A非表示、A収納、B表示、B消去、B収納、裸体表示），面板里看不到，不用管。

3MMD：手动换装

  1. 把 Eve_Mod_GantzReika_Layers.pmx 拖进 MMD 窗口（或「モデル操作」→「読込」）。
  2. 读入舞蹈：右上角模型下拉框选中这个模型，把 适配瓦雷莎.vmd 拖进窗口（或「ファイル」→「モーションデータ読込」）。
  3. 右下角「表情操作」的四个下拉框里，换装滑块在「その他」（其他）。下拉选 1_A脱ぎ，拖滑块就能看到 A 换成 B。

在第 N 帧一下子换掉

MMD 的表情在两个关键帧之间是直线渐变的，只在第 N 帧打一个 1，会从第 0 帧开始慢慢变。要「一下子换」，前后各打一帧：

  1. 时间轴跳到第 N−1 帧，「その他」选 1_A脱ぎ，滑块 0，点「登録」（注册）。
  2. 跳到第 N 帧，滑块 1，点「登録」。
  3. 换成裸体：在后面的第 M−1 帧给 2_B脱ぎ 打 0、第 M 帧打 1。1_A脱ぎ 不用动，一直是 1。
做对的样子：播放到第 N 帧，A 一下子变成 B；到第 M 帧 B 变成裸体。想慢慢淡出就把 0 和 1 两帧拉开几帧。

4MMD：一层一层爆开

  1. 拖进 Eve_Mod_GantzReika_Layers_burst.pmx（带碎片的版本）。
  2. 拖进 手势舞_加一层一层爆衣_第120帧开始_每层隔90帧.vmd：舞蹈和爆开在一个文件里。
    • 跳别的舞：先读那个舞蹈，再读 爆衣_第120帧开始_每层隔90帧.vmd（只有爆开的表情帧，叠在舞蹈上）。
  3. 播放：第 120 帧 A 碎开、露出 B；第 210 帧 B 碎开、露出裸体。碎片飞出去、落到地上，40 帧内淡出。

爆开那一帧碎片先出现在原位，看着和衣服一样；下一帧换层，碎片飞开。B 露出来的皮肤不碎，换层时直接换成裸体的皮肤。 换别的时间：在 MMD 里把 1_A脱ぎ 那组表情帧整体拖到别处就行（1_爆衣、1_爆衣落下、1_爆衣碎片_材質、1_A脱ぎ 一起拖；第二层是 2_ 开头的那几个）。 或者在 Blender 的爆衣插件里改好时间再导出，见第 6 节。

5Blender：换装（游戏材质）

插件 10-24 更新过，先重开一次 Blender，新代码才会用上。「剑星游戏材质」和「爆衣」两个插件在你的偏好设置里已经启用了。
  1. 文件 → 新建 → 常规，删掉立方体（选中后按 X）。
  2. 文件 → 导入 → MikuMikuDance Model (.pmd, .pmx)，选 Eve_Mod_GantzReika_Layers.pmx。右侧选项里 Scale（缩放） 填 0.08（人约 1.7 米），点 Import Model File。
  3. 鼠标放在 3D 视图里按 N，侧栏切到 MMD 标签。
  4. 「剑星游戏材质」面板：点「换上游戏原始材质」。面板上写「分层模型：A → B → 裸体」，下面显示 「Eve_Mod_GantzReika_A_HQ + Eve_Mod_GantzReika_B_HQ + Eve_Nude_Barefoot_HQ：换了 19 个材质，没找到 0 个，错误 0；6 个跟着滑块显示 / 隐藏」。
  5. 按 Z →「材质预览」。「实体」视图里换装滑块没反应。
  6. 同一个 MMD 标签里展开「Morph Tools」面板：
    • 列表右边点 ▼ →「绑定」（Bind）。只做一次，之后表情才有滑块；
    • 列表上面一排按钮点「群组」（Group），列表里只有 1_A脱ぎ、2_B脱ぎ；
    • 点中 1_A脱ぎ，列表下面出现一个滑块，拖到 1：A 换成 B。再点 2_B脱ぎ 拖到 1：换成裸体。
  7. 做成动画：鼠标放在滑块上按 I 打关键帧。和 MMD 一样，要「一下子换」就在第 N−1 帧打 0、第 N 帧打 1。
做对的样子：只看到一层衣服，换层时没有闪面；B 的肚子、大腿上没有细黑线（插件管着藏起来的层）。「游戏材质 / MMD 着色」两个按钮可以来回切着比较。

要跳舞：选中模型，文件 → 导入 → MikuMikuDance Motion (.vmd)，Scale（缩放） 也填 0.08。一定在「绑定」之后导入，VMD 里的表情帧才会落到滑块上。

6Blender：一层一层爆开

用做好的爆衣 PMX（最快）

  1. 按第 5 节导入 Eve_Mod_GantzReika_Layers_burst.pmx（Scale / 缩放 0.08），换上游戏材质，Morph Tools ▼ →「绑定」。
  2. 选中模型，导入舞蹈 VMD，再导入 爆衣_第120帧开始_每层隔90帧.vmd（两次的 Scale / 缩放 都是 0.08，其他选项不动）。
  3. 空格播放。VMD 导入默认在前面留 5 帧，所以 A 在第 126 帧左右爆开、B 在第 216 帧左右。

或者直接打开做视频用的场景 Eve_Mod_GantzReika_Layers_burst_一层一层爆_手势舞.blend（爆衣文件夹里，物理已经烘焙好），按空格播放。

自己生成（能改时间、碎片大小）

  1. 按第 5 节导入 没有碎片的 Eve_Mod_GantzReika_Layers.pmx，换上游戏材质（可选）。
  2. 侧栏切到「爆衣」标签，最上面点「MMD 表情」。第 1 栏写「分层模型：一层一层爆」，按步骤列出两层的材质： 按下的碎成碎片；EveSKin（B 露出来的皮肤）默认没按下，换层时直接换成裸体的皮肤。
  3. 点「生成爆衣表情」。状态栏：「爆衣表情做好了：一层一层爆：A 159 块碎片、B 108 块碎片，不碎、直接换掉：EveSKin」。
  4. 第 4 栏「第一层爆开帧」（默认 120）、「每层间隔」（默认 90 帧 = 3 秒）按需要改，点「在时间轴上预览」，空格。
  5. 给 MMD 用：PMX 用 mmd_tools 导出（Scale / 缩放 和导入时一样）；「导出爆衣 VMD」导出时间，填了「合进动作」就是舞蹈加爆开一个文件。

更细的设置（碎片大小、飞多远、淡出）见仓库 docs/clothes-burst-tutorial.md 例 5、例 6。

7给别的衣服做换装模型

同一个角色的几套衣服都能这样叠：最外面那套当底子，里面的每层只拿它自己的材质。命令（仓库 scripts\clothes_burst 里，普通 Python 就行）：

python pmx_layers.py <外层.pmx> --outer "<外层衣服的材质>" --outer-name A ^
    --layer B <里层.pmx> "<从它拿的材质>" ^
    --layer 裸体 <裸体.pmx> "<身体材质>" ^
    --out <合并.pmx>

Reika 用的就是这条（材质名在 PMX 编辑器或 Blender 的材质列表里看）：

python pmx_layers.py E:\game_export\StellarBlade\Reika\pmx\Mod_GantzReika_A\Eve_Mod_GantzReika_A.pmx --outer "SuitA_Body,SuitA_Mesh" ^
    --layer B E:\game_export\StellarBlade\Reika\pmx\Mod_GantzReika_B\Eve_Mod_GantzReika_B.pmx "EveSKin,SuitB,SuitA_Body" ^
    --layer 裸体 E:\game_export\StellarBlade\Eve\pmx\Nude_Barefoot\Eve_Nude_Barefoot.pmx "SkinEve" ^
    --out E:\game_export\StellarBlade\Reika\pmx\Mod_GantzReika_Layers\Eve_Mod_GantzReika_Layers.pmx
  • 由外到里写；层名要短，用 A、B、裸体 这种（表情名进 VMD 最多 15 字节）。
  • 各层要是同一个角色、同一套骨架（骨骼按名字对上）。
  • 做好以后的爆衣 PMX：scripts\riseoferos\burst_pmx_blender.py，或者第 6 节的插件。命令见 scripts/clothes_burst/README.md「然后：爆衣」。

8常见问题

现象原因怎么办
拉了 2_B脱ぎ，A 还在，底下露出裸体顺序反了先把 1_A脱ぎ 拉到 1
MMD 里衣服是慢慢变过去的只打了一个关键帧，MMD 从上一个关键帧直线渐变换装的前一帧打 0
MMD 里读了爆衣 VMD，没碎读进的是没有碎片的 Eve_Mod_GantzReika_Layers.pmx换 …_burst.pmx；VMD 要对着这个模型读
Blender 的 Morph Tools 里点了表情，没有滑块还没「绑定」列表右边 ▼ →「绑定」
Blender 里拉滑块，衣服不换视图是「实体」按 Z →「材质预览」
Blender 导入 VMD 后表情不动、衣服不换导入 VMD 时还没绑定，表情帧没落到滑块上删掉动作（或重新导入模型），先「绑定」再导入 VMD
B 的肚子、大腿上有几条细黑线没换游戏材质，或 Blender 还在用旧插件重开 Blender，点「换上游戏原始材质」（插件管着藏起来的层；只用 mmd_tools 时会有）
换上游戏材质后三层都露出来了旧版插件不认表情的透明度重开 Blender 用 10-24 的插件，「去掉游戏材质」后再换一次
碎片停在半空，到淡出才消失碎片跟着它挂的骨头走，手臂抬着时爆开，手臂上的碎片也跟着换个爆开帧（手放下的时候）
人有 20 多米高，或者跳舞飞出画面模型和 VMD 的 Scale 不一样Scale / 缩放 都填 0.08，删掉重新导入
