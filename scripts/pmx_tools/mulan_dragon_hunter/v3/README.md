# 水晶猎龙者 v11：照「MS移植第 44 期」的预览图重新建模（2026-11-21）

用户从 MS 移植的 QQ 群里下了预览包，里面第 44 期就是游戏原模型移植到 HS2 的水晶猎龙者（mod 本体要另外买）。

**只留身体、脸（Inase a08 裸体版）和马尾（星刃 Eve），其余全部由脚本照参考图建模**，贴图也全是程序生成的。

## 两种做法

### 1. 从皮肤上「长」出来的甲（`skinshell.py`）

贴身的部分（黑色紧身甲、胸甲、腰甲、肩 / 臂 / 腿的甲片、护胫、膝后的带子）不单独建模，直接取身体表面：

1. 给身体的每个顶点算一个标量场，**场 > 0 的地方就是这块甲**，场的零线就是甲的轮廓。
   轮廓画在身体坐标里：躯干用正视图的 (x, y) 多边形（正面、背面各一套，在体侧 z = 0 处对齐），
   四肢用绕骨骼的柱坐标（沿骨骼的距离 t、绕骨骼的角度 φ、离轴的距离 r）。
2. 身体网格很粗（肚子上的三角形有 2–4 cm），所以先把轮廓附近的三角形细分到 1 cm，跨轮廓的再细分到 0.3–0.5 cm，
   然后沿零线把三角形切开。蝙蝠翼的尖齿、甲片的锯齿边都是这样切出来的。
3. 沿法线外推（紧身甲 1.5 mm、胸甲 6.5 mm、腰甲 5 mm），在轮廓处补一圈「边」连回皮肤，看起来是有厚度的板。
4. 新顶点的权重是皮肤权重的线性插值，所以甲和身体一起弯，不会穿模。

叠在一起的甲片（肩甲 3 片、小臂 3 片、大腿 4 片）靠**倾斜的外推量**做出来：每片上缘离皮肤 3 mm、下缘 9–10 mm，
下缘压在下一片上面；下缘再切成 2–3 个尖。

贴图的小技巧：把「到轮廓的距离」写进 U（0 = 边缘，1 = 离边 4 cm），贴图只是一条横向渐变：
最左边一条红棕色亮线、后面一道暗槽、再往右是黑甲本体。这样每块甲不管什么形状，边上都有一圈描边。

## 画轮廓用的工具

- `bodymap.py`：把身体（或头 + 头发）渲染成带厘米网格的正 / 背 / 侧视图。所有轮廓的坐标都是对着这张图读出来的。
  a08 的几个位置：肚脐 (0, 111.5)、下胸线 y 125.5、乳头 (±9.2, 131.5)、腋下 (±13.5, 138)、裆 y 93、腰最细 y 116（半宽 10.3）。
- `probe.py`：列材质（面数、包围盒）、主要骨骼的位置、刚体。
- `render_views.py`：从任意角度渲染（`名字:偏航:俯仰:中心高度:画面高度`，`--dark` 用深色背景，和 HS2 预览图好比较）。
- `pose_test.py`：导入 VMD，跳到几帧渲染静帧（不算物理），检查盔甲跟着身体动时有没有穿模。
- `check_pmx.py`：读回成品，查面索引、权重是否归一、法线、贴图文件是否齐、材质面数、表情指向的材质。

## 踩过的坑

- **U 夹到 1.0 整块甲发红**：贴图是重复寻址，U = 1.0 双线性采样时混进了 U = 0 那一列（边缘的红线）。夹到 0.985。
- **乳头顶穿胸甲**：胸甲是皮肤外推的，乳头比周围高 1.33 cm，外推后是两个凸点。做法：先把乳头周围 2.6 cm 内的皮肤松弛成光滑曲面
  （只改一份拷贝，1500 次迭代；80 次根本没收敛，这一块网格很密），紧身甲和胸甲都从这份拷贝长出来；
  胸甲在乳头上方再抬高到「真乳头高度 + 3 mm」，4 cm 范围内平滑过渡。
- **用权重定袖口会参差不齐**：最初用「手臂骨骼的权重和 = 0.5」当胸甲的袖口线，出来是锯齿。
  改成几何定义：上臂骨 1.5 cm 处的一个平面，只在手臂圆柱（半径 6.5 cm）以内生效。
- **离边 1 cm 的第二条描边成了花斑**：那里的三角形没细分到那么细，等距线插出来是锯齿。只留紧贴边缘的一条线。
- **细分留下的 T 形接缝**：细分只做在轮廓附近，粗细交界处有悬挂点。外推方向用线性插值（不重新归一化），
  悬挂点正好落在相邻粗三角形的边上，不会裂缝。
- **面数**：甲片最初每片都细分到 0.3 cm，20 片 9 万面；锯齿有 2 cm 大，细分到 0.5 cm 就够（5 万面）。全模型 25 万面。
- **平的甲片在跳舞视频里整片发白**：不是高光颜色（降到 0.08 也没变），是加算的球面贴图。
  球面贴图按法线取色，一整片平板只有一个法线，等于整片取同一个像素；转到正对高光斑的角度时整片变白。
  查法：打开跳舞渲染存下的 .blend，把 v11 材质的球面贴图关掉再渲染同一帧，白色就没了。
  做法：平板类零件（裙甲、花瓣、头冠、晶翼、剑、背饰）换成 `sphere_soft`（只有一层很淡的宽渐变），
  有弧度的（紧身甲、胸甲、甲片、领口、铁靴）才用带高光斑的 `sphere_gloss`。
- **打开 .blend 后再渲染，输出路径要给绝对路径**：`blender -b x.blend --python ... -- r/why` 把 `r/why` 解析成了 `C:\r\why`。
- **Bash 工具的命令超过 8 KB 会被截断**（报 `unexpected EOF`）：长的修改脚本先用写文件的方式落盘再跑。带反斜杠的也一样。
- 铁靴：凸包切片在脚踝处会把小腿也包进去，所以只取 y < 11.5 cm 的顶点；权重取最近的皮肤顶点，脚趾那段会跟着 足先EX 动。
- 两鬓的发片、裙甲都**没有物理**：发片挂在 頭 上，裙甲靠权重跟着大腿走（手势舞里不穿模，但不会飘）。
