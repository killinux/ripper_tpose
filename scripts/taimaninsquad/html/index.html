手动操作说明：怎么看有哪些模型、怎么导出

下面每张卡片是游戏里的一个 3D 单位。自己动手有两条路：A. 用仓库里的脚本（推荐，一条命令出卡通着色的 .blend、XPS、PMX）；B. 完全不用脚本，用现成的图形界面工具（只能拿到带骨架的原始模型，材质要自己接）。

A-1　准备（只做一次）
  1. 打开 PowerShell，进到脚本目录：
    cd E:\code\othercode\ripper_tpose\scripts\taimaninsquad
  2. 装 Python 包：
    pip install UnityPy lz4 numpy pillow
  3. Blender 3.6：D:\Program Files\blender-3.6.15-windows-x64\blender.exe（装在别处就设环境变量 TSQUAD_BLENDER）。只出 .blend 不需要任何插件。
  4. 要出 XPS：仓库旁边要有 Blender2XPS（E:\code\othercode\blender2xps）。要出 PMX：Blender 3.6 里要装好 mmd_tools、Convert_to_MMD5、mmd_cloth_physics 三个插件。
  5. 游戏在 E:\SteamLibrary\steamapps\common\Taimanin Squad（别处就设 TSQUAD_GAME_DIR），导出到 E:\game_export\TaimaninSquad （TSQUAD_EXPORT_ROOT）。不用启动游戏、不用联网、不需要密钥。
A-2　看有哪些模型

在这一页看：上面的搜索框输名字或编号；类别按钮、「只看女性」「只看已导出」可以叠加。没导出的卡片上是预览渲染 （或游戏头像），带着这个单位的导出命令。「女性」的依据：游戏的配置表解不开，没有性别字段，所以按胸部骨认 （140 个），另有 8 个没有胸部骨的是看预览图补进名单的（卡片上 ♀ 的悬停提示会注明）。

在命令行看：

B　完全不用脚本：AssetStudio + Blender（实测过的手工路线）

实测对象是 Kirara（prf_24）：导出用的是 AssetStudioMod v0.19.0 的命令行版（和图形界面同一个内核）， 再把 FBX 导进 Blender 3.6；下面的菜单名取自图形界面程序本身。

  1. 看有哪些模型：资源管理器打开 E:\SteamLibrary\steamapps\common\Taimanin Squad\TaimaninSquad_Data\StreamingAssets\aa\StandaloneWindows64，搜索 localunit_aos_assets_。 每个文件是一个单位的美术包，文件名就是 localunit_aos_assets_<编号>_<名字>_<hash>.bundle （例：localunit_aos_assets_24_kirara_….bundle，6 MB）。不带 aos 的 localunit_assets_* 是同一个单位的动作和武器包。
  2. 取出模型：打开 AssetStudioMod 的 GUI（E:\tools\AssetStudioMod_v0.19.0\AssetStudioModGUI_net8_win64\AssetStudioModGUI.exe） → File > Load file 选那个美术包 → Asset List 页里 用 Filter Type 只留 Animator → 右键 prf_<编号>（带 _LOD1 的是低模）→ Export Animator + selected AnimationClips。得到 prf_<编号>.fbx 和同一文件夹里的 PNG 贴图。 （另一种点法：Scene Hierarchy 页勾上 prf_<编号> → Model > Export selected objects (merge)。）
  3. 大小：AssetStudio 默认的 FBX 进 Blender 只有 1.9 厘米高。两个办法任选其一：导出前在 Options > Export options 把 ScaleFactor 改成 100；或者 Blender 导入 FBX 时把「缩放」填 100。 两种都实测过，Kirara 进来是 1.88 米。
  4. 进 Blender：文件 > 导入 > FBX。骨架、蒙皮、脸上的表情形态键（closed_eyes、 smile_face ……）都在。
  5. 贴图要自己接：游戏着色器的贴图槽叫 _BaseMap，AssetStudio 只认 _MainTex，所以导入后 材质几乎都是空的。按名字接底色图：mat_face* → tex_d_face，mat_hair* → tex_d_hair， mat_skin / span / metal → tex_d_costume，mat_cloth → tex_d_cloth。 其余几张：tex_s_* 是阴影色（暗部直接换成它），tex_m_* 是遮罩（R 自发光 / G 高光 / B MatCap）， tex_on_face 是脸部阴影的阈值图。
  6. 手工路线拿不到的（脚本替你做了的）：卡通着色和描边；UV 接缝处拆开的顶点没有焊回去；嘴里的形态键不会跟着脸走； em_* 表情贴片没有藏起来；Magica Cloth 的布料组只是一堆空物体；阿莎姬、不知火、飞鸟、胧的腿蒙在另一条骨链上， 摆腿时小腿不跟着走（脚本导出时修掉了）；以及 XPS / PMX。
  7. 再往 XPS / PMX 走：手工步骤和别的游戏一样，见仓库里的 docs\vindictus-fiona-manual-export.md 第 5 节（Blender2XPS 导出 XPS）和第 6 节（Convert to MMD 5 转 PMX）。
