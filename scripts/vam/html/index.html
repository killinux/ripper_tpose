附录 · 导出脚本用法

脚本在 scripts\vam\，需要本机装有 VaM 1.22、Blender 3.6 与 AssetStudioModCLI。 Look 是"基础人体 + morph + 皮肤贴图 + 衣服 + 头发 + 挂在骨骼上的 CustomUnityAsset"， 导出的是静止 A-pose 静态网格（无骨架），贴图打包进 .blend。

cd E:\code\othercode\ripper_tpose\scripts\vam

.\export_vam_models.ps1 -List                              # 列出全部 Look / 衣服 / 头发（带序号）
.\export_vam_models.ps1 -List -Type look -Filter tifa      # 只看 Look，名字含 tifa
.\export_vam_models.ps1 -Only VAMSOY.Angela.1~Angela~Person  # 按 key 导出
.\export_vam_models.ps1 -Only Angela~Person                # 唯一子串也行，逗号分隔可多项
.\export_vam_models.ps1 -Index 125,550                     # 按 -List 序号
.\export_vam_models.ps1 -All -Type look -Force             # 全部 Look 重导
.\export_vam_models.ps1 -Only 瑶瑶~Person -Format blend,glb # 同时出 glb
python html\make_gallery.py                                # 重建本页

常用开关：-NoClothing / -NoHair / -NoAttachments 只导人体或去掉某类； -IncludePoseMorphs 保留姿势 morph；-Force 覆盖已有产物（缺省已有 blend 与预览的条目 SKIP）； -ManifestPath 给并行进程各自的清单。产物在 D:\vam_exports\looks|clothings|hairs\<key>\blend\， 清单 D:\vam_exports\vam_models_manifest.json。缩略图写在 D:\vam_exports\_gallery\thumbs\。
