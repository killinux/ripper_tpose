附录 · 导出脚本用法

脚本都在 scripts\riseoferos\，需在装有游戏的机器上运行。整个流程分两步： 先从 AssetBundle 提取白模，再无头重建材质。

第一步 · 提取（extract_character.ps1）

cd E:\code\othercode\ripper_tpose\scripts\riseoferos

.\extract_character.ps1 -List                        # 列出全部角色 ID
.\extract_character.ps1 m02 -ExportTextures          # 提取单个角色
.\extract_character.ps1 j10,k02,m01 -ExportTextures  # 逗号分隔批量

-ExportTextures 必须加，否则不导贴图，第二步会因缺少共享头部贴图而失败。 产物在 D:\roe_exports\<id>\。

第二步 · 材质化（export_character_models.ps1）

.\export_character_models.ps1 -List            # 看可转清单和各自用哪份 FBX
.\export_character_models.ps1                  # 全部，已有产物自动跳过
.\export_character_models.ps1 -Only m02        # 只转一个
.\export_character_models.ps1 -Only m02 -Force # 重做，覆盖已有产物

产出 <id>\blend\<模型名>.blend（贴图已打包进文件） 与同名 _preview.png。

参数作用
-Only <ids>写 m01 连 outfit 变体一起转；写 m01_outfit1 只转那一套
-Force覆盖重做；不加时 blend 与预览图都在的会 SKIP
-Format blend,glb额外导 GLB 到 blend\glb\，缺省只有 blend
-Format xps -NoPreview给已有 blend 的角色补带材质 XPS 到 blend\xps\<stem>\（.mesh + 同目录 PNG）
-Format pmx -NoPreview补 MMD 可用的 PMX 到 blend\pmx\<stem>\：Convert_to_MMD5 插件转标准 MMD 骨架（IK / D 骨 / 捩骨 / 肩P / 付与）+ 身体刚体 + 裙发物理，A-pose 37°，可直接加载 VMD
-NoPreview不渲预览图（实测只快约 9%，一般没必要关）
render_pmx_dance.ps1 -Stale另一个脚本：给 PMX 渲跳舞 mp4。骨骼问题只有动起来才看得见，改完导出流程务必重渲——卡片上标「已过期」的就是比 PMX 旧的视频
-ValidateOnly只检查材质不写文件，排查用
-ManifestPath自定义清单路径；多进程分片并行时每个分片必须各给一个

两个容易踩的坑

重新提取会删掉 blend 目录。 extract_character.ps1 <id> 会把 D:\roe_exports\<id>\ 整个删掉重建，第二步生成的 blend\ 也一起没。顺序永远是先提取后转换； 要重提某个角色，先把 blend 挪出去。

报 缺少贴图: face, eye_iris, eyebrow 说明该角色目录是旧流程导的、 缺同字母体型的公共头部贴图。补跑一次 .\extract_character.ps1 <id> -ExportTextures 再转即可。

并行加速

.\export_character_models.ps1 -Only a01,a02,a03 -ManifestPath D:\tmp\shard0.json -Force

默认那一个清单文件不支持并发写，分片时必须各给一个，跑完再合并。 全量 123 个条目用 6 分片并行，24 核机器约 25 分钟。

套装（suit）· export_suits.py

角色的服装变体（游戏里叫 suit：教师装、猫女、婚纱…）不是一个整体 FBX，而是裸模 + 头发 + 一堆分开的部件网格。标着「套装」徽章的卡片就是拼出来的这些，每套一个 .blend， 直接从 AssetBundle 读（不经 AssetStudio）：

python export_suits.py --list                     # 哪些套装、哪些已拼
python export_suits.py --lanes 4                  # 全部没拼的，4 路并行
python export_suits.py --only j01:idol,b01:* --force
python export_suits.py --exclude fm --force       # 跳过魔化（fm）套

前提只有该角色的裸模已提取（extract_character.ps1 <id>）。产物 <id>\blend\pc_<id>_<suit>.blend，中间数据 _suits\<id>\<suit>\， 清单 _suits\manifest.json。「去掉 N」徽章列的是没穿上的部件（道具、敞开/拉下的替代态、 被上衣遮住的乳饰），规则判错的在 suit_overrides.json 里按 <id>:<suit> 改，再 --only <id>:<suit> --force。部件坐标系的五种情况与「穿好」规则见 docs\roe-suit-assembly.md。

重新生成本页

python scripts\riseoferos\html\make_gallery.py

读 character_models_manifest.json 和 _suits\manifest.json，把预览图缩成 JPEG 缩略图放进 D:\roe_exports\_gallery\thumbs\，再重写本页。 缩略图刻意不放进仓库——和其它脚本一样，仓库不收任何游戏素材。
