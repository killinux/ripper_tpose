1先弄懂它在做什么（一分钟）

衣服本来是「长在」g05 身上的：挂在 g05 的骨头上（权重），贴着 g05 的身体（形状）。插件把这两层关系换成 a08 的：

g05 的衣服 ─┬─ 挂在哪些骨头上 ──① 换骨架 ───────────▶ 套到 a08 的骨架上 └─ 贴着 g05 的身体 ──②③ 换身材、贴合 ───▶ 贴到 a08 的裸体上 ④ 换权重 ─────────▶ 跟着 a08 的皮肤一起动 g05 飘带、前片的物理 ───⑤ 搬刚体关节、隔开碰撞组 ──▶ 只碰 a08 的身体，不碰 a08 的衣服
  • ① 骨头按名字对上（对不上的按位置配，比如胸骨），a08 没有的骨头（飘带、前片、光环）连父骨一起搬过去；
  • ② 把 g05「衣服底下那份身体」变成 a08 的身材，得到一张位移图；
  • ③ 每个衣服顶点按它在 g05 皮肤上的位置（沿皮肤偏多少、离皮肤多高）放到 a08 的皮肤上；离身体远的光环、法杖只按骨骼放；
  • ④ 贴在皮肤上的部分改用 a08 皮肤的权重，跳舞时胸带不会被皮肤顶穿；
  • ⑤ g05 的刚体、关节一起搬，放进 a08 没用过的碰撞组。

下面每一步后面标的 ①–⑤ 就是对应这里。原理细节见仓库 docs/pmx-outfit-transfer.md。

插件

需要三个插件。你的 Blender 3.6 里，mmd_tools 和 ROE Game Materials 已经勾上了，换装插件还没勾：

  1. 打开 Blender 3.6（D:\Program Files\blender-3.6.15-windows-x64\blender.exe）。
  2. 菜单 编辑 → 偏好设置… → 左边点 插件。
  3. 右上角搜索框输入 Outfit，找到「导入-导出: PMX Outfit Transfer」（英文界面叫 Import-Export），勾上前面的方框。
  4. 展开它能看到版本 0.2.0。关掉偏好设置窗口（会自动保存）。
插件文件已经用目录联接装在 Blender 里了（指向仓库 scripts\blender_addons\pmx_outfit_transfer），只差勾选这一步。

3打开换装面板

  1. 建议先开个干净的场景：文件 → 新建 → 常规，再把默认的立方体删掉（选中按 X → 删除）。场景里已有别的模型也行，只是新模型会叠在原点。
  2. 鼠标放在 3D 视图里，按 N 拉出右边的侧栏。
  3. 侧栏右边竖着的标签里点 MMD。
  4. 往下滚，找到面板「换装（服装移植）」。MMD 页签里面板很多，可以点其他面板的标题把它们折叠起来。

4填三个路径

每个框都可以点文件夹图标去选，也可以直接点进框里粘贴（下面灰色的路径点一下就全选了，Ctrl+C 复制）。

  1. 衣服来自：E:\game_export\RiseOfEros\Luf\pmx\pc_g05_hd_full\pc_g05_hd_full_裙子碰撞修正_瞳孔修正.pmx
  2. 穿到：E:\game_export\RiseOfEros\Inase\pmx\pc_a08_hd_full\pc_a08_hd_full_裙子碰撞修正.pmx
  3. 输出 PMX：E:\game_export\RiseOfEros\_混搭\练习_a08穿g05\pc_a08_hd_full_穿g05衣服.pmx

7点「换装」 （①–⑤ 一次做完）

  1. 点蓝色的「换装」按钮，等十几秒（Blender 会卡住一会儿，正常）。
  2. 面板最下面显示：
    「写出 pc_a08_hd_full_穿g05衣服.pmx：37 个新材质，42 根骨，30 刚体，30 关节」
  3. 场景里多了一个模型，名字是 Pc A08 Hd Full 穿G05衣服（mmd_tools 导入时会把名字改成首字母大写）。
  4. 输出文件夹 练习_a08穿g05\ 里有 pc_a08_hd_full_穿g05衣服.pmx 和 textures\（11 张贴图，实拷贝，整个文件夹能挪走）。
37 个新材质 = g05 的衣服拆成的小零件；42 根骨 = a08 没有、跟着衣服搬过来的骨头（飘带、前片、花环、光环……）；30 刚体 / 30 关节 = g05 衣服的物理。

8检查：拉「衣服非表示」

刚导入时是默认状态：a08 自己的衣服和 g05 的衣服都在（最上面第一张图）。要看「g05 穿在裸体上」：

  1. 点一下新模型（任何一部分都行）。
  2. 侧栏 MMD 页签里找到「变形工具」面板（默认是折叠的，点标题展开）。
  3. 面板最上面一排按钮选「组」（Group）。列表里有 衣服非表示，点它。
  4. 列表下面如果没有「值」这个滑块：点列表右边那一竖排按钮里的 ▼（下拉箭头）→ 选「绑定」（Bind）。 这是 mmd_tools 把表情滑块绑定到模型上，绑定一次就行。
  5. 把「值」拉到 1：a08 的衣服消失、换成裸体那份身体，g05 的衣服穿在裸体上（上面第二张图）。拉回 0 就恢复。
为什么是裸体那份：a08 full 里有两份身体。贴衣服的那份往里收过，防止穿模；裸体那份平时是透明的。「衣服非表示」= 1 时两份对调，所以 g05 的衣服当初就要贴在裸体那份上（第 5 步的「目标的裸体材质」）。

9换成游戏材质（可选）

  1. 点一下模型，侧栏 MMD 页签找到「ROE 游戏材质」面板。
  2. 点「换上游戏原始材质」。第一次用某个角色要几十秒，之后几秒。
  3. 面板下面显示：「角色 a08 + a01×2 + g05×37：换了 46 个材质，保留 4 个（眼睛 / 睫毛 / 眉毛等），错误 0」
    • a08 = a08 自己的衣服、头发、脸；a01×2 = 两份身体（a08 用的是家族底模 a01 的身体）；g05×37 = 搬过来的 g05 衣服。
  4. 「游戏材质 / MMD 着色」两个按钮来回切，对比最明显。「衣服非表示」在游戏材质下照样管用。
这一步要用 10-25 修过的插件（0.1.1）。今天之前打开的 Blender 要重启一次才会用上新版；旧版只会换 a08 的 7 个材质，g05 的衣服和身体不变。 自己在 mmd_tools 里解绑、重新绑定过表情滑块的话，点一下「游戏材质」按钮重新接上。

10跳个舞看看（可选）

  1. 选中模型，菜单 文件 → 导入 → MikuMikuDance Motion (.vmd)，选默认测试舞： E:\Downloads\mmd\0.meeynara手势舞2025.2.14by小王动画\适配瓦雷莎.vmd
  2. 侧栏 MMD 页签最上面那个面板里，「物理:」那一行点「建立」，让刚体开始算物理。
  3. 按 空格 播放。看前片、披帛会不会穿进腿，拉「衣服非表示」= 1 再看胸带。

在 Blender 里删不要的零件

  1. 点模型的网格，按 Tab 进编辑模式，按 Alt+A 先全部取消选择。
  2. 右边属性编辑器点材质页（红色小球图标），在材质列表里点一个 g05_…，点下面的「选择」。
  3. 按 X → 面，这块就删掉了。要删 a08 自己的衣服也一样，选 pc_a08_hd_body1 / body2。
  4. 删完按 Tab 回物体模式。在大纲视图里点模型最上层的根（名字 Pc A08 Hd Full 穿G05衣服）。
  5. 菜单 文件 → 导出 → MikuMikuDance Model (.pmx)，右边勾上「复制纹理」，存到一个新文件夹。

也可以用 PMXEditor：打开 PMX，在材质页按名字删材质（顶点会一起删），另存。

现在删材质只会删掉顶点，那件衣服的骨头、刚体、关节还在：看不见的布照样在算物理，偶尔会挡到别的布。 要彻底去掉，还得把对应的刚体删掉（比如披帛的 Riband_BL_…）。「勾选零件 → 连骨头、刚体一起删」的按钮在待做清单第 3 项里。
