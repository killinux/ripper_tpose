准备

用 Blender 3.6（D:\Program Files\blender-3.6.15-windows-x64\blender.exe），三个插件都已经装在里面。

做完的效果：Fiona 穿盔甲跳「最佳男主角」；第 2 秒黑色血管从胸口爬满盔甲，黑色黏液把她裹住；第 3–4 秒白裙子从黏液里由上往下长出来，腿上的黏液最后退掉。

1第一步：启用游戏材质插件（只做一次）

  1. 编辑 → 偏好设置 → 插件。
  2. 右上角搜索框输入 Vindictus，勾选 Material: Vindictus Game Materials。
  3. 关掉偏好设置窗口。以后打开 Blender 都是开着的（没开「自动保存偏好设置」的话，点左下角菜单 → 保存偏好设置）。

2第二步：导入两个模型

两个模型都用 Scale 0.08 导入，导入后叠在原点，这是对的。

  1. 文件 → 新建 → 常规。左键点中间的立方体，按 X → 删除。
  2. 文件 → 导入 → MikuMikuDance Model (.pmd, .pmx)。
  3. 文件窗口右侧的选项里把 Scale 改成 0.08（看不到选项就点右上角齿轮）。
  4. 地址栏粘贴 E:\game_export\Vindictus\Fiona\pmx\Fiona\ 回车，选 Fiona.pmx，点右下角 Import Model File。
  5. 同样导入 E:\game_export\Vindictus\Fiona\pmx\PCF_005\PCF_005.pmx，Scale 也是 0.08。
做对的样子：大纲视图最上层多了 Fiona 和 PCF 005 两个物体（模型的根，后面选模型就点它们），两套衣服叠在一起，人高约 1.8 米。

3第三步：换上游戏材质

一定要在第六步「生成变身效果」之前做：变身插件生成时会把效果接到当时的材质上。

  1. 鼠标放在 3D 视图里按 N 打开侧边栏，切到 MMD 标签，找到「Vindictus 游戏材质」面板。
  2. 大纲视图里点 Fiona，点「换上游戏原始材质」。第一次要扫一遍存档，十几秒。面板下面会显示「Fiona：换了 19 个材质……没找到 0 个」。
  3. 大纲视图里点 PCF 005，再点一次「换上游戏原始材质」，显示「PCF_005：换了 15 个材质」。
  4. 按 Z →「材质预览」看效果：盔甲有金属光泽，裙子有布纹。面板上「游戏材质 / MMD 着色」可以来回切着比较。

4第四步：给两个模型都加上舞蹈

同一个 VMD 给 Fiona 和 PCF 005 各导入一次，参数一样，两套衣服就同步跳。

  1. 大纲视图里点 Fiona。
  2. 文件 → 导入 → MikuMikuDance Motion (.vmd)，选 最佳男主角.vmd。
  3. 右侧选项：Scale = 0.08，Margin = 30（开头留 1 秒从站姿过渡进舞蹈），Update scene settings 保持勾选。
  4. 点 Import VMD File (.vmd)。
  5. 大纲视图里点 PCF 005，重复第 2–4 步。
做对的样子：时间轴变成 1–274 帧（30 帧过渡 + 244 帧舞蹈），按空格两套衣服一起跳、完全重合。看完按 Esc，把时间轴拖回第 1 帧。

5第五步（可选）：北方遗迹背景

不要背景就跳过这一步（第八步用白色环境光）。要背景就在第六步之前做完，因为变身生成时会记下她站的位置。

  1. 文件 → 附加，打开 E:\game_export\Vindictus\_disperse\场景和材质\北方遗迹场景\northruin_v3v.blend，进 Object 文件夹，按 A 全选，点「附加」。1878 个物体，要等一会。
  2. 再 文件 → 附加，同一个文件，进 World，选 VDF_Sky，点「附加」。
  3. 属性面板 → 世界属性（红色地球图标），最上面的世界下拉框选 VDF_Sky（游戏的天空和光）。
  4. 大纲视图里点 Fiona，侧边栏切到「条目」标签，「变换」里填：位置 X 842、Y -355、Z -64.82，旋转 Z 100°。
  5. 大纲视图里点 PCF 005，填一样的数。
做对的样子：她站在遗迹东边的土路上，面朝废墟。场景自带太阳 VDF_Sun，不用再加灯。

6第六步：设置毒液变身并生成

按顺序点，预设一定先选：它会改掉一批参数，后选会把前面改的盖掉。

  1. 侧边栏切到「MMD 变身」标签。
  2. 点最上面的「预设」→「毒液共生体」。
  3. 大纲视图里点 Fiona，再点「旧服装（变身前）」右边的吸管；点 PCF 005，再点「新服装（变身后）」右边的吸管。
  4. 取消勾选「跟随旧模型骨架」。
  5. 「开始帧」填 45，「结束帧」填 180：第 1.5 秒开始，第 6 秒换完。
  6. 「方向」保持「穿上（旧→新）」，勾选「留在原地」。
  7. 展开「旧服装处理」，勾选「保留共用部分」，材质栏填 *face01*;*hair*：脸和头发一直用 Fiona 的，不会出现两张脸。
  8. 回到面板上方点「生成变身效果」。界面会卡半分钟到两分钟，插件在把舞蹈从头播一遍、记录每个点的位置，等它跑完。

7第七步：预览

按 Z →「材质预览」，拖动时间轴看。两个高模加几何节点，按空格播放会掉帧，拖着看更准。

8第八步：灯光、相机和出视频

渲染设置（两种背景都一样）

  1. 渲染属性（相机背面图标）：渲染引擎 EEVEE；勾选「环境光遮蔽」和「辉光」；「色彩管理」→「查看变换」选 标准。
  2. 输出属性（打印机图标）：分辨率 X 720、Y 1280、100%；帧范围 1–274 在第四步已经自动设好。
  3. 「输出」：选保存的文件夹；文件格式 FFmpeg 视频；编码 → 容器 MPEG-4，视频编解码器 H.264，音频编解码器 AAC。
  4. 音乐：把任意一个编辑器切成「视频序列编辑器」，添加 → 声音，选 10月21日.WAV，把它的起始帧拖到 31（舞蹈从第 31 帧开始）。

没有背景（跳过了第五步）

  1. 世界属性：「颜色」改成白色，「强度」填 0.75。
  2. 大纲视图里选中自带的点光（Light），按 X 删掉；添加 → 灯光 → 日光，强度 0.8，旋转 X 50°、Y 0°、Z -30°。
  3. 选中相机，「条目」→「变换」：位置 X 0、Y -4.4、Z 0.95，旋转 X 89.4°、Y 0、Z 0；相机属性里焦距填 75 mm。

北方遗迹背景（做了第五步）

  1. 大纲视图里选中自带的点光（Light），按 X 删掉，场景的太阳和天空就够了。
  2. 选中相机，「变换」：位置 X 846.36、Y -354.23、Z -63.87，旋转 X 89.3°、Y 0、Z 100°；焦距 75 mm。

按小键盘 0 看相机画面，人应该在正中、头脚都在画里。最后 渲染 → 渲染动画（Ctrl+F12）。

和视频里不一样的地方

视频是用脚本做的，比手动多了几样。不做也不影响变身效果：

  • 胸部晃动：视频里用 MMD Physics 插件的弹簧骨骼（Vindictus 游戏里的数值）单独烘焙，盔甲的胸保持不动；手动不开物理，胸不晃。
  • 头发、裙子的物理：视频里两个模型的刚体分在不同碰撞层，互不干扰；手动按上面的说法别开物理最省事。
  • 肘部更圆滑（SDEF）：选中模型 → MMD 标签 → MMD SDEF Driver → Bind，两个模型各点一次。它是 Python 驱动器，要在 编辑 → 偏好设置 → 保存&加载 里勾「自动运行 Python 脚本」。
  • 相机运动：视频里相机从头到尾左右慢慢转 ±10°，第 180–225 帧推近到半身。手动可以在这两帧给相机的位置、旋转各打一个关键帧（鼠标放在数值上按 I）。
  • 左上角字幕：后期加的。

换别的衣服就改第二步的两个文件；换效果就在第六步换预设，再点一次「生成变身效果」。第三步的游戏材质对存档里 Fiona 的全部 PMX 都能用，插件说明在 E:\code\othercode\ripper_tpose\scripts\blender_addons\vindictus_game_materials\README.md。
