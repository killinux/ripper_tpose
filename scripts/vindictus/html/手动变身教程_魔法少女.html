准备

用 Blender 3.6（D:\Program Files\blender-3.6.15-windows-x64\blender.exe），两个插件已经装在里面。做完的效果：Fiona 跳手势舞，第 2 秒从手脚开始变身，第 7 秒换成 PCF_005 的魔法少女装。

1第一步：导入两个模型

两个模型都用 Scale 0.08 导入，导入后它们叠在原点，这是对的。

  1. 文件 → 新建 → 常规。当前文件里有要留的东西先保存。
  2. 左键点中间的立方体，按 X → 删除。
  3. 文件 → 导入 → MikuMikuDance Model (.pmd, .pmx)。
  4. 文件窗口右侧是导入选项（看不到就点右上角齿轮），把 Scale 改成 0.08，其他不动。
  5. 地址栏粘贴 E:\game_export\Vindictus\Fiona\pmx\Fiona\ 回车，选中 Fiona.pmx，点右下角 Import Model File (.pmd, .pmx)。等十几秒，原点会站着穿盔甲的 Fiona。
  6. 再导入 E:\game_export\Vindictus\Fiona\pmx\PCF_005\PCF_005.pmx，Scale 同样是 0.08。
做对的样子：右上角大纲视图最上层多了 Fiona 和 PCF 005 两个物体（模型的根物体，后面选模型就点它们）；两套衣服叠在一起，人高约 1.8 米。人大得出屏幕（约 22 米高）就是 Scale 还是 1.0，删掉重新导入。

2第二步：给两个模型都加上舞蹈

同一个 VMD 给 Fiona 和 PCF 005 各导入一次，参数完全一样，两套衣服就同步跳舞（原因见注意事项）。

  1. 大纲视图里点 Fiona（最上层那个）。
  2. 文件 → 导入 → MikuMikuDance Motion (.vmd)，地址栏粘贴 E:\Downloads\mmd\0.meeynara手势舞2025.2.14by小王动画\，选 适配瓦雷莎.vmd。
  3. 右侧选项改三处：
    • Scale = 0.08（和模型一致）
    • Margin = 30：开头留 30 帧从站姿过渡进舞蹈，和视频一致
    • Update scene settings 保持勾选：自动把帧率设成 30、帧范围设成 1–334
  4. 点右下角 Import VMD File (.vmd)。
  5. 大纲视图里点 PCF 005，重复第 2–4 步，参数一样。
做对的样子：时间轴变成 1–334 帧，按空格两套衣服一起跳，完全重合。只有一套在动就是第 5 步漏了；人飞出画面就是 Scale 没填 0.08。按 Esc 停止播放，把时间轴拖回第 1 帧再做下一步。

3第三步：设置变身并生成

按顺序点，预设一定先选：它会改掉一批参数，后选会把前面改的盖掉。

  1. 鼠标放在 3D 视图里按 N 打开侧边栏，切到「MMD 变身」标签。
  2. 点最上面的「预设」→「魔法少女」。
  3. 大纲视图里点 Fiona，再点「旧服装（变身前）」这一行右边的吸管。
  4. 大纲视图里点 PCF 005，再点「新服装（变身后）」右边的吸管。
  5. 取消勾选「跟随旧模型骨架」。
  6. 「开始帧」填 60，「结束帧」填 210：第 2 秒开始变，第 7 秒换完。
  7. 「方向」保持「穿上（旧→新）」，勾选「留在原地」：碎片留在空中，不跟着她的动作甩。
  8. 往下展开「旧服装处理」，勾选「保留共用部分」，材质栏填 *face01*;*hair*：脸和头发始终用 Fiona 的，不会出现两张脸。
  9. 回到面板上方，点「生成变身效果」。
生成时插件把舞蹈从头播一遍，记下每个点被变身扫到时的位置，界面会卡一两分钟（测试里 83 秒），等它跑完。做完场景里会多一个叫 MMD Disperse Mask 的空物体，它的大小就是变身进度，关键帧已经打好。

4第四步：预览

切到材质预览就能看到变身；光晕要等第五步开了「辉光」，在「渲染」着色里才看得到。

  1. 鼠标放在 3D 视图里按 Z →「材质预览」（或点视图右上角第三个小球）。
  2. 拖动时间轴看。两个高模加几何节点，按空格播放会掉帧，拖着看更准。
帧应该看到
1–30从站姿过渡进舞蹈
30–60穿盔甲的 Fiona 跳舞
60–210先从手脚亮起粉色光剪影，光带绕着手脚转，盔甲碎成发光的碎片飘走，白裙子逐渐长出来
约 210新衣服完整的一刻整身闪光，迸出星星
210–334穿 PCF_005 继续跳舞，头冠、耳环、手臂饰品跟着动

想改效果就改完参数再点一次「生成变身效果」，不用重新导入。

5第五步：灯光、相机和出视频

照视频的 MMD 观感设：EEVEE + 辉光 + 「标准」色彩，白色环境光加一盏日光，竖屏 720 × 1280。属性面板在屏幕右下方，左边一列小图标是各个页签。

  1. 渲染属性（相机背面图标）：
    • 渲染引擎 = EEVEE
    • 勾选「辉光」，魔法少女的光晕靠它
    • 「色彩管理」→「查看变换」= 标准：贴图颜色原样显示，默认的 Filmic 会发灰
  2. 世界属性（红色地球图标）：「颜色」改成白色，「强度」填 0.75。
  3. 大纲视图里选中新文件自带的点光（名字是 Light 或「灯光」），按 X 删掉；再 添加 → 灯光 → 日光，在灯泡图标页把「强度」改成 0.8，在物体页（橙色方块图标）把旋转设成 X 50°、Y 0°、Z -30°。
  4. 输出属性（打印机图标）：分辨率 X 720、Y 1280、100%；帧范围 1–334、帧率 30 在第二步已经自动设好。
  5. 相机：按小键盘 1 切到前视图，用滚轮和 Shift+中键把人放在画面中间；选中相机，按 Ctrl+Alt+小键盘 0 把相机对到当前视图，再按小键盘 0 看相机画面。她抬腿、举手时会变宽变高，上下左右留点空。
  6. 输出属性里的「输出」：选保存的文件夹；文件格式选 FFmpeg 视频，编码 → 容器 MPEG-4、视频编解码器 H.264；要音乐的话音频编解码器选 AAC。
  7. 音乐（可选）：把任意一个编辑器切成「视频序列编辑器」，添加 → 声音，选 meeynara手势舞2026.2.14.WAV，把它的起始帧拖到 31（第 1 秒，舞蹈从这里开始）。
  8. 菜单 渲染 → 渲染动画（Ctrl+F12）。纯色背景大约每帧 4–5 秒，334 帧约 25 分钟，进度看弹出的渲染窗口。

注意事项和常见问题

最容易出错的是缩放和「跟随旧模型骨架」这两处，先对照下表。

现象原因怎么办
人约 22 米高，或跳舞时飞出画面模型或 VMD 的 Scale 不是 0.08（这版 mmd_tools 默认 1.0，对话框会记住上次的值）删掉重新导入，模型和舞蹈都填 0.08
头冠、耳环、手臂羽饰拉出横穿画面的长条「跟随旧模型骨架」开着取消勾选，确认两个模型都导了舞蹈，再点生成
只有一套衣服在动第二步只给一个模型导了舞蹈选中另一个模型再导一次同一个 VMD
面前两张脸叠在一起没勾「保留共用部分」，或勾完没重新生成填 *face01*;*hair* 后再点一次生成
头发、裙子乱飞或炸开开了物理：两套模型叠在一起，各自的刚体互相碰撞不要点侧边栏 MMD 标签里的 Physics: Build；已经点了就点 Clean
看不到发光视图不是材质预览 / 渲染着色，或没开「辉光」按 Z 切着色模式，渲染属性里勾「辉光」
点生成后界面卡住插件在把舞蹈播一遍记位置正常，等 1–2 分钟
  • 为什么要关「跟随旧模型骨架」：勾着时，插件把新服装直接绑到旧模型的骨架上。PCF_005 的头冠、耳环和手臂羽饰用的骨骼 Fiona 没有，这些点就停在原地。两个模型各跳一遍同一个舞蹈，动作完全一致，就绕开了这个问题。
  • 物理：不开物理只是头发和裙子不飘，变身效果不受影响。视频里的胸部晃动是另外用弹簧骨骼烘焙的，手动实验不需要。
  • 肘部更圆滑（可选）：选中模型 → 侧边栏 MMD 标签 → MMD SDEF Driver → Bind，两个模型各点一次。它靠 Python 驱动器，要在 编辑 → 偏好设置 → 保存&加载 里勾「自动运行 Python 脚本」。
  • 深色背景：世界颜色保持白色照亮人物，在 渲染属性 → 胶片 里勾「透明」，输出 PNG（RGBA），之后在剪辑软件里垫任意背景。
  • 改参数：边缘、线框、粒子、发光这些面板改了立即生效；路径、起点、帧范围、方向、保留共用部分改了要再点一次「生成变身效果」。

继续试：换衣服、换效果

换一对衣服只要改第一步的两个文件和第三步的预设、锁定材质，其余步骤不变。视频计划里的七对如下，文件都在 E:\game_export\Vindictus\Fiona\pmx\<名称>\<名称>.pmx。

1Fiona → PCF_005魔法少女*face01*;*hair*
2PCF_067 → PCF_009装甲换装*face01*
3PCF_001_Temp → PCF_010冰封碎裂*face01*
4PCF_007 → PCF_003燃烧成灰*face01*
5PCF_001 → PCF_008故障风*face01*
6PCF_012 → PCF_006纳米流动*face01*;*hair*
7PCF_004 → PCF_002残影汇聚*face01*;*hair*

只锁 *face01* 的配对，头发会跟着衣服一起换。预设菜单里一共 33 种（纳米战衣、灰飞烟灭、毒液共生体、液态金属、金币迸发、魔法阵穿身、水墨晕染、钢铁侠 Mark 50 等），换一个再点一次「生成变身效果」就能看。
