附录 · 导出脚本用法

脚本在 scripts\doa6\，需在装有游戏的机器上运行。 完整说明见同目录 EXPORT_GUIDE.md（操作）与 README.md（格式与原理）。

角色由三个部件组成

部件条目名来源
服装 + 身体<角色>_COS_NNNCharacterEditor.rdb
脸<角色>_FACE_NNNCharacterEditor.rdb
头发<角色>_HAIR_NNNCharacterEditor.rdb
贴图MPR_Muscle_Character_<角色><COS><NNN>_…MaterialEditor.rdb（45GB）

一键出带材质 blend（export_full.ps1）

cd E:\code\othercode\ripper_tpose\scripts\doa6

.\export_full.ps1 KAS -Label KAS_Kasumi        # 默认 COS_001/HAIR_001/FACE_001
.\export_full.ps1 MOM -Cos 102 -Label MOM_DLC  # 指定服装编号
.\export_full.ps1 -List                        # 列出全部 1536 个模型

产物是 _blends\<Label>.blend（贴图已打包）和同名 _preview.png。

mod 变体（含 nude）

.\export_nude_mod.ps1 D:\mods\xxx.zip -Chr HEL -Label HEL_Helena_Nude
.\export_nude_mod.ps1 D:\mods\ayane.zip -Chr AYA -Label AYA_Malf -Assign "3=f01,5=body"

吃 REDELBE layer2 mod（zip 或目录），自动接上该角色已导出的官方发型/脸。 紫色徽标标出的就是这类变体。两条材质路线自动选择：

路线触发条件可靠性
A 精确mod 替换的服装编号本机有（如 HEL_COS_001）→ 走原版 ktid 链一次到位
B 启发式替换未安装的 DLC 位（如 MOM_COS_105）→ 按网格大小猜部位多数一次对，弄反时用 -Assign 纠正
官方内容没有 nude（逐条目核实过）。mod 主要来源： GameBanana（game id 6966，可脚本化直连下载，但多为微比基尼/走光级别）； 全裸整合包在 LoversLab / DeviantArt，需登录手动下载。

已知坑

症状原因 / 处理
Noesis 打开就崩别用 Cethleann.DataExporter 解 DOA6：它的 zlib 每块只读一次，1536 个 g1m 里 1300 个在 ~80% 处截断，坏文件让插件静默崩溃。 用仓库的 extract_rdb.py
客串角色导出失败NIC / MAI / SNK 的 COS_000~003 是无 ktid 的占位调试体，正装从 COS_004 起
Phase 4 头发是白模她的 HAIR_001 在 MaterialEditor 里确实没有贴图
mod 变体皮肤/衣服贴图弄反路线 B 的启发式猜错，按脚本打印的 assign 把两个部位对调后加 -Assign 重跑
.ps1 报 missing terminator脚本被存成无 BOM 的 UTF-8， PowerShell 5.1 按 GBK 解析吞掉引号；用 UTF-8 with BOM 重存

重新生成本页

blender --background --factory-startup --python scripts\doa6\html\collect_manifest.py
python scripts\doa6\html\make_gallery.py

第一步用 Blender 打开每个 blend 收集网格/材质/贴图统计写成 manifest， 第二步把预览图缩成 JPEG 放进 _gallery\thumbs\ 并重写本页。 缩略图刻意不进仓库 —— 和其它脚本一样，仓库不收任何游戏素材。
