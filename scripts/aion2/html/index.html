怎么导出模型（操作说明）

下面列的是游戏里的全部 3D 模型。导出 = 从游戏的资源包里读出网格、骨架、材质参数和贴图， 做成能直接打开的 .blend（材质已经烘成普通的颜色 / 粗糙度 / 金属度 / 法线贴图），并渲三张检查图。 不用启动游戏、不用联网；需要一把 AES 密钥（第 0 步）。脚本都在 E:\code\othercode\ripper_tpose\scripts\aion2。

最短的路：三条命令 （第一次用，先做下面的「第 0 步」）
  1. 打开 PowerShell，进到脚本目录：
    cd E:\code\othercode\ripper_tpose\scripts\aion2
  2. 导出一个模型。这里是 Yustiel；换别的就把 NPC_Yustiel_01 换成它的 id —— 下面「全部模型」每一行的「复制」就是它自己的这条命令：
    python export_model.py NPC_Yustiel_01
    约 2 分钟。最后一行是 done: …\NPC_Yustiel_01.blend 就成了。
  3. 刷新本页：「已导出」里会多出这张卡片（预览图、.blend 的位置）。
    python html\make_gallery.py约 5 秒
第 0 步　准备（只做一次）
  1. Python 3 和三个包：numpy、Pillow、cryptography 本机已有
    pip install numpy pillow cryptography
  2. 游戏装在 D:\Program Files (x86)\Steam\steamapps\common\AION2 本机已有（别处就在命令后面加 --game-root 路径）。
  3. AES 密钥：一行 0x… 写在 E:\tools\aion2\_keys\aes_key.txt，或者放进环境变量 AION2_AES_KEY 本机已有。 游戏的资源包是加密的，没有它什么都读不出来。密钥不进仓库，从哪来、游戏更新后怎么判断它失效了，见 README 的「容器和密钥」一节。
  4. Oodle 解压库 E:\tools\cue4parse_cli\oodle-data-shared.dll 本机已有（--oodle 可改）。
  5. UE Viewer 的 UE5 特制版（Gildor 论坛 spiritovod 的版本）E:\tools\umodel_specific\materials\umodel_materials_ue5.exe 本机已有（--umodel 可改）。 普通版的 UE Viewer 读不了这个游戏。
  6. Blender 3.6 D:\Program Files\blender-3.6.15-windows-x64\blender.exe 本机已有（--blender 可改），装好 PSK 导入插件 io_scene_psk_psa 本机已有（插件装上就行，脚本运行时自己启用）。
  7. 建索引：读一遍游戏里全部 48 万个包的包头，记下每个包是什么（网格、贴图、材质……），再写模型总目录。
    python list_models.py --scan读全部包头（6 个进程，约 1 分钟）
    python list_models.py --catalogue写模型总目录，顺便判断 NPC / 怪物的性别
    实测（全新的空目录）：第一条 53 秒，第二条十几秒。游戏更新后第一条要重跑（会提示 class cache is from another game version）。

第 1 步　找到要导的模型

在这一页找：工具栏的搜索框输名字（英文 id 里的一段，例如 leda、angel、maid）； 类别按钮、「只看女性」「只看已导出」可以叠加。「全部模型」每一行最后是导出命令，点「复制」。

在命令行找：

python list_models.py全部模型按类别和性别计数（共 6,426 个）
python list_models.py --find yustiel leda siel按名字找，列出 id 里含任一个词的；支持 * ? 通配符（--find "gf_*maid*"）
python list_models.py --women --kind npc女性 NPC（83 个，含修果族等非人类；儿童不算）
python list_models.py --kind costume --gender GF女性时装（97 套）；--kind outfit 是编号盔甲套装
python list_models.py --kind hair --gender GF女性发型（103 款）；--kind head 是脸（59 张）
python list_models.py --resolve GF_Angel_01一个模型由哪些部件拼成（导出时会用到哪些游戏包）
python list_models.py --catalogue重写模型总目录 _meta\aion2_models.json（本页读它）

id 的规则：

类别id 的样子说明
玩家的套装GF_0001_T04、GF_Angel_01 GF = 女、GM = 男。编号盔甲 = <性别>_<编号>_T<阶>；时装用英文名（Angel、Maid、Qipao、Swimsuit_07……）。 导出时自动配脸和发型
脸、发型GF_Head_001、GF_Hair_308给套装用的 --head / --hair；也能单独导
NPCNPC_Yustiel_01、NPC_F_Refugee_01 有名字的角色用名字；路人用 NPC_F_…（女）/ NPC_M_…（男）
怪物、BossMOB_Cromede_01_V01、_CV01 是换色 / 变体
过场动画里的NPC_Siel_01、Seq_Cromede_01_V02_Body用游戏里的文件名；有些只有身体或只有头

「女性」怎么认的：玩家部件看 GF；NPC、怪物、过场模型游戏里没有性别字段，按顺序看四条，先成立的算数： ① 名字里有 F_ / M_；② 名字里的词以 F / M 结尾（VillagerF、ShugoAF）； ③ 网格用了玩家女性的部件（Yustiel 的脸、Leda 的头发都是玩家的）；④ 骨架里有女性的胸部骨。名字或文件夹里有 Kid / Child 的是儿童， 不算进「女性」。全部模型里每一行的 ♀ 悬停能看到是按哪一条认的。没逐个看图，可能差一两个。

第 2 步　导出

一个模型

python export_model.py NPC_Yustiel_01一个 NPC，原样导出（身体、头、头发都是它自己的）
python export_model.py GF_Angel_01一套女性时装：自动配上 001 号脸、001 号发型；时装没有的身体部位用底模补
python export_model.py GF_Angel_01 --hair GF_Hair_308 --head GF_Head_006换发型、换脸；输出文件夹名会加后缀（GF_Angel_01__Head_006__Hair_308）
python export_model.py GF_Cat_03 --variant B同一部位有 A / B 两版的（猫咪装、企鹅装的兜帽）用 B 版，默认 A
python export_model.py GF_0001_T04 --keep-hair全盔默认会按游戏的设置换成贴头皮的短发或剪掉头顶的头发；加这个保留原发型

这条命令做了什么

  1. 拼部件（list_models.resolve）：找出这个模型由哪些网格组成。玩家套装 = 套装的身体、裤子、手套、鞋、头盔、肩甲、披风 + 脸 + 发型；套装没有身体 / 裤子时用底模补。戴全盔时按游戏的设置换发型或剪头发。
  2. UE Viewer 导出：每个部件调一次 UE Viewer，导出网格（.psk）、材质参数（.props.txt）和贴图（.png） 到 E:\aion2_exports\umodel_exports（已经有的跳过）。第一次每个部件 10–20 秒（实测 Yustiel 5 个部件 75 秒），之后几乎不花时间。
  3. 烘材质（bake_materials.py）：游戏的材质是运行时合成的，直接用导出的贴图是灰的。按材质类型（盔甲染色、皮肤、脸和眉毛、 眼球、睫毛、头发）算成普通的颜色 / ORM / 自发光贴图 → <输出>\textures\，记录在 materials.json。
  4. 建 .blend（Blender 3.6 在后台运行，20–80 秒）：导入各部件，按骨骼名把骨架合成一副，接上材质，保存，渲正面、背面、脸部三张图。

第 4 步　出问题时：终端里的话是什么意思
看到意思怎么办
no class cache yet: run python list_models.py --scan first还没建索引做第 0 步最后一条
class cache is from another game version - run with --scan游戏更新过python list_models.py --scan，再 --catalogue
encrypted container needs the AES key找不到密钥第 0 步第 3 条
解出 0 个路径、包头读出来是乱码密钥不对（游戏更新换了密钥）README「容器和密钥」：找新的公开密钥
AION2 Paks folder not found游戏不在默认位置加 --game-root
unknown model or part …id 拼错了，或 --head / --hair 给的不存在python list_models.py --find 名字的一段
umodel …: nothing exported 和 MISSING PSK for <部件>UE Viewer 没读出这个部件 这个部件会缺，其余照常；检查 UE Viewer 是不是特制版、密钥对不对
material … not exported by UE Viewer这个材质没导出来那块面是灰的；--force 重导一次
eyebrow texture slice N not found眉毛贴图缺这一张脸上没有画眉毛，其余正常
Blender failed (rc N) 加 25 行日志Blender 那一步出错看日志最后几行；常见的是 Blender 路径不对、PSK 插件没装
no nude recipe yet: run python nude_survey.py …要先量一次底子照提示跑那条命令
已知的不足
  • 脸部妆容只做了眉毛（眼影、眼线、唇妆图层没烘）；捏脸变形（MorphTarget）UE Viewer 导不出来，所以没有表情。
  • NPC 的头发如果用的是玩家发型（Leda），颜色是那款发型材质的默认色，游戏里 NPC 可能另外调过。
  • 有些 NPC 文件夹里只有头或只有头盔（Grisilla、Chloris），剩下的部分游戏是按 NPC 外观数据拼的，这部分数据还没解。
  • 自发光（光环、Siel 裙子上的亮片）按材质里的强度烘，静止的图里会比游戏里亮；在 Blender 材质里调 Emission Strength。
  • 完整清单见 README 的「已知限制」。
