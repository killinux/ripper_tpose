# PMX Outfit Transfer —— 把一个 PMX 的衣服贴身穿到另一个 PMX 上（Blender 插件）

给 PMX 模型之间**换衣服、拼衣服**用：选一个模型的衣服材质，连同它们的骨骼、刚体、关节、材质和贴图，搬到另一个模型上，
按目标的裸体形状贴身拟合，写出一个新的 PMX。两套衣服的刚体互不碰撞，原来的两个文件都不动。

```
scripts/blender_addons/pmx_outfit_transfer/
  __init__.py   Blender 插件入口：侧栏 MMD 页签 → 换装（服装移植）、挑零件
  core.py       算法：骨骼重定向 + 身体形状场 + 按面坐标系贴合；骨骼/刚体/关节/材质/贴图搬运；碰撞组隔离
  cli.py        命令行：blender -b --factory-startup --python cli.py -- 源.pmx 目标.pmx 输出.pmx [选项]
  parts.py      挑零件：删材质时连同只给它用的骨骼、刚体、关节、表情项、贴图一起删（任何 PMX 都能用）
  pick_cli.py   挑零件的命令行：python pick_cli.py 模型.pmx [输出.pmx] --remove "a,b" [选项]
```

2026-10-24 第一个用例：Luf g05（女神装）的整套衣服 → Inase a08 full 的裸体（成品 `_混搭\a08_full_穿g05衣服\`）。

为它加了「贴身部分跟着皮肤动」（默认开）和裸体模型的「衣服非表示」。

## 安装

和仓库里其他插件一样用目录联接装进 Blender 3.6，本机已装好：

```powershell
New-Item -ItemType Junction -Path "$env:APPDATA\Blender Foundation\Blender\3.6\scripts\addons\pmx_outfit_transfer" `
         -Target "E:\code\othercode\ripper_tpose\scripts\blender_addons\pmx_outfit_transfer"
```

「编辑 → 偏好设置 → 插件」里搜 `PMX Outfit Transfer` 勾选（已经开着的 Blender 要重启或 F3「Reload Scripts」）。
需要 mmd_tools（读写 PMX、把结果导入场景）。

## 用法

面板在 3D 视图侧栏（`N`）的 **MMD** 页签，「换装（服装移植）」：

1. **衣服来自**：提供衣服的 PMX；**穿到**：目标 PMX；**输出 PMX** 留空就在目标旁边新建「`<目标>_穿<前缀>衣服`」文件夹。不会覆盖已有文件。
2. 点「**读取源模型的材质**」：列出源的全部材质，身体 / 脸 / 头发 / 眼睛 / 武器默认不勾，其余默认勾上；勾选要搬的。
   同时认出两边的身体材质（ROE：源用 `*_nk_body`，目标用 `*_nk_body_nude`），认错了手改。
3. 选项（默认就是 g05 → a08 用的）：
   - **按身体形状贴身拟合**：关掉只按骨骼位置重定向；
   - **贴身距离 / 远离距离**：离源身体 2 cm 以内的衣服完全跟着身体形状走，12 cm 以外只跟骨骼（光环、法杖、长披帛的末端），中间渐变；
   - **按骨骼方向旋转**：两个模型休息姿势不同（T 形 / A 形）时需要，相同时没影响；
   - **拆分材质**：「按挂的骨头」一根骨头一个材质（`g05_body2_Leaf_L`、`g05_body1_Riband_M`……），挑零件方便；「按连通块」每块布一个；「不拆」原样；
   - **贴身部分跟着皮肤动**（2026-10-25 起，默认开）：离目标皮肤 1.5 cm 以内的衣服改用皮肤在那里的权重，再往外 2 cm 渐变回衣服自己的；
     胸带、腰带、腿环跳舞时和皮肤一起动，皮肤基本不会顶出来。挂在衣服物理骨上的份额（前片、披帛、吊坠）不变，目标的身体一点不动；
   - **两套衣服的刚体互不碰撞**、**新衣服碰目标的身体**；
   - **加进「衣服非表示」**：full 版拉这个表情时新衣服也一起藏。默认不加：拉「衣服非表示」= 脱掉目标自己的衣服、留下新衣服，正好是「新衣服穿在裸体上」。
     目标是裸体模型（没有「衣服非表示」）时，勾上就新建一个只管新衣服的「衣服非表示」（放在表情面板「其他」里）。
4. 点「**换装**」。十几秒后写出 PMX，默认再用 mmd_tools 导入场景。
5. 挑零件：用下面的「挑零件」面板（不要用 PMXEditor 删材质，那样骨骼、刚体、关节会留下）。要调位置就在 Blender 里改那块布的顶点。

### 挑零件（2026-10-31 起）

同一个页签的第二个面板「**挑零件（删掉不要的零件）**」，任何 PMX 都能用（换装、换头的成品，或者原版模型）：

1. **模型**：要挑的 PMX，留空就用上面换装刚写出的那个。点「**读取零件**」：一个材质一个零件，默认都勾着（= 留下）。
2. 把不要的去掉勾。三种方法：
   - 直接点勾；
   - **名字含** 填一段字（比如 `pc_a08_hd_body`、`g05_body2`、`wp_`），点「勾上」/「去掉」，名字里有这段字的一起改；
   - 在 3D 视图里选中模型网格上的面（编辑模式，`L` 选一整块），点「**去掉选中的面所在的零件**」。
3. **输出 PMX** 留空就写到模型旁边「`<模型>_挑零件.pmx`」（已有就 `_挑零件2`、`3`…）。不覆盖，原文件不动；换了文件夹会把贴图拷过去。
4. 点「**删掉没勾的零件**」。几秒钟，导入结果，场景里原来那个模型藏起来；列表换成新模型的零件，可以接着挑。

删一个零件时一起删的：
- 只有它用的顶点（别的零件也用的顶点留下）；
- 只挂在它上面的骨骼，连同骨链末端、根部没有权重的骨头。不删的：MMD 标准骨（`左手捩1` 这类，哪怕只有删掉的袖子用它）、
  留下的骨头的父骨 / IK 目标 / 付与亲，还有留下的物理链挂着的刚体；
- 这些骨骼上的刚体，碰到这些刚体的关节；
- 表情里指向它的项。表情只剩空壳的跟着删（只藏武器的「武器非表示」）；显示枠一样；
- 只有它用的贴图。

full 版的两份身体：删掉贴身那份（`*_nk_body`），裸体那份（`*_nk_body_nude`）自动改成默认显示，「裸体形状」随之没用了一起删；
反过来删掉裸体那份，「衣服非表示」就不再藏贴身那份（不然拉表情身体会消失）。

选项：「骨骼、刚体、关节一起删」关掉 = 只删网格和表情项，和在 PMXEditor 里删材质一样；「删掉变空的表情」关掉 = 空表情留着。

命令行：

```powershell
python scripts\blender_addons\pmx_outfit_transfer\pick_cli.py 模型.pmx --list            # 列出零件
python scripts\blender_addons\pmx_outfit_transfer\pick_cli.py 模型.pmx [输出.pmx] --remove "a,b" [--remove-like wp_] `
    [--keep "x,y"] [--dry-run] [--keep-bones] [--keep-empty-morphs]
```

`--dry-run` 只列出会删掉什么。Blender 里跑：`blender -b --factory-startup --python pick_cli.py -- ...`。

命令行（批处理、不开 Blender 界面）：

```powershell
& "D:\Program Files\blender-3.6.15-windows-x64\blender.exe" -b --factory-startup --python scripts\blender_addons\pmx_outfit_transfer\cli.py -- `
    源.pmx 目标.pmx 输出.pmx [--materials "a,b"] [--donor-body M] [--target-body M] [--no-fit] [--near 2] [--far 12] `
    [--no-rotation] [--split bone|island|none] [--prefix g05] [--no-isolate] [--no-body-collision] [--hide-morph 衣服非表示_材質] `
    [--no-follow-body] [--follow-reach 1.5] [--follow-fade 2]
```

普通 Python（装了 numpy）也能跑 `python cli.py ...`，最近点搜索用 numpy 暴力算，慢一些。

## 原理

1. **骨骼重定向**：衣服每个顶点按它的蒙皮权重，当作挂在目标同名骨头的休息位置上（线性混合蒙皮，每根骨头一个平移 + 可选的方向旋转）。
   目标没有的骨头：先在同一个父骨下找 5 cm 以内、没被占用的骨头按位置配（ROE 各家族胸骨名字不同：`chest_L02` / `Breast_L02` / `OPAI_L02`），
   配不上的连同到最近已配骨头之间的父链一起搬过来；两边都挂着物理、名字还一样的（两条都叫 `Skirt_L_01` 的裙链）改名搬。
2. **身体形状场**：源的身体（衣服是在它上面做的）同样重定向后，每个顶点找目标裸体上最近的点，位移场平滑 6 遍去掉拓扑噪声，再吸回目标表面。
   得到「源身体变成目标身材」的网格，拓扑不变。
3. **贴合**：在**源模型自己的空间**里，每个衣服顶点找源身体最近的面，记下在这个面坐标系里的偏移；面变到目标身材后，按同样的偏移放回去
   （和 Blender 的 Surface Deform 一个道理）。离身体远的部分按距离渐变回第 1 步的结果。
   偏移一定要在源的空间量：第 1 步之后衣服和皮肤可能已经错开（大腿环挂 `左足D`，皮肤挂 `ThighTwist`，两根骨头在两个模型里的相对位置不同）。
4. **物理**：衣服骨上的刚体、关节一起搬，位置按第 1–3 步同样移动；一头挂在源身体刚体上的关节改挂目标同名骨头的刚体（g05 胸前的吊坠挂到 a08 的胸部刚体上）。
   碰撞组：新衣服的动态刚体换到目标没用的组，目标的衣服刚体屏蔽这些组，新衣服只碰目标的身体碰撞体。
5. 材质、贴图真复制到输出文件夹的 `textures\`；新骨骼放进显示枠「`<前缀>衣服`」。
6. **权重**（贴身部分跟着皮肤动）：拟合之后，每个衣服顶点找目标裸体上最近的点，离皮肤 1.5 cm 以内用那个点的权重（三角形三个顶点的权重按重心坐标混合），
   1.5–3.5 cm 和衣服自己的权重线性混合，再远不变；挂在衣服物理骨（带动态刚体的骨，和它下面的骨）上的份额照旧。
   为什么：源的权重换到目标骨头上以后，胸、大腿这些地方和目标皮肤的分法不一样（g05 胸带挂胸骨的份额比 a08 皮肤小，胸一晃皮肤就顶出胸带）。
7. **挑零件**（parts.py）：删的材质 → 只被它们的面用到的顶点 → 权重只落在这些顶点上的骨骼，加上它们下面没有权重的骨（链尾）、
   子骨全删的没权重的骨（链根）；再把下面这些放回来，直到不变：MMD 标准骨名、留下的骨的父骨 / IK 目标和链 / 付与亲、
   留下的物理链挂着的刚体（删之前和某个跟骨骼走的刚体连着、删之后连不上的动态刚体，沿最短的关节路径把要删的刚体留下）。
   然后按新编号改一遍所有引用：顶点权重（权重为 0 的占位改指同一顶点的主骨）、骨的父骨 / 尾端（尾端骨被删就换成偏移量）/ IK / 付与、
   刚体的骨、关节的刚体、各类表情、显示枠、材质的贴图。写出前后各查一遍所有索引。
   换身体的表情（同一个材质表情里既有「透明度 ×0」又有「透明度 +」）：藏的全删了 → 显示的那份把这个偏移并进材质本身；显示的全删了 → 不再藏。

## 做不了 / 要自己来的

- 两边都要有裸体材质才能贴身拟合，没有就只按骨骼走（会提示）。
- 离皮肤远的衣服（宽松的长袍、光环）照旧用源的权重。2026-10-25 之前做的成品（`a08_full_穿g05衣服`）没有「贴身部分跟着皮肤动」，
  胸带下面的身体会顶出来：重新换一次装，或者用 `scripts/riseoferos/pmx_body_follows_cups.py` + `pmx_body_cover_cups.py` 处理。
- 源的表情（材质表情、顶点表情）不搬。
- IK 骨不搬 IK 设置。
- 远离身体的东西（法杖、光环）只按骨骼放，位置要自己看。
