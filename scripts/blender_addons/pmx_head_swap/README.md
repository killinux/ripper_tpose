# PMX Head Swap —— 给一个 PMX 模型换上另一个模型的头，脖子接缝看不出来（Blender 插件）

选一个模型的头（脸、眼睛、睫毛、眉毛、头发），连同它的骨骼、头发物理、贴图、表情换到另一个模型的身体上，写出新的 PMX。
脖子的接缝是**顶点对顶点焊接**的，接缝处法线、骨骼权重、肤色都做成连续的。目标自己的脸、头发（和头发物理、脸的表情）去掉。
两个原文件不动。

```
scripts/blender_addons/pmx_head_swap/
  __init__.py   Blender 插件入口：侧栏 MMD 页签 → 换头
  core.py       算法（共用 pmx_outfit_transfer/core.py 的底层：读写 PMX、骨骼配对、碰撞组隔离）
  cli.py        命令行：blender -b --factory-startup --python cli.py -- 头.pmx 身体.pmx 输出.pmx [选项]
```

2026-10-24 第一个用例：Luf g05 full 换上 Inase a08 的头，成品在 `E:\game_export\RiseOfEros\_混搭\g05_full_换a08头\`。
一步一步的用法（面板、选项、换完要做的、常见问题）见 [docs/pmx-head-swap-usage.md](../../../docs/pmx-head-swap-usage.md)，
原理和数字见 [docs/pmx-head-swap.md](../../../docs/pmx-head-swap.md)。

## 安装

目录联接（本机已装）：

```powershell
New-Item -ItemType Junction -Path "$env:APPDATA\Blender Foundation\Blender\3.6\scripts\addons\pmx_head_swap" `
         -Target "E:\code\othercode\ripper_tpose\scripts\blender_addons\pmx_head_swap"
```

偏好设置 → 插件，搜 `PMX Head Swap` 勾上。要同时装着 `pmx_outfit_transfer`（同一个目录，共用代码；不必启用）和 mmd_tools。

## 用法

侧栏（`N`）→ **MMD** 页签 →「**换头**」：

1. **头来自**：提供头的 PMX；**换到**：要换头的 PMX（身体留下）；**输出 PMX** 留空就在目标旁边新建 `<目标>_换<前缀>头\`。
2. 「**读取源模型的材质**」：脸、眼睛、睫毛、眉毛、头发默认勾上（按名字认：`_nk_face`、`eye_`、`lash`、`brow`、`_nk_hair` 等），
   头饰之类自己勾；「目标去掉的材质」自动填目标自己的同类材质（含 `_nude` 副本），可以改。
3. 选项：
   - **脖子过渡 cm**（默认 4）：头的脖子在接缝以上这段里逐渐变成身体那一圈的形状，法线和权重同样过渡；
   - **肤色**：「匹配 + 接缝渐变」（默认）整张脸贴图乘一个增益，让接缝上下的皮肤一样，剩下的局部差别烘成接缝带里的渐变；「只匹配整张」；「不动」；
   - **头的缩放**：以脖子那一圈为中心缩放整个头（默认 1）；
   - **做完导入场景**。
4. 「**换头**」。几秒钟。结果用 mmd_tools 导入场景，可以转着看脖子。

命令行：

```powershell
& "D:\Program Files\blender-3.6.15-windows-x64\blender.exe" -b --factory-startup --python scripts\blender_addons\pmx_head_swap\cli.py -- `
    头.pmx 身体.pmx 输出.pmx [--head "pc_a_nk_face,eye_portable,..."] [--remove "pc_g_nk_face,..."] [--blend 4] `
    [--tone seam|whole|none] [--scale 1.0] [--prefix a08]
```

普通 Python（numpy + Pillow）也能跑：`python cli.py …`。

## 原理（脖子为什么看不出来）

1. **接缝 = 脖子那一圈**：头的脸网格在脖子根有一圈开放边（ROE 的脸带着脖子到锁骨），身体在顶上也有一圈。先把头刚性摆好：
   圈心对圈心，脖子轴（圈心 → 頭）对脖子轴，可选缩放。
2. **顶点焊接**：两圈顶点数一样时按绕脖子的角度一一配对（ROE 都是 60 个），头的每个顶点**直接挪到**身体那个顶点的位置；
   不一样时头的顶点投到身体那圈的折线上，身体圈上的顶点再切进头的边里，两边变成同一条折线——没有缝，也没有 T 形接点。
3. **过渡带**：接缝处的位移沿脖子往上在 N cm 里衰减（smoothstep），位移场在脸网格上平滑 15 遍，接缝处和带子外侧钉死，不起棱。
   UV 接缝处重合的两个顶点当一个算，否则后颈会裂开一条细缝。
4. **法线**：接缝顶点用身体那一圈的法线；带子里的顶点按接缝处「头法线 → 身体法线」的转角乘以衰减再转一点，明暗连续。
5. **权重**：接缝顶点用身体顶点的权重，带子里按衰减混合，脖子一转两边一起动。
6. **肤色**：脸贴图采样接缝上方 0.3–3 cm 的皮肤、身体贴图采样接缝下方同样一段，比值作为整张脸贴图的增益；
   每个接缝顶点剩下的差别（身体色 / 脸色）在带子里按衰减烘进贴图（三角形重心插值），写成 `<脸贴图>_toned.png`。
7. 头的骨骼：同名的（頭、両目、左目……）对上，目标 頭 下面同名的骨头**挪到源的位置**（眼睛绕新眼睛转）；源独有的（头发链、脸骨）搬过来，
   头发刚体、关节一起，碰撞组换到目标没用的组。源的表情（顶点表情）按新顶点号带过来，目标的脸表情随旧头删掉。
   目标里只给旧头发用的骨头留着，它们的刚体和关节删掉。

## 别家游戏（0.2，2026-10-31）

- 星刃 Eve ↔ Inase a08 两个方向都换过，成品 `E:\game_export\RiseOfEros\_混搭\跨游戏换头_a08身体换Eve头\`。
- 别家的材质名 ROE 的规则认不出：头部材质（脸放第一个）和目标要去掉的材质手动勾 / 填；
  「源的脸材质」「目标的身体材质」可以手填（命令行 `--face`、`--body`），留空时身体按 body / skin 认。
- 两边脖子接缝的顶点数不同时（Eve 44、a08 60）走「投影 + 切边」，2026-10-31 修好了这条路接缝上的小洞（见 docs/pmx-head-swap.md「跨游戏」）。

## 做不了 / 注意

- 两边都要有带脖子的脸网格和在脖子根开口的身体（ROE 的导出都是这样）。脸只到下巴、脖子在身体上的模型，接缝会在下巴，还没处理。
- 两圈顶点数不同的「投影 + 切边」路径写了，还没有实例验证过。
- 源的材质表情（换贴图之类）不搬；IK 骨不带 IK。
- 头发很长的模型，头发不参与脖子过渡，接缝附近可能有一两毫米的悬空，自己挪一下。
