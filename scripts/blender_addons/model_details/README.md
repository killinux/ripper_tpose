# 模型细节 Model Details（Blender 3.6 插件）

导入游戏模型以后做细节修饰的插件，一个面板一项，以后的细节功能都加在这里。面板在 3D 视图侧栏（按 `N`）的 **细节** 标签页。

| 面板 | 做什么 | 适用 |
|---|---|---|
| 眼睛 | **眼睛发亮有神**：虹膜透光、角膜湿润反光、跟着镜头方向的眼神光 | ROE、剑星、Vindictus 的 PMX，以及别的眼睛贴图是"眼白中间一个虹膜"的模型 |

## 安装

仓库里的插件用目录联接装进 Blender，和别的插件一样。本机已经装好：

```powershell
New-Item -ItemType Junction -Path "$env:APPDATA\Blender Foundation\Blender\3.6\scripts\addons\model_details" `
         -Target "E:\code\othercode\ripper_tpose\scripts\blender_addons\model_details"
```

然后在「编辑 → 偏好设置 → 插件」里搜 `Model Details` 勾选。改过插件以后：重启 Blender，或者 F3 搜「Reload Scripts」。

## 眼睛发亮有神

1. 导入 PMX，选中模型：点模型的根、骨架或网格都行。
2. 点「**眼睛发亮有神**」。面板会显示认出的眼睛材质和测出的虹膜大小，比如「眼睛：eye_portable（虹膜半径 0.260，1 个输出）」。
3. 拖滑块，实时生效。「恢复默认」回到默认值；「去掉」把眼睛恢复原样。

| 参数 | 默认 | 作用 |
|---|---|---|
| 虹膜发光 | 0.35 | 整个虹膜自己发的光：眼皮阴影里、暗场景里也亮；瞳孔不发光 |
| 下半透光 | 1.2 | 虹膜下半圈额外的光：光从上面穿过角膜照亮虹膜下缘，眼睛显得通透 |
| 虹膜鲜艳 | 1.15 | 发出的光的颜色饱和度 |
| 眼神光 | 6 | 虹膜上两个高光点（一大一小）的亮度；0 = 不要 |
| 眼神光大小 | 1.0 | 高光点大小的倍数 |
| 眼神光方向 | 145° | 大高光点在**屏幕上**的方向：0 右、90 上、145 左上、180 左；小的在对面 |
| 湿润反光 | 0.5 | 角膜的反光，场景里的灯在眼睛上的清楚小亮点；0.5 = 真实角膜的强度 |

- 眼神光跟着镜头方向（在视口里跟着视图）。两只眼睛都在同一边，转镜头也保持在屏幕的同一侧；眼睛转动时它跟着虹膜走，眨眼时被眼皮盖住。
- **和游戏材质插件一起用**：「ROE 游戏材质」「剑星游戏材质」「Vindictus 游戏材质」都行，ROE 插件的「2.6 游戏原版眼睛」也行。
  - 先换游戏材质再点这个，或者先点这个再换都可以。
  - 换过游戏材质后，面板会提示「材质换过了，再点一次」，再点一次就好。
  - 游戏材质插件的「MMD 着色 / 游戏材质」切换，两边都带着效果；
  - 游戏材质插件的「去掉游戏材质」不影响这里，眼睛还是正常的。
- 效果对比（左边原来、右边加了效果；四行依次是：正面 MMD 着色、正面游戏材质、单眼 MMD 着色、单眼游戏材质；Cycles）：
  - ROE（Rana f13，游戏材质那两行是「2.6 游戏原版眼睛」）：`E:\game_export\RiseOfEros\Rana\pmx\pc_f13_hd_full\插件效果_眼睛发亮有神对比.jpg`
  - 剑星（Eve Cooling Suit）：`E:\game_export\StellarBlade\Eve\pmx\CH_P_EVE_Nikke_06\插件效果_眼睛发亮有神对比.jpg`
  - Vindictus（Fiona）：`E:\game_export\Vindictus\Fiona\pmx\Fiona\插件效果_眼睛发亮有神对比.jpg`
- 不影响再导出 PMX：插件不改 mmd_tools 的节点和贴图，PMX 里还是原来的眼睛。效果只在 Blender 里有。

### 怎么认眼睛

- 材质名里有 eye / iris / 眼 / 瞳 这类字，而且不是睫毛、眉毛、眼影、遮蔽、高光贴片、泪膜这些。
- 它的颜色贴图（PMX 的 `mmd_base_tex`）里要能测出"眼白中间一个虹膜"：
  - 先找贴图中间接近纯黑的瞳孔；
  - 再从中心往外看一圈圈的亮度：最亮的那圈是眼白，亮度升到虹膜和眼白中间的地方就是虹膜边；
  - 测出来的虹膜中心、虹膜半径、瞳孔半径记在材质的 `mdx_eye` 属性里。
- 三个游戏测出来的：ROE 虹膜半径 0.26（瞳孔很小），剑星 0.10（瞳孔是虹膜的一半），Vindictus 0.19。
  发光范围、透光范围、眼神光的位置和大小，都按这些尺寸换算。
- 认不出的眼睛材质会跳过，面板上写出名字和原因。

做法细节和试过又放弃的办法见 [`docs/model-details-eyes.md`](../../../docs/model-details-eyes.md)。
