# 布料撕裂 Cloth Tear（Blender 3.6）

把 B 站视频「blender-布料模拟撕裂效果」（峰峰居士，BV1Zk4y1x7Eo）的做法做成按钮：布被拉扯时沿你定好的裂缝撕开。

## 在哪里

已经装好并启用。打开 Blender 3.6 → 3D 视图按 **N** → 侧栏 **「布料撕裂」** 页签。
（开关：编辑 → 偏好设置 → 插件，搜「布料撕裂」。）

## 先看效果（10 秒）

1. 新建一个场景（或删掉默认方块）。
2. 点 **「一键创建撕裂示例」**。
3. 回到第 1 帧，按 **空格** 播放；想反复看就点 **「烘焙」**，然后随便拖时间轴。

你会看到一块布从两个角挂起来，右边被拉开，到第 120–170 帧从中间撕成两半，各挂在一个钩子上。
已经做好的样例：`D:\cloth_tear_demo\cloth_tear_demo.mp4`（视频）、`cloth_tear_demo.blend`（场景）。

## 用在自己的布上

| 步骤 | 操作 | 说明 |
|---|---|---|
| 1 | 选中布 → **「细分网格」** | 面不够多时用，刀数默认 20，「戳孔面」打开撕口更碎。已经很密的网格跳过 |
| 2 | Tab 进编辑模式，选要挂住 / 拉扯的顶点（比如两个角）→ **「选中顶点钩挂 + 固定」** | 每个顶点挂一个空物体，并加进固定组 `Group`。给空物体打位置关键帧就是拉扯动画。也可以用自己的钉固方式 |
| 3 | 加布料修改器（物理属性 → 布料），**形状 → 固定组** 选 `Group` | 先播放确认：不撕的时候拉扯效果是对的 |
| 4 | 编辑模式、边选择模式，选一串边当裂缝 → **「选中边设为裂缝」** | 或者直接点 **「随机生成裂缝」**。要撕成两半，让一条裂缝从两个固定点中间穿过去 |
| 5 | 设好 **松开方向、开始帧、结束帧** → **「生成 / 更新撕裂」** | 开始帧要在拉扯开始之后。修改器栈末尾会多出 `CT 拆缝`、`CT 布料撕裂`、`CT 合缝` |
| 6 | **「清除烘焙」→「烘焙」**，再播放 | 改了任何设置都要先清除再烘 |

不想要了：**「移除撕裂设置」**，只删这三个修改器，钩挂、原布料、裂缝都留着。
想把插件加的东西全部撤掉、从头再来：最下面 **「6. 清理」→「全部清理」**（见后面「撕衣服」最后一段）。

## 用在角色衣服上（撕衣服）

实测过：Fiona 18 None（PMX 原尺寸导入，约 18 个单位高）的连衣裙，裙子分成两个物体，第 30 帧开始从上往下撕，
90 帧碎片往下掉；1.2 到第 130 帧两件裙子全部落在地上，身上一片不剩（1.1 会剩腰上一圈和吊在项链上的两片，原因见下面）。
照着做的完整例子（每一步点哪里、成功是什么样子）：[docs/cloth-tear-fiona-demo.md](../../../docs/cloth-tear-fiona-demo.md)。

**准备**：衣服要是单独的网格物体，带骨架修改器跟着身体。MMD 模型导入后是一整个网格：
选中模型 → 侧栏 **MMD** → **「按材质分开」**，每种材质变成一个物体（例如 `00C_+Dress.1`）。

| 步骤 | 操作 | 说明 |
|---|---|---|
| 1 | 选中要撕的衣服（可以多选）→ **「衣服跟随身体（撕衣服用）」** | 每件衣服加布料 1 并且全部固定（顶点组 `CT_Follow`），撕开之前衣服完全跟着身体动画走，不会穿模。和衣服重叠的身体网格自动加碰撞（修改器叫 `CT 碰撞`），项链、耳环、臂甲这类饰品不加（状态栏会列出来），脚底加一块不渲染的地面 `CT_地面碰撞`（1.3 起边长 = 4 倍身高、单面碰撞，推远的碎片不会从边上掉下去）。「撕开后仍固定」自动改成「无」 |
| 2 | 衣服还选着 → **「随机生成裂缝」** | 每件各生成「裂缝条数」条。衣服由好几块拼成也没关系，按块分配。想要几道撕穿的、几道撕一半的：先关「不贯穿」点一次，再开「不贯穿」、换个种子点一次。「切开套圈」默认按下：腰带、筒裙这种套成圈的布再补一两条裂缝切开，状态栏会说「切开套圈 N 处」 |
| 3 | 松开方向选 **物体 Z**，设 **开始帧 / 结束帧** → **「生成 / 更新撕裂」** | 从上往下撕。想从下摆往上撕就勾「反过来」。选中的衣服每件都生成；选中了没有布料或没有裂缝的物体（比如身体）会提示，一件都不改 |
| 4 | 衣服还选着 → **「加推力场」** | 放一个力场，从身体中轴往外水平推，范围是衣服那一段高度，只推撕裂用的布料 2，从开始帧推到结束帧后 10 帧；碎片掉到衣服下面就不再受力，自然落地。默认「按尺寸调快」：模型比真人大时把布料 2 调快，否则像慢动作。**注意（10-02 实测）**：默认强度 25 其实几乎推不动，碎片能落下靠的是重力和「按尺寸调快」；想把碎片推开要几百到上千，见下面「爆衣」和 [clothes-burst-survey.md](../../../docs/clothes-burst-survey.md) 第 8 节 |
| 5 | **「烘焙」**，拖时间轴看 | 底部状态栏有进度条，Esc 取消。改了任何设置都要先「清除烘焙」再烘。想先快速看一眼：按下「快速预览」再烘，时间差不多减半，满意了关掉、清除烘焙、再烘一次定稿。后台实测 150 帧：Fiona 两件裙子约 1.5 分钟（快速预览约 50 秒），Tifa 12 件战斗服约 4.5 分钟（快速预览约 3 分钟） |

想让一部分撕开后还挂在身上（领口、腰带、肩带）：「撕开后仍固定」选「自选顶点组」，再选一个只含这些顶点的顶点组。

**撕完还有东西挂在身上**，1.1 时有三种原因，1.2 都处理了（Fiona 的练习场景逐个试过，见 guide 第 6 节）：

| 挂住的样子 | 原因 | 1.2 的处理 |
|---|---|---|
| 腰上剩一圈 | 那块布是个圈（腰带），裂缝没把圈切断，撕开以后还是一个圈，过不了胯 | 「切开套圈」：补最少的裂缝把圈切开。手动画裂缝时点「只切开套圈」 |
| 胸前两片吊在脖子上 | 项链也加了碰撞，裙带从项链底下穿过，碎片被项链兜住 | 项链、耳环、臂甲这类饰品不加碰撞 |
| 肩上、手臂上挂着小块 | 挂在臂甲尖上。1.1 时以为是推力方向不对，10-02 实测推力只有重力的百分之几，主要是臂甲的碰撞挂住的 | 臂甲也算饰品，不加碰撞（推力改成水平的那一条，实际没起作用） |

还挂着别的：选中那件衣服，在挂住的地方加几条横过去的裂缝（编辑模式选边 →「选中边设为裂缝」），
或者给挡住它的物体去掉碰撞（物理属性 → 碰撞 → ×），再「生成 / 更新撕裂」→ 清除烘焙 → 烘焙。

**1.1 做过的场景**：项链上已经有碰撞，1.2 不会自己删。点「6. 清理」→「全部清理」，再从第 1 步重做一遍。

**全部清理**：「6. 清理」→「全部清理」，弹出的小窗里列出要清理的衣服，确定后删掉插件在这个场景里加的所有东西：
- 每件衣服的三个撕裂修改器、「衣服跟随身体」加的布料 1（衣服原来就有布料的，固定组等设置还原）、`CT_Follow` / `CT_Pin` 顶点组、裂缝；
- 身体上的碰撞（1.1 加的叫 `Collision`，也认得）、地面、推力场和它的集合、没人用的节点组。
- 钩挂和空物体不动。小窗里取消「也清除裂缝」可以留着裂缝。Ctrl+Z 可以撤销。

衣服面数太少时先「细分网格」，否则撕口很整齐、很假。

**爆衣（衣服一下子炸开）**：更方便的是单独的「爆衣」插件（`scripts/blender_addons/clothes_burst`，侧栏「爆衣」）。
它一键设好，推力按重力的倍数、每件衣服自动换算，还能只爆衣服的一部分，见它的 README 和 [教程](../../../docs/clothes-burst-tutorial.md)。
只用本插件也行，改参数就能爆（用 Fiona 的裙子试过，见 [clothes-burst-survey.md](../../../docs/clothes-burst-survey.md) 第 8 节）：
1. 裂缝条数 10，「不贯穿」不按下 →「随机生成裂缝」；再按下「不贯穿」、换个种子 → 再点一次；
2. 开始帧 30，结束帧 33 →「生成 / 更新撕裂」；
3. 推力强度直接输入 500（滑块只能拖到 200）→「加推力场」；
4. 烘焙。第 35 帧左右炸开，碎片飞出约一个身高再落地。

推力 500 只对 Fiona 的裙子合适：布料面积小、网格密的衣服要加大很多（比如 Tifa 战斗服上的细线条）。

## 参数

| 参数 | 作用 |
|---|---|
| 松开方向 | 从哪边开始撕：UV 的 V（和视频一样）、UV 的 U、物体 X / Y / Z。数值大的一边先撕 |
| 反过来 | 从另一边开始撕（比如从下往上） |
| 开始帧 / 结束帧 | 开始帧之前布是完整的；结束帧时所有裂缝都已松开 |
| 过渡宽度 | 撕开的那条「线」有多宽（占整块布的比例）。小 = 撕得干脆，大 = 慢慢扯开 |
| 合并距离 | 裂缝两边离得比这还近就当没撕开，合在一起不露缝（默认 1 mm） |
| 裂缝条数 / 锯齿程度 / 随机种子 | 随机裂缝的数量、弯曲程度；换种子换一种裂法 |
| 不贯穿 | 打开：从布边撕进去一段就停，出裂口和毛边。关掉：从布边到布边，会撕成几块 |
| 切开套圈 | 默认打开。「随机生成裂缝」之后再看每块布：套成圈的（身体从圈里穿过去，比如腰带、袖子、筒裙）补最少的裂缝把圈切开，已有的裂缝算已经撕开；镂空花纹这种小圈不算。只想撕出口子、不想让衣服掉下来时关掉 |
| 撕开后仍固定 | 同布料固定组（视频的做法，钩挂的角一直挂着）/ 无（全部掉落，撕衣服用）/ 自选顶点组 |
| 推力强度 | 推力场的力（从身体中轴水平往外），默认 25。10-02 实测：25 几乎没有作用（Blender 给布料施加力场时按面积 × 0.02 缩放、再除以帧率，Fiona 的裙子只有重力的 4%–9%）；要几百才看得出推开，500 左右是爆衣。大的值直接输入 |
| 按尺寸调快 | 打开时，布料 2 的速度取 √(身高 ÷ 1.7)，质量步数提高到速度 × 5。模型比真人大时，碎片能及时落下主要靠它 |
| 布料 2 速度 / 质量步数 | 生成撕裂后出现在「4. 推力」下面，直接改的是 `CT 布料撕裂` 修改器的时间缩放和质量步数 |
| 快速预览 | 在「5. 烘焙」里。按下时布料 2 的质量步数减半（速度 × 2.5，平时 × 5），烘焙快将近一倍；碎片可能挂在手指上滑不下来（Tifa 的手套），定稿前关掉 |

生成以后，开始帧、结束帧、过渡宽度、合并距离可以直接在面板下方改，不用重新生成。改完记得清除烘焙重算。

## 常见问题

- **没撕开**：
  - 是不是还没有裂缝？面板上「2. 裂缝」会显示条数；
  - 开始帧是不是在动画范围外？
  - 改完设置有没有清除烘焙？
  - 修改器顺序必须是：钩挂 → 布料 → CT 拆缝 → CT 布料撕裂 → CT 合缝。被手动拖乱了就再点一次「生成 / 更新撕裂」。
- **撕开的布整块掉下去了**：它没连着任何固定点，这是物理上对的。让裂缝别把固定点和那块布隔开，或者多固定几个点。
- **太慢**：`CT 布料撕裂` 是原布料的完整拷贝，可以在修改器面板里单独关掉它的自碰撞，或降低质量步数。
- **网格有接缝 / 一开始就裂开**：合并距离调大一点（比如 0.002）。
- **衣服：裂缝撕开了，但碎片贴在身上不动**：先确认「按尺寸调快」开着（模型大时不开，碎片像慢动作，看着像贴住了）；
  再看是不是被别的物体挡住或者是个套圈（见上面「撕完还有东西挂在身上」）。想把碎片推开，推力强度要输入几百再点「加推力场」，默认的 25 太小。
- **衣服：碎片像慢动作一样飘**：模型比真人大很多（PMX 原尺寸约 18 高），打开「按尺寸调快」再点一次「加推力场」，或者直接调「布料 2 速度」。
- **衣服：碎片穿过身体**：身体那块网格没加碰撞（「衣服跟随身体」只给和衣服重叠的身体网格加）。手动加：物理属性 → 碰撞。
- **衣服：碎片穿过了项链、臂甲**：这类饰品故意不加碰撞（加了会把碎片挂住）。想让它挡住碎片就手动加碰撞。
  按名字认饰品：necklace、earring、pad、armor、项链、耳环、护甲、臂甲……（`core.py` 的 `ACCESSORIES`）。
- **衣服：撕完一片吊在脖子上、一圈卡在腰上**：见上面「撕完还有东西挂在身上」。
- **多层衣服（连体衣外面还有上衣、手套、靴套）**：里外几层要一起选上撕。只撕外层，里面那层会露出来；只撕连体衣，
  它伸进手套、靴套里的那截被手套、靴套的碰撞兜住，撕完还挂着。Tifa 的 GANTZ 战斗服就是 12 件一起撕的（guide 第 7 节）。
- **「烘焙」很久**：它就是 Blender 自带的「烘焙所有动力学解算结果」，烘的是场景里所有物理缓存，MMD 的刚体（头发物理）也会一起烘。
  进度在底部状态栏，Esc 取消。时间大部分花在撕裂用的布料 2 上（质量步数和身体碰撞），先用「快速预览」调好再定稿。
  撕衣服时布料 1 每个点都固定、算了也白算，1.3 起生成撕裂时自动关掉它（修改器列表里它的显示开关是灭的），缓存减半，结果不变。
- **碎片从地面边上掉下去、掉到地面下面**：1.2 及以前的地面只有 20 × 20，模型按 PMX 原尺寸（约 20 高）时推远的碎片会出界。
  1.3 再点一次「衣服跟随身体」，地面就换成 4 倍身高见方的单面碰撞，然后清除烘焙、烘焙。
- **推力把头发也吹动了**：插件把刚体世界的力场集合设成空集合 `CT_无力场`，头发不受影响；如果你原来就给刚体世界设过力场集合，插件不会改它。
- 不要推力场了：**「4. 推力」右边的垃圾桶**，删掉力场和它的集合，布料 2 的速度不变。

## 原理（一句话）

两个布料修改器叠在一起：
- 第一个模拟完整的布被拉扯；
- 中间的几何节点沿裂缝把网格拆开，并让固定组的权重随时间从一边扫到另一边、从 1 变成 0；
- 第二个布料用这个固定组，权重为 1 时跟着第一个布料走，权重降下来就沿裂缝散开；
- 最后把没撕开的缝合回去。

撕衣服时，布料 1 全部固定（衣服跟着身体动画走），松开的碎片靠重力落下；推力场要设到几百以上才推得动（见上面「爆衣」）。

视频逐步解读、节点图、衣服模式的原理和测试记录见 [docs/cloth-tear-guide.md](../../../docs/cloth-tear-guide.md)。
