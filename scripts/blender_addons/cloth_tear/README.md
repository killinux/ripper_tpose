# 布料撕裂 Cloth Tear（Blender 3.6）

把 B 站视频「blender-布料模拟撕裂效果」（峰峰居士，BV1Zk4y1x7Eo）的做法做成按钮：布被拉扯时沿你定好的裂缝撕开。

## 在哪里

已经装好并启用。打开 Blender 3.6 → 3D 视图按 **N** → 侧栏 **「布料撕裂」** 页签。
（开关：编辑 → 偏好设置 → 插件，搜「布料撕裂」。）

## 先看效果（10 秒）

1. 新建一个场景（或删掉默认方块）。
2. 点 **「一键创建撕裂示例」**。
3. 回到第 1 帧，按 **空格** 播放；想反复看就点 **「烘焙」**，然后随便拖时间轴。

你会看到一块布从两个角挂起来，右边被拉开，到第 120–170 帧从中间撕成两半，各挂在一个钩子上。
已经做好的样例：`D:\cloth_tear_demo\cloth_tear_demo.mp4`（视频）、`cloth_tear_demo.blend`（场景）。

## 用在自己的布上

| 步骤 | 操作 | 说明 |
|---|---|---|
| 1 | 选中布 → **「细分网格」** | 面不够多时用，刀数默认 20，「戳孔面」打开撕口更碎。已经很密的网格跳过 |
| 2 | Tab 进编辑模式，选要挂住 / 拉扯的顶点（比如两个角）→ **「选中顶点钩挂 + 固定」** | 每个顶点挂一个空物体，并加进固定组 `Group`。给空物体打位置关键帧就是拉扯动画。也可以用自己的钉固方式 |
| 3 | 加布料修改器（物理属性 → 布料），**形状 → 固定组** 选 `Group` | 先播放确认：不撕的时候拉扯效果是对的 |
| 4 | 编辑模式、边选择模式，选一串边当裂缝 → **「选中边设为裂缝」** | 或者直接点 **「随机生成裂缝」**。要撕成两半，让一条裂缝从两个固定点中间穿过去 |
| 5 | 设好 **松开方向、开始帧、结束帧** → **「生成 / 更新撕裂」** | 开始帧要在拉扯开始之后。修改器栈末尾会多出 `CT 拆缝`、`CT 布料撕裂`、`CT 合缝` |
| 6 | **「清除烘焙」→「烘焙」**，再播放 | 改了任何设置都要先清除再烘 |

不想要了：**「移除撕裂设置」**，只删这三个修改器，钩挂、原布料、裂缝都留着。

## 用在角色衣服上（撕衣服）

实测过：Fiona 18 None（PMX 原尺寸导入，约 18 个单位高）的连衣裙，裙子分成两个物体，第 30 帧开始从上往下撕，
90 帧碎片往下掉，110 帧落到脚边。照着做的完整例子（每一步点哪里、成功是什么样子）：
[docs/cloth-tear-fiona-demo.md](../../../docs/cloth-tear-fiona-demo.md)。

**准备**：衣服要是单独的网格物体，带骨架修改器跟着身体。MMD 模型导入后是一整个网格：
选中模型 → 侧栏 **MMD** → **「按材质分开」**，每种材质变成一个物体（例如 `00C_+Dress.1`）。

| 步骤 | 操作 | 说明 |
|---|---|---|
| 1 | 选中要撕的衣服（可以多选）→ **「衣服跟随身体（撕衣服用）」** | 每件衣服加布料 1 并且全部固定（顶点组 `CT_Follow`），撕开之前衣服完全跟着身体动画走，不会穿模。和衣服重叠的身体网格自动加碰撞，脚底加一块不渲染的地面 `CT_地面碰撞`。「撕开后仍固定」自动改成「无」 |
| 2 | 衣服还选着 → **「随机生成裂缝」** | 每件各生成「裂缝条数」条。衣服由好几块拼成也没关系，按块分配。想要几道撕穿的、几道撕一半的：先关「不贯穿」点一次，再开「不贯穿」、换个种子点一次 |
| 3 | 松开方向选 **物体 Z**，设 **开始帧 / 结束帧** → **「生成 / 更新撕裂」** | 从上往下撕。想从下摆往上撕就勾「反过来」。选中的衣服每件都生成；选中了没有布料或没有裂缝的物体（比如身体）会提示，一件都不改 |
| 4 | 衣服还选着 → **「加推力场」** | 角色站着不动时，松开的碎片没有东西拉，只会贴在身上（视频里是钩子把布扯开）。这个按钮在衣服中心放一个往外推的力场，只推撕裂用的布料 2，从开始帧推到结束帧后 10 帧。默认「按尺寸调快」：模型比真人大时把布料 2 调快，否则像慢动作 |
| 5 | **「烘焙」**，拖时间轴看 | 底部状态栏有进度条，Esc 取消。改了任何设置都要先「清除烘焙」再烘。Fiona 的两件裙子 200 帧烘了约 3.5 分钟（质量步数 12；步数越高、帧数越多越慢） |

想让一部分撕开后还挂在身上（领口、腰带、肩带）：「撕开后仍固定」选「自选顶点组」，再选一个只含这些顶点的顶点组。

撕完还有一块挂着不掉，通常是它套在脖子或手臂上，又没有裂缝穿过它（Fiona 胸前挂脖的那部分就是这样）。
想让它也掉，就在这块上多加几条裂缝（编辑模式选边 →「选中边设为裂缝」），再「生成 / 更新撕裂」→ 清除烘焙 → 烘焙。

衣服面数太少时先「细分网格」，否则撕口很整齐、很假。

## 参数

| 参数 | 作用 |
|---|---|
| 松开方向 | 从哪边开始撕：UV 的 V（和视频一样）、UV 的 U、物体 X / Y / Z。数值大的一边先撕 |
| 反过来 | 从另一边开始撕（比如从下往上） |
| 开始帧 / 结束帧 | 开始帧之前布是完整的；结束帧时所有裂缝都已松开 |
| 过渡宽度 | 撕开的那条「线」有多宽（占整块布的比例）。小 = 撕得干脆，大 = 慢慢扯开 |
| 合并距离 | 裂缝两边离得比这还近就当没撕开，合在一起不露缝（默认 1 mm） |
| 裂缝条数 / 锯齿程度 / 随机种子 | 随机裂缝的数量、弯曲程度；换种子换一种裂法 |
| 不贯穿 | 打开：从布边撕进去一段就停，出裂口和毛边。关掉：从布边到布边，会撕成几块 |
| 撕开后仍固定 | 同布料固定组（视频的做法，钩挂的角一直挂着）/ 无（全部掉落，撕衣服用）/ 自选顶点组 |
| 推力强度 | 推力场的力，默认 25。碎片贴在身上不动就加大，炸飞就减小 |
| 按尺寸调快 | 打开时，布料 2 的速度取 √(身高 ÷ 1.7)，质量步数提高到速度 × 5。配合它，推力强度不用跟着模型大小改 |
| 布料 2 速度 / 质量步数 | 生成撕裂后出现在「4. 推力」下面，直接改的是 `CT 布料撕裂` 修改器的时间缩放和质量步数 |

生成以后，开始帧、结束帧、过渡宽度、合并距离可以直接在面板下方改，不用重新生成。改完记得清除烘焙重算。

## 常见问题

- **没撕开**：
  - 是不是还没有裂缝？面板上「2. 裂缝」会显示条数；
  - 开始帧是不是在动画范围外？
  - 改完设置有没有清除烘焙？
  - 修改器顺序必须是：钩挂 → 布料 → CT 拆缝 → CT 布料撕裂 → CT 合缝。被手动拖乱了就再点一次「生成 / 更新撕裂」。
- **撕开的布整块掉下去了**：它没连着任何固定点，这是物理上对的。让裂缝别把固定点和那块布隔开，或者多固定几个点。
- **太慢**：`CT 布料撕裂` 是原布料的完整拷贝，可以在修改器面板里单独关掉它的自碰撞，或降低质量步数。
- **网格有接缝 / 一开始就裂开**：合并距离调大一点（比如 0.002）。
- **衣服：裂缝撕开了，但碎片贴在身上不动**：角色不动时没有东西拉它，点「加推力场」。
- **衣服：碎片像慢动作一样飘**：模型比真人大很多（PMX 原尺寸约 18 高），打开「按尺寸调快」再点一次「加推力场」，或者直接调「布料 2 速度」。
- **衣服：碎片穿过身体**：身体那块网格没加碰撞（「衣服跟随身体」只给和衣服重叠的身体网格加）。手动加：物理属性 → 碰撞。
- **「烘焙」很久**：它就是 Blender 自带的「烘焙所有动力学解算结果」，烘的是场景里所有物理缓存，MMD 的刚体（头发物理）也会一起烘。
  进度在底部状态栏，Esc 取消。
- **推力把头发也吹动了**：插件把刚体世界的力场集合设成空集合 `CT_无力场`，头发不受影响；如果你原来就给刚体世界设过力场集合，插件不会改它。
- 不要推力场了：**「4. 推力」右边的垃圾桶**，删掉力场和它的集合，布料 2 的速度不变。

## 原理（一句话）

两个布料修改器叠在一起：
- 第一个模拟完整的布被拉扯；
- 中间的几何节点沿裂缝把网格拆开，并让固定组的权重随时间从一边扫到另一边、从 1 变成 0；
- 第二个布料用这个固定组，权重为 1 时跟着第一个布料走，权重降下来就沿裂缝散开；
- 最后把没撕开的缝合回去。

撕衣服时，布料 1 全部固定（衣服跟着身体动画走），推力场负责把松开的碎片推离身体。

视频逐步解读、节点图、衣服模式的原理和测试记录见 [docs/cloth-tear-guide.md](../../../docs/cloth-tear-guide.md)。
