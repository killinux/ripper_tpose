# 爆衣 Clothes Burst（Blender 3.6 插件）

一个插件、几种爆衣做法。面板最上面选**方式**：

| 方式 | 给谁用 | 怎么做的 |
|---|---|---|
| **布料撕裂** | Blender 里渲染 | 真的布料物理：裂缝、松开、推力，碎片撞到身体和地面。带不进 MMD |
| **MMD 表情**：碎片飞散 | MMD | 衣服复制一份切成碎片，飞出去、落地都预先算成表情；MMD 里不用物理，哪个版本都能放 |
| **MMD 表情**：直接消失 | MMD | 衣服一下子（或几帧内淡出）没了，没有碎片 |

MMD 的两种做法在 [下面「给 MMD 用（2.0）」](#给-mmd-用20) 一节；下面先说布料撕裂。

**布料撕裂**：选中衣服（可以多件），或者在编辑模式里选中衣服的一部分，点一下「一键爆衣」，再点「烘焙」：
到了指定的帧，衣服炸成碎片往外飞，再落到地上。没选中的部分留在身上。设置都有默认值，也都能改。
1.1 起还有**外观**：撕口是参差不齐的毛边；碎片可以淡出，或者一块块烧掉似的溶解、边缘发光。
外观只影响渲染，改了马上生效，不用重新烘焙。

- **布料撕裂需要「布料撕裂 Cloth Tear」插件**（MMD 的做法不需要）：撕开用的是它的做法，代码也直接调用它。两个插件在同一个仓库：
  `scripts/blender_addons/cloth_tear` 和 `scripts/blender_addons/clothes_burst`，放在同一个插件目录里就行，
  布料撕裂插件本身不用启用。
- **Blender 3.6**：仓库里两个都已经用目录联接装进 3.6 并启用了，重开 Blender 后，3D 视图按 N，侧栏最右边多一个「爆衣」页签。
  如果没有：编辑 → 偏好设置 → 插件，搜「爆衣」，勾上。
- 演示视频：`D:\cloth_tear_demo\clothes_burst_demo.mp4`，四格分别是：
  - 整件爆开；
  - 只爆裙摆；
  - 只爆上身；
  - Tifa 整套战斗服。
- 一步步的教程（Fiona 示例：整件、只爆裙摆、调效果）见 [docs/clothes-burst-tutorial.md](../../../docs/clothes-burst-tutorial.md)；
  原理和测试见 [docs/clothes-burst-guide.md](../../../docs/clothes-burst-guide.md)。

## 怎么用

**准备**：衣服要是单独的网格物体，带骨架修改器跟着身体。MMD 模型导入后是一整个网格：
选中模型 → 侧栏 **MMD** → **「按材质分开」**，每种材质变成一个物体（例如 `00C_+Dress.1`）。

**整件爆开**

1. 物体模式，在大纲视图里点要爆的衣服，Ctrl+点加选别的（可以多件）。身体不要选上；
2. 侧栏「爆衣」→ **「一键爆衣」**。
   - 状态栏会提示设好了什么：裂缝条数、推力、跟着哪根骨骼。
   - 碰撞、地面、布料都是自动加的；
3. **「烘焙」**（底部状态栏有进度条，Esc 取消），烘完拖时间轴或从第 1 帧播放。

**只爆一部分**（例如只爆裙摆，上衣留着）

1. 选中那件衣服，Tab 进编辑模式，按 3 切到面选择，选中要爆开的面（L 选相连的块、框选、Ctrl+加号扩大选择都行）。
   几件衣服可以一起进编辑模式各选一部分；
2. 还在编辑模式里，点 **「一键爆衣」**：
   - 选中的面炸开，没选中的留在身上；
   - 范围会存下来，之后在物体模式里改了设置再点「一键爆衣」，还是只爆这一部分；
3. **「烘焙」**。

**改设置再试**：改完设置 → 再点「一键爆衣」→「清除烘焙」→「烘焙」。再点「一键爆衣」时，原来的烘焙会自动清掉。
想先快速看一眼，就按下「快速预览」再烘，满意了关掉、清除烘焙、再烘一次定稿。

**场景的帧范围**：碎片大约在爆开后 40 帧落地。时间线的「结束点」要在「一键爆衣」之前改好，因为缓存按场景的帧范围设；
太短时状态栏会提醒。

**外观（1.1）**：面板的「外观」一栏。
- **撕口毛边**（默认开）：撕开以后，撕口变成毛边，边上稍微变暗。
- **碎片消失**（默认「不消失」）：
  - 「淡出」：碎片渐渐变透明；
  - 「溶解」：碎片一块一块烧掉似的消失，边缘发光，光边里面一圈焦黑；
  - 「松开后几帧开始」「用几帧」控制时间。默认松开后第 3 帧开始、12 帧消失完：碎片在空中边飞边烧，落地前烧完。
- **只影响渲染**：碎片照样模拟、照样落地，外观只决定画出来是什么样。所以外观的设置改了马上生效，不用重新烘焙，
  也不用再点「一键爆衣」。
- **在哪里看**：3D 视图右上角切到「材质预览」或「渲染」（或按 Z 选），或者渲染出图。「实体」视图看不到。
  Eevee 在渲染属性里打开「辉光」，溶解的光边更好看；Cycles 直接就有。

## 设置

| 设置 | 默认 | 作用 |
|---|---|---|
| 爆开帧 | 30 | 这一帧开始炸开；之前衣服完整地跟着身体动 |
| 松开用几帧 | 3 | 几帧之内所有裂缝松开。小 = 一下子炸开；大（比如 30）= 从上往下很快地撕开 |
| 推力（× 重力） | 1.0 | 把碎片推出去的力，按重力的倍数算。每件衣服按自己的面积和顶点数自动换算，大块布和细布条飞得差不多远。1 = 碎片飞出约一个身高的距离；2 = 两倍远；0 = 不推，碎片散开直接掉下去 |
| 推几帧 | 10 | 推力从爆开帧开始持续几帧，越长飞得越远 |
| 推的方向 | 水平往外 | 「水平往外」：从身体中轴往四周推。「四面八方」：从中心往所有方向推，上半身的碎片会往上飞 |
| 贯穿裂缝 / 不贯穿裂缝 | 10 / 10 | 每件衣服（或选中的范围）随机生成的裂缝条数。贯穿的从布边到布边，把布切成块；不贯穿的撕进去一段就停，出裂口和毛边。越多越碎 |
| 锯齿程度 / 随机种子 | 0.6 / 1 | 裂缝弯曲的程度；换个种子就换一种碎法 |
| 更多设置 → 切开套圈 | 开 | 腰带、袖子、筒裙这种套成圈的布，再补一条裂缝切开，不然碎片卡在身上掉不下来 |
| 更多设置 → 重新生成裂缝 | 开 | 每次「一键爆衣」都重新随机生成裂缝。关掉时保留已有的裂缝，例如用布料撕裂插件手画的，只补范围的边界 |
| 更多设置 → 从下往上 | 关 | 「松开用几帧」比较大时才看得出来：默认从上往下松开 |
| 更多设置 → 过渡宽度 / 合并距离 | 0.08 / 0.0005 | 和布料撕裂插件的同名设置一样，一般不用改 |
| 快速预览 | 关 | 布料 2 的质量步数减半，烘焙快将近一倍；碎片可能挂在手指上，定稿前关掉 |
| 外观 → 撕口毛边 | 开 | 撕开以后撕口变成毛边。只影响渲染 |
| 外观 → 宽度 / 变暗 | 0.5 / 0.3 | 毛边多宽，按身高的百分比（0.5 ≈ 1.7 米的人身上 8 毫米，1 以上像撕纸）；撕口附近变暗多少，0 = 不变暗 |
| 外观 → 碎片消失 | 不消失 | 「淡出」：渐渐变透明；「溶解」：一块块烧掉，边缘发光 |
| 外观 → 松开后几帧开始 / 用几帧 | 3 / 12 | 碎片松开以后过几帧开始消失、用几帧消失完（默认在空中烧完）。只对飞出去的碎片，留在身上的部分不消失 |
| 外观 → 光边颜色 / 光边亮度 | 橙色 / 6 | 溶解时边缘发光的颜色和亮度，亮度 0 = 不发光 |

## 常见问题

- **点了没反应 / 按钮是灰的**：物体模式下要先选中衣服；编辑模式下要选中面。单独选中的顶点、边不算，要围成面。
- **飞得太远、飞出画面**：「推力（× 重力）」调小（比如 0.5），或「推几帧」减少。**太近、像直接掉下去**：调大（比如 2）。
- **想让碎片往上飞**：推的方向选「四面八方」。
- **碎片太大块 / 太碎**：增减「贯穿裂缝」「不贯穿裂缝」；换「随机种子」换一种碎法。
- **还有一块挂在身上**：
  - 多半是被饰品挡住了。项链、耳环、臂甲这类饰品默认不加碰撞，按名字认，见布料撕裂插件 `core.py` 的 `ACCESSORIES`；
  - 名字认不出来的饰品，可以选中它 → 物理属性 → 碰撞 → ×，再清除烘焙、烘焙。
- **不同的衣服在不同的帧爆开**：
  - 先选 A 设爆开帧 30、点「一键爆衣」；再选 B 设爆开帧 60、再点一次；
  - 每次「一键爆衣」用自己的一组推力场（`CB_爆衣推力_1`、`_2`……），互不影响；
  - 一起选中再点，就合成一组。
- **只爆一部分时，没爆的部分边上有一圈在晃**：范围边界上的那一圈顶点是松开的（两边都是），看起来像撕开的毛边。
  不想要就把范围多选一圈。
- **角色在动（套了舞蹈动作）**：推力场跟着要爆的那部分的骨骼走（整件一般是「腰」，裙摆是「下半身」），所以还是从身体往外推。
- **烘焙很久**：Fiona 两件裙子 120 帧约 1 分钟，Tifa 12 件约 2 分钟（后台实测）。先用「快速预览」调好再定稿。
- **外观看不到**：
  - 视图是不是「实体」：要切到「材质预览」或「渲染」；
  - 衣服的材质要用节点（MMD、游戏导出的材质都是），没用节点的材质状态栏会列出来；
  - 帧在爆开之前：撕开以后才有毛边，松开后过「松开后几帧开始」才开始消失。
- **外观会不会改坏我的材质**：
  - 插件在材质里「材质输出」前面插一个节点组「CB 爆衣外观」（着色器编辑器里看得到），原来的连线接在它的输入上；
  - 混合模式是「不透明」的材质改成 Alpha Hashed（Eevee 才能透明），改之前的值记在材质上；
  - 把外观两项都关掉、「撤掉选中衣服的爆衣」或「全部清理」，都会拿掉节点组，混合模式也改回去；
  - 和衣服共用材质的身体不受影响：外观只认爆过的衣服上写的属性。
- **溶解得太早 / 太晚**：调「松开后几帧开始」「用几帧」。默认 3 / 12 是在空中烧完；想等碎片落地再消失：开始 25、用 25；
  想让碎片在地上多躺一会儿：开始 60。
- **导出 FBX / XPS 之前**：先关掉外观（或全部清理）。有的导出器只认直接接在「材质输出」上的原理化 BSDF，
  中间多了节点组可能导不出贴图。
- **和布料撕裂插件一起用**：撕衣服的修改器、碰撞、地面是同一套。
  - 爆过的衣服在布料撕裂面板里也能看到、能调；
  - 布料撕裂的「全部清理」不会删爆衣的推力场，要用爆衣面板的「全部清理」。
- **插件加了什么**（全部清理会删掉）：
  - 每件衣服：布料 1（`CT_Follow` 全部固定）、`CT 拆缝` → `CT 布料撕裂` → `CT 合缝`、顶点组 `CT_Pin` 和 `CB_Keep`（只爆一部分时）、裂缝（边折痕）、面属性 `cb_region`（只爆一部分时）、外观用的顶点属性 `cb_t` `cb_free` `cb_edge` `cb_rest`；
  - 衣服的材质：「材质输出」前面的节点组节点 `CB 爆衣外观`，原来不透明的改成 Alpha Hashed（材质属性 `cb_blend` 记着原来的）；
  - 身体：碰撞修改器 `CT 碰撞`；
  - 场景：地面 `CT_地面碰撞`、推力场 `CB_爆衣推力_N` 和集合 `CB_爆衣力场_N`、着色器节点组 `CB_爆衣外观`。

## 原理（简单说）

撕开用布料撕裂插件的做法，先把它的四步列出来：
1. 布料 1 每个点都固定，跟着身体走；
2. 几何节点沿裂缝把网格拆开，按帧把固定组松开；
3. 布料 2 让松开的碎片自由运动；
4. 最后把还没松开的缝合回去。

爆衣在这上面加了四样：
- **裂缝只在范围里**：只爆一部分时，范围的边界也是裂缝；
- **几帧之内全部松开**：没选中的部分进顶点组 `CB_Keep`，一直固定；
- **短促的推力**：
  - Blender 给布料施加力场时按面积缩放，还要除以帧率，力场「强度」的数值和推多远对不上。
    插件按「重力的倍数」换算（用一块单独的布标定过，误差 < 0.1%）：
    力场的加速度 ÷ 重力 = 强度 × 0.02 × 面积 ÷（顶点质量 × 顶点数 × 帧率 × |重力| × 0.001）；
  - 每件衣服各算各的，用布料的力场权重补齐，细布条也一样推得动；
- **推力场跟着骨骼**：用 Child Of 约束跟着身体的骨骼走。

外观（1.1）分两半：
- 「一键爆衣」时给每件衣服写四个顶点属性：这个点哪一帧松开、会不会飞出去、离最近的裂缝多远、静止时在哪。
  修改器（拆缝、布料、合缝）会把属性一路带下去，裂缝拆开后两边各有一份；
- 材质里的节点组读这几个属性和当前帧（节点组里一个值节点，驱动器是 `frame`）：
  - 撕开以后，离裂缝近于「宽度 × 噪波」的地方透明，这就是毛边；
  - 松开后过几帧，透明度渐变（淡出），或者噪波低于一个逐渐升高的阈值的地方透明（溶解），阈值边上发光；
- 噪波用静止时的位置算，碎片飞走、翻转时花纹贴在布上不动。

详见 [docs/clothes-burst-guide.md](../../../docs/clothes-burst-guide.md) 的「外观」一节。

## 给 MMD 用（2.0）

面板最上面选 **「MMD 表情」**。做在 **mmd_tools 导入的模型**上（任何 PMX；需要启用 mmd_tools，不需要布料撕裂插件），
爆衣做成模型的**表情**，mmd_tools 照常导出 PMX，再导出一个只有表情帧的 VMD。MMD 里不用物理，哪个版本都能放。

**怎么用**

1. 用 mmd_tools 导入 PMX，选中模型里随便哪个物体；
2. 「1. 模型和衣服」：点材质按钮选哪些是衣服（按下 = 衣服）。模型自带表情 `衣服非表示_材質` 时（ROE 的 full 版都有），
   点 **「按「衣服非表示_材質」选」** 一下就选好；也可以编辑模式里选中衣服上的几个面，点 **「按选中的面选」**；
3. 「2. 做法」：**碎片飞散** 或 **直接消失**。身体有形状键「裸体形状」时（ROE 的 full 版）勾 **「换成完整身体」**，
   有同一身体的 nude 版 PMX 可以填进「nude 版 PMX」（脱衣身体的法线从它拿，最准）；
4. 「3. 生成」：**「生成爆衣表情」**。改了设置再点一次就重做；**「撤掉爆衣表情」** 让模型回到生成之前；
5. 「4. 时间、预览、导出」：填「爆开帧」，点 **「在时间轴上预览」**，按空格播放看效果（只打爆衣的几个表情帧，别的表情不动）；
   **「导出爆衣 VMD」**：只有表情帧的 VMD；填了「合进动作」就是那段动作加上爆衣的帧；
6. PMX 用 mmd_tools 照常导出模型（缩放和导入时一样）。MMD 里：读入 PMX → 读入舞蹈动作 → 再对这个模型读入爆衣 VMD。

**要知道的**（2026-10-05 在用户开着的 Blender 里走了一遍以后补的）

- 在 3D 视图的 **「材质预览」**（或「渲染」）里看：「实体」视图里材质表情不起作用，衣服不会消失。
- **导入的已经是爆衣 PMX**（这个插件或 `burst_pmx_blender.py` 做的）：插件认得出来，第 3 栏写「模型已经带着爆衣表情
  （导入的爆衣 PMX）」，不再生成（再生成会叠一层），「在时间轴上预览」「导出爆衣 VMD」照常用。
- **材质被 mmd_tools 的「Convert Materials For Cycles」转成了原理化BSDF**：mmd_tools 的材质表情节点留在材质里，却连不到
  原理化BSDF 上，表情拉满也看不出来。插件给爆衣涉及的材质（衣服、身体、碎片、脱衣身体）在材质输出前面插一个节点
  「CB 爆衣透明」：按这几个表情算出的透明度（MMD 的算法：文件里的 alpha × 乘算 + 加算）和「透明」混合，由表情滑块驱动。
  生成时插、撤掉时拿掉；导入的爆衣 PMX 上是预览时插、「清除预览」时拿掉。只影响 Blender 里的显示，导出的 PMX 不变。
  mmd_tools 自己的着色器不用插。
- **刚生成的头几秒衣服上闪过黑块 / 白块**：EEVEE 在编译新材质的着色器，等几秒。
- **导入设置随意**：缩放 0.08 还是 1.0（mmd_tools 有的版本默认 0.08，用户装的默认 1.0）、骨骼改不改名都行，结果一样。
  nude 版 PMX 的缩放从两边共有的骨骼算（两两骨骼距离之比的中位数），主骨骼按 mmd_tools 存的日文原名认。

**加了什么**（都在模型里，mmd_tools 导出时带进 PMX）

| 东西 | 碎片飞散 | 直接消失 | 说明 |
|---|---|---|---|
| 碎片物体 `<网格>_burst`，材质 `<材质>_burst` | ✓ | | 衣服的副本切成碎片，每块只挂一根主骨骼；材质在文件里透明 |
| 顶点表情 `爆衣` / `爆衣落下` | ✓ | | 碎片飞出去（沿身体表面往外、上扬、转）/ 落到地上（叠加在 `爆衣` 上） |
| 材质表情 `爆衣碎片_材質` | ✓ | | 碎片的透明度加回来 |
| 材质表情 `衣服非表示_材質` | 没有才加 | 没有才加 | 衣服的透明度 × 0 |
| 脱衣身体 `<网格>_nude`，材质 `<材质>_nude` | 勾了才有 | 勾了才有 | 身体的副本：裸体形状的位置和法线，文件里透明 |
| `裸体形状` 改成材质表情 | 勾了才有 | 勾了才有 | 原来的身体 × 0、脱衣身体加回来（换身体） |
| 组合表情 `衣服非表示` | 没有才加 | 没有才加 | `衣服非表示_材質` + `裸体形状`，平时拉滑块一下脱掉 |
| 材质里的节点「CB 爆衣透明」 | 不是 MMD 着色器的材质才有 | 同左 | 只为 Blender 里看得见材质表情（见上），不进 PMX |

碎片和脱衣身体的材质用 BLEND 混合、不显示背面（和 mmd_tools 导入器对重合的面一样）：它们和原来的面重合，
mmd_tools 设透明度时给的 HASHED 在 EEVEE 里会画成黑块。

**为什么要「换成完整身体」**：ROE 的 full 版身体平时收在衣服里（不穿模），形状键「裸体形状」是它自己的形状。
MMD 的顶点表情只挪位置、不重算法线，光照还是「收在衣服里」那个形状的：胸部有凹坑、指甲黑口。两份身体各有各的法线，
MMD 和 Blender 里都对。

**VMD 的时间**（30 fps，「慢放」按倍数拉长）：

| 碎片飞散 | 爆开后第几帧 |
|---|---|
| 衣服隐藏、碎片显示（碎片还在原位） | 0 |
| 碎片飞出（先快后慢） | 0 → 8 |
| 换成完整身体（这时碎片已经离开身体） | 0 → 2 |
| 碎片落地（越落越快） | 6 → 30 |
| 碎片淡出（「碎片淡出」关掉就留在地上） | 26 → 40 |

直接消失：衣服在「淡出用几帧」里淡出，淡完那一帧换身体。

**限制**：轨迹是预先算的，碎片不和身体、地面、彼此碰撞；碎片一直跟着挂的骨头走：护臂碎片会被手臂甩一下，
手臂抬着的时候爆开，它们的「往下落」也跟着手臂转，停在半空，到淡出才消失（a08 跳手势舞时左臂的链环）。
