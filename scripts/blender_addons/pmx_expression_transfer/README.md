# PMX Expression Transfer —— 把一个 PMX 模型的表情移植到另一个 PMX 模型的脸上（Blender 插件）

选一个表情齐全的 PMX 当来源，把它的表情（眨眼、口型、眉毛……）按目标的脸型贴到另一个 PMX 的脸上，写出新的 PMX。
两张脸的网格**不用一样**：不同游戏、不同顶点数、不同脸型都行。每个表情写成目标的顶点表情，名字、面板和来源一样，
MMD 的舞蹈 VMD 按名字就能驱动。两个原文件不动。

```
scripts/blender_addons/pmx_expression_transfer/
  __init__.py   Blender 插件入口：侧栏 MMD 页签 → 表情移植
  core.py       算法（共用 pmx_outfit_transfer/core.py 的底层：读写 PMX、最近点搜索）
  cli.py        命令行：blender -b --factory-startup --python cli.py -- 来源.pmx 目标.pmx 输出.pmx [选项]
```

2026-10-25 第一批用例：FF7 系的 PMX 没有表情（脸只绑在「頭」一根骨上），用 FF7 Remake Tifa 的游戏表情（09-26 的试做）
移植过去。一步一步的用法见 [docs/pmx-expression-transfer-usage.md](../../../docs/pmx-expression-transfer-usage.md)，
原理和数字见 [docs/pmx-expression-transfer.md](../../../docs/pmx-expression-transfer.md)。

## 安装

目录联接（本机已装）：

```powershell
New-Item -ItemType Junction -Path "$env:APPDATA\Blender Foundation\Blender\3.6\scripts\addons\pmx_expression_transfer" `
         -Target "E:\code\othercode\ripper_tpose\scripts\blender_addons\pmx_expression_transfer"
```

偏好设置 → 插件，搜 `PMX Expression Transfer` 勾上。要同时装着 `pmx_outfit_transfer`（同一个目录，共用代码；不必启用）和 mmd_tools。

## 用法

侧栏（`N`）→ **MMD** 页签 →「**表情移植**」：

1. **表情来自**：表情齐全的 PMX；**移到**：要加表情的 PMX；**输出 PMX** 留空就在目标旁边新建 `<目标>_表情移植\`。
2. 「**读取表情**」：列出来源的表情，默认勾上**目标没有的 MMD 标准表情**；目标已有的、动眼球 / 牙齿 / 伸舌头的、
   材质表情不勾（右边写着原因）。下面三个按钮：只勾标准表情 / 全选 / 全不选。
3. 选项：
   - **同名的替换**：目标已有同名表情时换成移植的（默认关：只补缺的）；
   - **眨眼闭严修正**（默认开）：按两边眼睛张开的高度修正眼皮，来源闭上的地方目标也正好闭上；
   - **牙齿舌头跟着下巴**（默认开）；
   - **强度**：按面板（眉 / 目 / 口 / 其他）整体放大缩小；
   - **做完导入场景**。
4. 「**移植表情**」。一张脸一两分钟（Blender 里更快）。

命令行：

```powershell
& "D:\Program Files\blender-3.6.15-windows-x64\blender.exe" -b --factory-startup --python scripts\blender_addons\pmx_expression_transfer\cli.py -- `
    来源.pmx 目标.pmx 输出.pmx [--morphs "あ,い,う"] [--replace] [--no-lid] [--no-jaw] [--strength "brow=1,eye=1,mouth=1,other=1"]
python cli.py 来源.pmx 目标.pmx --list      # 只列出会搬哪些、为什么不搬
```

普通 Python（numpy）也能跑：`python cli.py …`。

## 原理（一张脸的表情怎么到另一张脸上）

1. **各自的坐标**：眼球给出两只眼睛的中心，左右方向和上方由它们定，脸朝第三个方向；长度都用两眼距离（IOD）量。
2. **从正面找特征**（两张脸用同一套办法）：把脸的皮肤从正前方做深度缓冲——
   - 眼睛开口 = 眼球比皮肤更靠前的那块区域，开口的上下边就是上下眼皮边缘（眼睛是洞的网格、眼窝封闭的网格都一样）；
   - 嘴唇缝 = 嘴中间那条又窄又深的谷（闭着嘴是一条缝，张着嘴是个洞），沿着它往两边找，谷消失处是嘴角；
   - 鼻尖 = 两眼和嘴之间最靠前的点。
3. **把来源的脸弯到目标的脸上**：眼皮、嘴唇、鼻尖这些特征点先二维对上，由此在整个脸的正面配出几百对对应点，
   再用三维薄板样条把来源的每个皮肤顶点搬过去（特征点精确重合）。目标的每个皮肤顶点去找弯过来的来源皮肤上最近的点——
   上眼皮只找上眼皮、下嘴唇只找下嘴唇，不会跨过开口。
4. **表情搬过去**：来源的位移乘上这个弯折在那一点的局部导数（雅可比）——目标的嘴更宽，笑的时候嘴角就拉得更开；眼睛更高，眼皮走得更远。
5. **眼睛闭严**：沿眼皮取 17 个点，每个点上「上下眼皮的距离 / 睁眼时的距离」做成和来源一样（来源闭上了目标也正好闭上、
   来源交叠多少目标也交叠多少），修正量在眼皮上渐变开；眼皮不陷进眼球（按眼球网格本身判断）。
6. **找不到可靠对应点的皮肤**（离弯过来的来源皮肤超过约 0.7 mm：比如嘴唇内侧卷进嘴里很深的那一片）不用搬来的位移，
   用周围可靠的点平滑插值；嘴里深处和口腔连着的那一圈按上牙不动、下巴转动定。
7. **睫毛、眉毛**这类小零件骑在下面的皮肤上：一根睫毛（一个连通小块）整块跟着它根部的皮肤；挂在眼皮上的睫毛随眼皮
   绕眼球中心转，眼皮转多少度它转多少度。
8. **牙齿、舌头**：按导出时的零件分（上牙床、下牙床、舌头、口腔侧壁），上面的不动，下面的整块随下巴转。
   下巴转多少：来源有牙齿时取来源下牙的刚体运动（绕下牙中心的转角、转轴方向不变，中心和平移按两张脸的比例换算），
   没有就按目标下巴的皮肤拟合。
   和嘴唇内侧缝在一起的那一圈跟着嘴唇走。

## 做不了 / 注意

- 眼睛要有眼球网格（挂在 `左目` / `右目` 上，或材质名带 eye / iris / 瞳）。眼睛画在贴图上、没有眼球的卡通脸不支持。
- 只搬顶点位移：材质表情（换眼睛贴图、脸红贴图）、UV 表情不搬；伸舌头（ぺろっ、てへぺろ）、瞳小、歯無し默认不勾。
- 嘴缝要能从正面看出来（一条缝或一道深谷）。嘴唇完全长平的脸找不到嘴角。
- 来源和目标风格差得多时（写实脸 ↔ 卡通脸），口型会带着来源的风格（来源嘴张得大，目标也张得大）；可以用面板强度调小。
